# V45.1 Mobile Map Navigation / Gesture UX

## Goal

スマホ版Canovia Mapで以下を同時に満たす。

- Nodeを選んだ後も別Nodeへそのまま切り替えられる
- Context SurfaceのClose / Expandを確実に操作できる
- Mapを上下左右へ自由にPanできる
- Pinchで拡大縮小できる
- 迷子にならないようPan / Zoom範囲を制限する
- 1操作で中央・等倍へ戻れる
- Navigation Graph / Attention State / canonical dataは変更しない

## Mobile selection model

V45.0以前のFocus Modeは、Node選択時に1-hop以外を非表示にして
NodeをFocus layoutへ再配置していた。

これはDesktopではContextを絞る利点がある一方、Mobileでは:

- 他Nodeへ直接切り替えにくい
- Map全体の位置感覚が失われる
- Bottom Sheetと組み合わせたときに「押せないNode」に見える

という問題がある。

V45.1ではMobileだけ:

```text
Map remains spatially stable
        ↓
tap Node
        ↓
selected highlight
        ↓
Context Surface content switches
```

とする。

MobileではNode選択中も他Nodeをpointer-enabledのまま維持する。

Desktop Focus Modeは従来どおり1-hop Focusを維持する。

## Context Surface reliability

Close / Expandは個別DOM参照へのlistenerだけに依存せず、
Map pageのdelegated clickでも処理する。

Closeはhistory backの完了を待たず:

1. Surfaceを即時close
2. selected stateを即時clear
3. 必要ならbrowser historyを同期

とする。

これによりタッチ時に「×を押したのに見た目が変わらない」状態を避ける。

Touch targetは最低2.75remを確保する。

## Transformable scene

Node / SVG edgesを`data-map-scene`内へまとめる。

Map shellはviewport、
Map sceneはtransform対象。

```text
Map Shell / viewport
  ├─ fixed axis / controls / Spatial Dock
  └─ Map Scene
      ├─ constellation edges
      └─ Nodes
```

transform:

```css
translate3d(panX, panY, 0) scale(zoom)
```

absolute Node coordinates自体は書き換えない。

## Pan

Mobile Map Sceneは1本指Pointer gestureで上下左右へPanできる。

Map rotationは行わない。

理由:

- Plan / Execution / Reflection / Collaborationの方向文法を保持する
- Spatial Memoryを壊さない
- 「360°移動」は全方向Panとして扱う

Drag thresholdは5px。

thresholdを超えたGesture後は短時間clickを抑止し、
Pan終了時のNode誤タップを防ぐ。

## Pinch zoom

2 pointerでPinch Zoomする。

Zoom range:

- min: 0.82x
- max: 2.2x

Pinch midpointを基準にscaleし、
同時にmidpoint移動分をPanへ反映する。

## Bounded universe

無限Panは禁止する。

scale >= 1:

```text
maxPan =
  scaled content overflow / 2
  + viewport * 10%
```

scale < 1:

```text
maxPan = viewport * 4%
```

これにより:

- 端のNodeを見るための余白は残す
- Map全体が画面外へ消えるほど移動できない
- 縮小時に大量の空白へ迷い込まない

## Controls

Mobile Map右上に:

- − : zoom out
- ◎ : center / 1x reset
- ＋ : zoom in

を表示する。

Reset:

```text
panX = 0
panY = 0
scale = 1
```

Zoom limitに到達したbuttonはdisabledにする。

## Double click / double tap

空白領域のdouble click / compatible double tapでは:

- current <= 1.18x -> 1.55x
- current > 1.18x -> 1x

へ切り替える。

Node / link / form control上では発火しない。

## Responsive behavior

Gesture transformはMobile runtime stateだけ。

Desktopへbreakpointを跨いだ場合:

- transform -> identity
- existing Desktop Focusへ再Projection

DesktopからMobileへ戻った場合:

- Mobile stable selectionへ切り替える

Resize / orientation change時は現在transformを新viewport boundsへ再clampする。

## Decorative orbit

MobileではShell固定pseudo orbitを非表示にし、
Map Scene内にorbit decorationを置く。

そのためPan / Zoom時に:

- Node
- edges
- orbit

が同じ空間として動く。

Axis labels / Spatial Dock / gesture controlsはviewport chromeとして固定する。

## Persistence

保存しない:

- panX
- panY
- zoom
- pointer state
- gesture history

Level遷移・reloadではFit状態から開始する。

canonical Map stateには含めない。

## Telemetry

V45.1ではgesture coordinate / zoom valueをTelemetryへ追加しない。

既存Map interaction telemetryのみ継続する。

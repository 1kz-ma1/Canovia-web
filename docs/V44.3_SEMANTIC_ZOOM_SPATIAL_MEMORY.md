# V44.3 Semantic Zoom / Spatial Memory

## Goal

Canovia Mapを「階層ごとに別ページへ飛ぶNavigation」から、同じ情報空間を拡大・縮小しながら辿るNavigationへ進化させる。

V44.3でL0〜L3を一本の経路として接続する。

```text
L0 Intent
  ↓ Semantic Zoom
L1 Domain
  ↓ Semantic Zoom
L2 Plan
  ↓ Semantic Zoom
L3 Execution
  ↓
Classic Surface / Execution Tool
```

同時に、入力・相談の場所であるSpace StationをL1〜L3でも同じ位置に残し、Spatial Memoryを成立させる。

## Hierarchy contract

### L0 Intent

固定Nodeは Space Station / 計画 / 実行 / 振り返り / 共同。
V44.3以降、非Station IntentはL3へ直接飛ばず、まずL1へ入る。
例: `/map?level=l1&intent=execution`。

### L1 Domain

ユーザーが現在アクセスできるPlanをDomainへまとめて表示する。
V44.3のDomainは新しい永続Entityではなく、既存 `Plan.category` からProjection時に導出する。
Domain keyはcategory labelから決定的に生成する12文字hashで、Domain rowやGraph rowは保存しない。

### L2 Plan

選択したDomainに属するPlanだけを表示する。
Plan Nodeは `/map?level=l3&intent=...&domain=...&plan=<id>` へSemantic Zoomする。

### L3 Execution

既存V43 Execution Mapを再利用する。
Semantic Zoomから `plan=<id>` が指定された場合、そのPlanをExecution scopeとして優先する。
DashboardGuidanceServiceは廃止せず、選択Plan内部のCurrent Task / Tool等のexecution guidanceとして利用する。
`plan` 指定なしのlegacy L3はV43互換挙動を維持する。

## Navigation Graph vs Attention State

`HierarchyNavigationGraphService` はIntent Context / Domain / Plan / parent-child relation / Semantic Zoom destinationを決める。
position / importance / size / glow / edge strengthは決めない。

`HierarchyMapAttentionStateService` がcenter parent、child orbit position、size / state / importance、edge visual strengthを投影する。
位置はProjection時に決定的に算出し、永続化しない。

Recommendationは今後emphasis / center distance / glow / size / Personalized Satellite promotionへ作用させる。
Node existenceは変えない。

## Domain projection

V44.3では既存Plan categoryをDomainとして利用する。
新しい分類入力、Domain table、Plan複製を導入せず、Hierarchy UXを先に検証する。
未分類Planは「未分類」Domainへ入る。
Domain metadataとしてplan count / active task count / collaborative plan countをProjection時に算出する。

## Semantic Zoom

Semantic Zoomは意味上の親子関係に沿ったLevel移動のみを指す。

Zoom In:
- Intent → Domain
- Domain → Plan
- Plan → Execution
- `data-map-semantic-zoom`
- `data-map-zoom-direction="in"`
- UI: 「潜る ↘」

Zoom Out:
- Breadcrumb / parent CTA
- `data-map-zoom-direction="out"`
- UI: 「戻る ↖」

transition directionはsessionStorageへ短時間だけ保存する。
保存するのはdirection / from depth / timestampのみで、Plan title / Task title / user input / AI content / URL contentは保存しない。
到着時にstateを消費し、10秒を超えた古いstateは破棄する。
`prefers-reduced-motion` ではanimationを無効化する。

## Spatial Memory

ユーザーがLevelを移動しても「入力・相談はここ」という場所を再学習させない。

L0ではSpace Stationが中央固定Graph Node。
L1 / L2 / L3ではSpace StationをGraph Entityとして注入せず、右下固定のSpatial Dockとして表示する。

理由:
- Domain / Plan / Execution semantic graphを汚さない
- Space Stationは階層のchildではない
- Recommendationで消えない
- graph layoutを変えずCapture / Companionへ入れる
- 同じ方向・位置をLevel間で維持できる

Spatial DockはNavigation chromeである。

## Space Station Dock

L1〜L3で右下Dockを押すと `#dock=space-station` を使ってContextual Classic Surfaceを開く。
Graph Nodeの位置は変更せず、V44.2のSpace Station Surfaceを再利用する。
新しいCapture storeは作らない。
Back / Escape / closeはNode Focusと同じContext close boundaryを使う。
Node Focusの `#focus=...` とDockの `#dock=...` は別状態として扱う。

## Deep-level Capture return

L1〜L3のDockからCapture / Suggest / Confirmした場合、処理後にL0へ戻さない。
限定されたstructural fieldsだけをPOSTする。

- `return_to=map_station`
- `map_level=l1|l2|l3`
- `map_intent`
- `map_domain`
- `map_plan`

server validationでenum / hash / integerへ制限し、任意URLは受け付けない。
処理後は同じHierarchy URL + `#dock=space-station` へ戻る。

## Hierarchy breadcrumbs

各Levelで現在地を表示する。例: `Canovia › 実行 › 個人開発 › Canovia`。
BreadcrumbはSemantic Zoom Outとして扱う。
Depth Trackは L0 Intent / L1 Domain / L2 Plan / L3 Execution を示す。

## Focus Mode compatibility

既存Focus Modeは維持する。
Hierarchy Nodeでもselected nodeをcenterへ置き、one-hop neighborだけを見せ、semantic directionを維持する。
Spatial DockはGraph layoutを変えずContext Surfaceだけを差し替える。

## Living Reevaluation

Level間Semantic Zoomはmutationではないためpending reevaluationを作らない。
Classic Surface / Capture / Companion等でCanovia stateを変更した場合は従来のLiving Reevaluation boundaryを利用する。
L1〜L3 projection keyにはSpace Stationのsafe `state_key` を合成し、user content本文は含めない。

## Telemetry

V44.3で追加するstructural values:
- node_type: `domain`, `intent_context`
- position_role: `hierarchy-parent`, `hierarchy-child`, `spatial-dock`
- action_role: `zoom`

既存同様whitelist外metadataは破棄する。Domain名、Plan名、Task名、Capture本文等はMap Telemetryへ保存しない。

## Compatibility

- `/map` = L0
- direct `/map?level=l3`
- plan指定なしL3のV43 guidance behavior
- V43 Execution Graph
- Primary Action direct launch
- non-primary direct navigation
- Focus Mode
- Contextual Classic Surface
- Contextual Companion at L3
- Space Station V44.2 Human Review boundary
- Inbox page / Classic Home / Home Surface preference
- Living Reevaluation / Instant Navigation / no-JS fallback

## Non-goals

- Personalized Satellite
- usage based L0 promotion
- recommendation based node existence
- external GitHub / Calendar graph projection
- collaboration tool reprojection
- Graph DB / Domain DB table
- absolute node position persistence
- AI layout / AI automatic Plan・Task selection / automatic mutation

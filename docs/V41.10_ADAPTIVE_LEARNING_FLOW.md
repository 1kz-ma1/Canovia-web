# V41.10 Adaptive Learning Flow

> V56.15 preserves the V41.10 Study Activity Policy as the Task-semantic method-fit layer. State-aware method priority now wraps this policy in `StudyMethodRecommendationService`; `forPlanTask()` remains backward-compatible.


## Goal

AI演習を「同じTaskで問題を繰り返す機能」から、学習結果に応じて安全にTaskを進めるフローへ拡張する。

Phase Aでは以下に限定する。

1. 採点後UIをPrimary Action中心へ整理
2. AIのTask完了提案をCanovia側で検証
3. 1回の高得点だけでTaskを跨がない
4. 仕上げ確認を通過したら次のeligible Taskへ進む
5. 次Taskの内容を新しいStudy Practice Strategy / Promptへ使う

Phase Bではさらに以下を追加する。

1. Study Activity Policy（Question Practice / Recall / Resource Study）
2. TOEIC語彙などでAI PracticeをPrimaryにしない判定
3. Home / Plan / Task ToolsのPrimary ActionをActivity Policyへ接続
4. AI演習の信頼度目安（出題内容 / 採点 / Coverage / 学習方法との相性）
5. 信頼度は「実測したAI正答率」ではないことを明示する。

## Completion Boundary

AIの `next_step.kind=complete_task` と `recommended_task_progress_percent=100` は、DB更新命令ではなく **completion signal** とする。

Canoviaの `StudyTaskProgressionService` が以下を判定する。

- `reinforce_current`
- `continue_current`
- `verify_mastery`
- `advance_task`
- `review_plan`
- `plan_complete`

### Mastery verification

Task完了には、直近2回が連続して以下を満たすことを要求する。

- score >= 85
- summary weaknessesが空
- incorrect / partial のうち重大なerror typeが残っていない

重大なerror type:

- knowledge_gap
- concept_gap
- reasoning_gap
- condition_reading
- unit_error
- unknown

`careless` と `calculation_slip` は、それ単独ではTask完了を阻止しない。

完了Signalはあるが検証不足の場合、進捗100%への自動反映を止め、最大99%で `mastery_verification` に移る。

## Next Task

仕上げ確認を通過した場合、CanoviaがPlan内から次に実行可能なTaskを選ぶ。

- done / cancelled / 100% は除外
- dependencyが未完了なら除外
- 現在Taskへのdependencyは、現在Taskを完了すると仮定して解放
- doing
- priority
- activation_cost
- sort_order
- id

の順で決定する。

AIはTask IDを選ばない。

## Result UI

Result画面ではPrimary mutationを1つだけ表示する。

未反映:

```
NEXT ACTION
...
[結果を反映して次へ]
```

詳細な強み・弱点・問題別Feedback・評価根拠は「詳しい評価を確認」へ折りたたむ。

Task反映用の第二CTAは廃止する。

## Study Activity Policy

資格学習カテゴリだけを理由にAI演習をPrimaryへしない。

Task本文・説明・next actionから以下の相対適合度を決定する。

- Question Practice: 過去問、模試、計算、理解確認、問題演習
- Recall: 単語、語彙、熟語、暗記、フラッシュカード
- Resource Study: 参考書、教科書、講義、解説、インプット

例: 「TOEIC英単語を暗記する」はRecallをPrimaryにし、AI演習は理解確認用のsecondary optionとして残す。

## Practice Reliability

AI演習画面には4軸の目安を表示する。

- 出題内容
- 採点
- 範囲カバー
- 学習方法との相性

スコアは実測したモデル正答率ではない。Question Bank / Hybrid / Native AI / External AIという出題元、grading方式、選択問題数・Coverage、Study Activity適合度から決定論で算出する。

この表示の目的は「AIの数字を信じさせる」ことではなく、問題集・教材学習・Recallの方が適切なTaskでは、その可能性をUI上で明示することにある。

## V58.10 Language Activity update

The V41.10 follow-up "Listening / Dictation / Shadowing等のActivity追加" is
implemented in V58.10.

The three Activities are now Task-semantic Study methods with a dedicated
provider-free execution surface and explicit self-reported Evidence. They do
not use microphone capture, speech recognition or automatic scoring.

Question-oriented Listening Tasks remain Question Practice.

See `docs/V58.10_STUDY_LANGUAGE_ACTIVITIES.md`.

## V58.12 Activity outcome observation update

The V41.10 follow-up "実利用データからのActivity効果検証" is implemented at
the safe observation boundary in V58.12.

Canovia compares adjacent valid Practice assessments and attributes the interval
only when zero or one tracked non-Practice Activity type is present. Mixed
Activity intervals and intervals over 14 days are excluded.

The result is descriptive before/after evidence only. It does not automatically
change Study Method Recommendation or Practice Reliability.

See `docs/V58.12_STUDY_ACTIVITY_OUTCOME_OBSERVATION.md`.

## V58.13 Question Candidate Reliability update

The V41.10 follow-up "Question Candidate品質・利用実績をReliabilityへ反映" is
implemented in V58.13.

For the current exam profile, Canovia observes Candidate promoted / rejected
Human Review outcomes and reuse of promoted Candidate Questions in assessed
Practice Sessions.

After at least 5 reviewed Candidates, Native AI / Hybrid AI question-quality
Reliability can receive a bounded -6..+6 adjustment scaled by review/reuse
evidence volume.

Learner correctness is explicitly excluded from Question quality.

See `docs/V58.13_QUESTION_CANDIDATE_RELIABILITY.md`.

## V58.14 Resource Study execution update

Resource Study now has a dedicated execution surface and explicit completion
Evidence.

```text
resource_study
→ /plans/{plan}/tasks/{task}/study-resource
→ explicit outcome
→ study_resource_study_completed
```

Opening a Resource link alone does not create Evidence.

The Activity remains self-reported and does not automatically mutate Task
progress or mastery. Existing `study.resource` /
`canovia.study.resource` Execution Ecosystem contracts remain unchanged.

V58.12 can now include Resource Study in before/after Practice observation.

See `docs/V58.14_RESOURCE_STUDY_EVIDENCE.md`.

## V58.15 Study Method outcome calibration update

V58.12 Activity observations now provide a bounded secondary personalization
signal for Study Method fit.

Only explicit non-Practice Activities are eligible:

- Recall
- Resource Study
- Listening
- Dictation
- Shadowing

At least 3 same-Task actor-scoped comparable observations are required.
The latest at most 5 observations use median score delta plus a 2/3 direction
consistency gate.

Applied fit adjustment is capped at ±5.

The deterministic Primary Method selected by V56.15 is not auto-switched.

Question Practice is explicitly excluded because an interval with no tracked
Activity does not prove that only Practice occurred.

See `docs/V58.15_STUDY_METHOD_OUTCOME_CALIBRATION.md`.

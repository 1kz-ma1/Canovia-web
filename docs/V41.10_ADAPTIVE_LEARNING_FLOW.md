# V41.10 Adaptive Learning Flow

## Goal

AI演習を「同じTaskで問題を繰り返す機能」から、学習結果に応じて安全にTaskを進めるフローへ拡張する。

Phase Aでは以下に限定する。

1. 採点後UIをPrimary Action中心へ整理
2. AIのTask完了提案をCanovia側で検証
3. 1回の高得点だけでTaskを跨がない
4. 仕上げ確認を通過したら次のeligible Taskへ進む
5. 次Taskの内容を新しいStudy Practice Strategy / Promptへ使う

Phase Bではさらに以下を追加する。

1. Study Activity Policy（Question Practice / Recall / Resource Study）
2. TOEIC語彙などでAI PracticeをPrimaryにしない判定
3. Home / Plan / Task ToolsのPrimary ActionをActivity Policyへ接続
4. AI演習の信頼度目安（出題内容 / 採点 / Coverage / 学習方法との相性）
5. 信頼度は「実測したAI正答率」ではないことを明示する。

## Completion Boundary

AIの `next_step.kind=complete_task` と `recommended_task_progress_percent=100` は、DB更新命令ではなく **completion signal** とする。

Canoviaの `StudyTaskProgressionService` が以下を判定する。

- `reinforce_current`
- `continue_current`
- `verify_mastery`
- `advance_task`
- `review_plan`
- `plan_complete`

### Mastery verification

Task完了には、直近2回が連続して以下を満たすことを要求する。

- score >= 85
- summary weaknessesが空
- incorrect / partial のうち重大なerror typeが残っていない

重大なerror type:

- knowledge_gap
- concept_gap
- reasoning_gap
- condition_reading
- unit_error
- unknown

`careless` と `calculation_slip` は、それ単独ではTask完了を阻止しない。

完了Signalはあるが検証不足の場合、進捗100%への自動反映を止め、最大99%で `mastery_verification` に移る。

## Next Task

仕上げ確認を通過した場合、CanoviaがPlan内から次に実行可能なTaskを選ぶ。

- done / cancelled / 100% は除外
- dependencyが未完了なら除外
- 現在Taskへのdependencyは、現在Taskを完了すると仮定して解放
- doing
- priority
- activation_cost
- sort_order
- id

の順で決定する。

AIはTask IDを選ばない。

## Result UI

Result画面ではPrimary mutationを1つだけ表示する。

未反映:

```
NEXT ACTION
...
[結果を反映して次へ]
```

詳細な強み・弱点・問題別Feedback・評価根拠は「詳しい評価を確認」へ折りたたむ。

Task反映用の第二CTAは廃止する。

## Study Activity Policy

資格学習カテゴリだけを理由にAI演習をPrimaryへしない。

Task本文・説明・next actionから以下の相対適合度を決定する。

- Question Practice: 過去問、模試、計算、理解確認、問題演習
- Recall: 単語、語彙、熟語、暗記、フラッシュカード
- Resource Study: 参考書、教科書、講義、解説、インプット

例: 「TOEIC英単語を暗記する」はRecallをPrimaryにし、AI演習は理解確認用のsecondary optionとして残す。

## Practice Reliability

AI演習画面には4軸の目安を表示する。

- 出題内容
- 採点
- 範囲カバー
- 学習方法との相性

スコアは実測したモデル正答率ではない。Question Bank / Hybrid / Native AI / External AIという出題元、grading方式、選択問題数・Coverage、Study Activity適合度から決定論で算出する。

この表示の目的は「AIの数字を信じさせる」ことではなく、問題集・教材学習・Recallの方が適切なTaskでは、その可能性をUI上で明示することにある。

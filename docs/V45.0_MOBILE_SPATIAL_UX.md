# V45.0 Mobile Spatial UX

## Goal

Canovia Mapをスマホで「Desktopを縮小した画面」ではなく、
縦長Viewportに最適化されたSpatial Navigationとして表示する。

V44で追加した以下の意味構造は変更しない。

- L0 fixed Intent Hub
- Space Station
- Semantic Zoom
- Spatial Memory
- Personalized Satellites
- Collaboration Purpose Map

V45.0はvisual / interaction projectionだけを変更する。

## Problem

V44.4までにL0へ最大4個のPersonalized Satelliteが追加された。

Desktopでは十分な面積があるため、

- Space Station
- 4 Intent
- 最大4 Satellite

を円形に配置できる。

一方、スマホではDesktopと同じ座標比率を使いながらNode実寸を維持していたため、

- IntentとSatelliteの間隔が狭い
- Node内のDirect Open pillが情報密度を上げる
- Map Canvasより周辺UIの比率が大きい
- 縦長Viewportを十分活用できない

という問題が出た。

## Principle

> Mobileは縮小版ではなく、同じ意味空間の別Projection。

Server側のsemantic / attention座標は変更しない。

Mobile layoutはclient側でrequest時に決定し、
DBへabsolute positionを保存しない。

Desktop layoutも変更しない。

## Mobile L0

スマホでは2リング構造を明確にする。

```text
           Satellite 1

   Plan                  Execution

Satellite 4   Space Station   Satellite 2

 Collaboration          Reflection

           Satellite 3
```

V45.4.1以降、Mobile role positionはViewport aspect ratioを考慮して算出する。

- Space Station: 50 / 50
- Intent inner ring: viewport widthを基準に約23%相当のpixel radius
- Satellite outer ring: viewport widthを基準に約38%相当のpixel radius
- y方向は同じpixel radiusをviewport heightへ換算したpercentを使用

このため390×700のような縦長Canvasでも、同じringの上下・左右距離はrendered pixel上でほぼ同じになる。

この座標はclient projectionであり、canonical attention positionではない。

## Mobile L1 / L2

Hierarchy parentは50 / 50を維持する。

Hierarchy childrenはViewport aspect ratioを補正したpixel-balanced orbitへ再配置する。

- child <= 4: viewport widthの約34%をpixel radiusにする
- child >= 5: viewport widthの約37%をpixel radiusにする
- x/y percentは同じpixel radiusから個別換算する

これにより縦長Viewportでも軌道そのものが縦方向へ引き伸ばされない。

## L3

Execution Mapのbase semantic directionsは変更しない。

Focus Modeには既存mobile focus layoutを継続使用する。

- selected Context: upper center
- Context Surface: bottom sheet

これによりActionとsheetの重なりを避ける。

## Edge synchronization

NodeだけをCSSで移動するとconstellation lineが元座標に残る。

V45.0では`buildMobileBaseLayout()`でNode positionを計算し、
同じMapを使ってSVG edgeの:

- x1
- y1
- x2
- y2

も更新する。

Nodeとedgeは常に同じprojectionを参照する。

## Responsive lifecycle

Mobile projectionは以下で再計算する。

- Map mount
- viewport resize / orientation change
- pageshow / bfcache return
- Focus reset

Desktopへ戻った場合はserver-projected positionへ復帰する。

## Canvas height

スマホMapはViewportをより大きく使う。

通常:

`clamp(42rem, calc(100dvh - 8.5rem), 50rem)`

短い端末:

- max-width 430px
- max-height 740px

では39remへcompact fallbackする。

Bottom Context Surfaceは既存mobile tab barとsafe-areaを避ける。

## Mobile node density

L0 mobileではDirect Open pillをMap Node内部から非表示にする。

Node tap:

```text
Node
  ↓
Context Surface
  ↓
canonical action
```

とする。

Direct Navigation自体のURL / semantic contractは削除しない。
Desktopでは従来どおり表示する。

L0 subtitleもmobileでは非表示とし、

- eyebrow
- label
- visual role

を優先する。

V45.4.1以降のMobile proportion:

- Space Station: 1:1
- Intent Planet: 1:1
- Personalized Satellite: 約1.38:1
- Hierarchy child: 約7.5rem × min-height 4.9rem
- Hierarchy parent: 約8.4rem × min-height 5.6rem

Fullscreen + Pan/Zoomにより「全Nodeを横幅へ無理に収める」制約を外し、意味に合う自然な比率を優先する。

## Hero density

Mobile Map Heroは:

- smaller padding
- smaller kicker / title
- description max 2 lines
- compact action buttons

へ変更する。

Mapそのものへvertical spaceを優先配分する。

## Spatial Memory

V44.3のSpatial Memoryは維持する。

- L0: Space Station center
- L1-L3: bottom-right Space Station Dock
- Focus / Capture後のhierarchy return

は変更しない。

## Accessibility

- Nodeのsemantic linkを削除しない
- Context Surfaceからcanonical actionへ到達可能
- focus stateを維持
- reduced-motion behaviorを維持
- viewport変更後もfocus layoutを再Projection

## Telemetry

V45.0では新しいuser-content telemetryを追加しない。

Mobile / Desktopは既存device metadataで区別可能。

absolute mobile coordinatesやviewport dimensionsは保存しない。

## Compatibility

維持:

- Desktop coordinates
- Navigation Graph
- Attention State
- L0 fixed 5 nodes
- Personalized Satellite promotion
- Semantic Zoom URLs
- Collaboration Purpose hierarchy
- L3 Execution behavior
- Contextual Classic Surface
- Space Station
- Living Reevaluation
- Instant Navigation

## Tests

JSで以下を固定する。

- mobile L0 two-ring pixel radius
- desktop/server positionをmutateしない
- mobile hierarchy aspect-compensated orbit
- existing Focus behavior

Feature regressionではV42〜V44.5を継続検証する。

## Next

V45.1以降は実機確認を前提に、

- touch target refinement
- Context Surface gesture
- node label collision handling
- mobile zoom animation
- tablet breakpoint

を必要に応じて分割する。

# V58.14 Resource Study Completion Evidence

Status: implemented / validated  
Branch: `feature/v58-14-resource-study-evidence`

## 1. Goal

Turn Resource Study from a recommendation-only Activity into an executable,
measurable Study Activity without treating a Resource-link open as learning.

```text
Resource Study recommendation
→ dedicated execution surface
→ learner opens material
→ learner explicitly records outcome
→ study_resource_study_completed Evidence
→ V58.12 before / after observation
```

## 2. Dedicated execution surface

Routes:

```text
GET  /plans/{plan}/tasks/{task}/study-resource
POST /plans/{plan}/tasks/{task}/study-resource
```

The surface provides:

- Resource Study execution guidance;
- eligible registered Resources;
- explicit Resource link opening;
- explicit completion/outcome form;
- recent Resource Study Evidence.

The existing Execution Ecosystem remains authoritative:

- capability: `study.resource`
- provider: `canovia.study.resource`

No new provider or capability is added.

## 3. Link-open is not Evidence

Opening a Resource URL does not create any TaskEvidence.

Canovia does not infer:

- that the material was read;
- how much was read;
- comprehension;
- mastery;
- Task progress.

Only the explicit outcome form creates Resource Study Evidence.

## 4. Resource context

Resource selection prefers:

1. Resources explicitly linked to the current Task;
2. when the Task has no linked Resource, unassigned Plan-level Resources.

If a submitted `resource_id` is present, the server re-resolves the eligible
Resource set and accepts only an ID from that set.

Therefore:

- cross-Plan Resource IDs are rejected;
- Resources linked only to another Task are rejected;
- a crafted POST cannot bypass the visible Resource context.

The Resource itself remains an external reference.

Canovia does not server-fetch or inspect the Resource URL.

## 5. Evidence contract

New TaskEvidence type:

`study_resource_study_completed`

Metadata:

- resource_id nullable;
- resource_title nullable;
- outcome_rating;
- reflection nullable.

Allowed `outcome_rating` values:

- `needs_review`
- `partial`
- `covered`

Confidence:

`0.65`

The confidence represents explicit self-reported Activity completion, not
objective comprehension.

Idempotency key:

`study-resource:{request_uuid}`

Repeated submission of the same request UUID does not duplicate Evidence.

## 6. Readable Evidence

`TaskEvidence::typeLabel()` renders:

`教材学習`

The summary shows:

- selected Resource title when available;
- learner-reported outcome.

Examples:

- `DNS教材 · 一部理解できた`
- `Resource Study · 必要範囲を確認できた`

## 7. Intelligence normalization

`TaskEvidenceAdapter` exposes only bounded decision facts:

- resource_id;
- outcome_rating.

It does not expose:

- Resource title;
- Resource URL;
- free-text reflection.

This keeps arbitrary Resource text and learner notes outside normalized
Intelligence facts.

## 8. V58.12 Activity observation

V58.14 extends the V58.12 tracked Activity set with:

`study_resource_study_completed → resource_study`

Behavior between adjacent valid Practice assessments:

### Resource Study only

```text
Practice 50
→ Resource Study
→ Resource Study
→ Practice 72
```

produces:

- usage_count = 2;
- observation_count = 1;
- before = 50;
- after = 72;
- delta = +22.

### Mixed Activity

```text
Practice
→ Resource Study
→ Recall
→ Practice
```

remains ambiguous and is excluded from per-Activity attribution.

Resource Study now uses the normal V58.12 status:

- `waiting` without comparable explicit Evidence;
- `observed` with a valid comparison.

The previous permanent `unmeasured` state is retired.

## 9. Recommendation boundary

V58.14 changes the Resource Study action URL from the generic Resource library
to the dedicated Resource Study execution surface.

It does not change:

- StudyActivityPolicy fit scoring;
- V56.15 recommendation scoring;
- repeated-knowledge-gap policy;
- Practice strategy;
- Practice Reliability.

The generic Resource library remains available from the execution surface for
material management.

## 10. Progress / mastery boundary

Recording Resource Study does not automatically change:

- Task progress_percent;
- remaining_minutes;
- Task status;
- Task completion;
- Recall mastery;
- Practice mastery.

A self-reported Resource Study session is Activity Evidence, not objective
mastery Evidence.

## 11. Free path

Resource Study execution and Evidence recording are native non-AI behavior.

No new entitlement is required.

The surface performs no Native AI or external-provider request.

## 12. Storage / migration

No migration is required.

V58.14 reuses:

- PlanResource;
- plan_resource_task;
- TaskEvidence.

No Resource body is copied into TaskEvidence.


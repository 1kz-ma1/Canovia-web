# V49.6 Semantic Expansion Clarity

## 目的

V49.5まででSemantic Zoomのgesture安定化、screen-space Node sizing、In-place Expansion、collision resolutionを導入した。

一方、実機では次の違和感が残った。

- zoom-in後もparent Nodeが通常Nodeと同じ強さで残り、childと競合する
- child Nodeが元levelとほぼ同じ視覚サイズで現れ、画面密度が急に高くなる
- 少しzoom-outしただけでparent Projectionへ戻り、camera縮小と階層移動を区別しにくい
- 最も具体的なleaf NodeまでSemantic Zoom候補に見え、detailを開く操作と階層移動が混ざる

V49.6ではSemantic Zoomを「containerを開いて具体化する操作」に限定し、leafはdetail-firstへ固定する。

## Interaction contract

### Container Node

Container Nodeでzoom-inする場合:

1. selected Nodeのworld positionは維持
2. next Projectionをその位置へ展開
3. arriving parent Nodeは半透明かつ縮退してspatial contextになる
4. child Nodeはparent周辺へ展開し、parentより一段小さいvisual scaleで表示
5. camera scaleは維持する

parent Nodeは新しい主役ではなく、展開元を示す背景Contextとして扱う。

### Leaf Node

`presentation.kind = leaf` のNodeはSemantic Zoom対象にしない。

- Node tap/click: Context Surface / Palette detail
- pinch target: semantic candidateにならない
- zoom-in chip: 表示しない
- `data-map-semantic-capability="detail"`

Containerで実際に次階層へ進めるNodeだけ:

- `data-map-semantic-capability="expand"`
- `data-map-semantic-zoom`
- semantic arm candidate

とする。

## Parent receding

Semantic arrival後のanchorへpersistent class:

- `is-semantic-expanded-parent`

を付与する。

visual contract:

- opacity: 約0.18
- saturation / brightness低下
- desktop visual scale: 0.78
- mobile visual scale: 0.82
- pointer eventsなし

arrival animation用の `is-semantic-expansion-anchor` は従来通り一時classとし、animation終了後もreceded parentだけ残す。

## Child density

Semantic arrival後のchildrenへpersistent class:

- `is-semantic-expanded-child`

を付与する。

visual scale:

- desktop: 0.88
- mobile: 0.84
- hover / active時だけわずかに拡大

既存V49.4 counter-scaleと組み合わせるため、camera zoomでDOM cardが過度に巨大化しない。

canonical Node size / coordinateは変更しない。変更対象はcurrent rendered projectionのみ。

## Deliberate zoom-out

Semantic zoom-out thresholdを:

- before: 0.82
- V49.6: 0.70

へ変更する。

0.82〜0.71は同じsemantic level内のcamera zoomとして扱う。

これにより「少し縮小しただけで全体へ戻る」挙動を避け、階層を戻すには明確に縮小する必要がある。

Map camera minimum 0.68は維持するため、0.70は意図的なcollapse gestureとして到達可能。

## Semantic capability

Scene Nodeへ:

```text
data-map-semantic-capability="expand | detail | none"
```

を付与する。

### expand

- non-leaf
- direct navigation kind = zoom-in
- Semantic Zoom対象

### detail

- presentation.kind = leaf
- Palette / Context Surfaceを開く
- Semantic Zoom対象外

### none

- direct / satellite / static等でSemantic Zoom対象外

runtimeのzoom-in target探索でも `expand` だけを候補にする。

## Mobile / PWA

Mobileでもleaf/detail分離とparent recedingは共通。

child visual scaleはmobileで0.84とし、既存mobile layout / fit logicは維持する。

semantic open threshold 1.42は変更しない。

zoom-out thresholdだけ0.70へ共通変更する。

## Persistence

追加永続化なし。

runtime / DOM classのみ:

- semantic capability
- expanded parent visual class
- expanded child visual class

DB / sessionStorage / Telemetry schemaの変更なし。

## Tests

### JS

- 0.82 zoom-out -> no semantic navigation
- 0.71 -> no semantic navigation
- 0.70 -> zoom-out

既存open thresholds:

- mobile 1.42
- desktop 1.46

は維持する。

### Feature

Execution leaf Taskについて:

- `data-map-semantic-capability="detail"`
- descendantに `data-map-semantic-zoom` が存在しない
- Palette detailは従来通り開ける

## Non-goals

- Single-Surface Architecture
- parent NodeのDB非表示化
- canonical Node size mutation
- nested ancestor stack persistence
- spring / inertia
- gesture physics全面再設計
- detail Surface redesign

V49.6は現Projection Architectureのまま、Semantic ZoomとDetail interactionの責務を明確に分離する。

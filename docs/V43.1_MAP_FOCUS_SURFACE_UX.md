# V43.1 Focus / Context Surface UX

## Goal

MobileでFocusした時に、選択NodeとBottom Sheetが画面下半分を取り合う状態を避ける。

Nodeを選ぶ → 関係を見る → 必要な操作を開く、の流れでMapを見失わないことを優先する。

## Mobile focus safe area

DesktopのFocus配置は変更しない。

MobileではFocus layoutを別計算する。

- selected node: y=34
- future: y=14
- past / other: y≈60-62
- input / action: y≈34

Bottom Sheetが下部を占有しても、選択Nodeと主要な1-hopが上側へ残る。

SVG Edgeも同じ座標へ更新するため、NodeだけCSSでずらす方式は使わない。

## Context Surface sizing

Mobile Bottom Sheetは初期状態をcompactにする。

- compact: max 34dvh / 18rem
- expanded: max 64dvh / 34rem

headerの「広げる / 縮める」で切り替える。

Focus自体は維持されるため、Surfaceを縮めてもMap Contextは失われない。

新しいNodeをFocusした時はcompactへ戻す。

## Close semantics

- ×: Focusを閉じる
- Escape: Focusを閉じる
- browser Back: Focus historyを戻す
- 全体を見る: Focusを閉じる
- 広げる / 縮める: Focusは維持

閉じる操作とSheet size操作を分離する。

## Accessibility

- selected Nodeへ aria-selected / aria-expanded
- Context Surfaceへ aria-label
- size toggleへ aria-expanded
- reduced motionではSheet height transitionを無効化

## Boundaries

変更しない:

- Primary Action selection
- Map Projection
- Classic Surface actions
- Companion
- Living Reevaluation
- Telemetry semantics
- no-JS href fallback

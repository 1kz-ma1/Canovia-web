# V44.1 L0 Intent Hub

## Goal

Canovia Mapの既定入口を、V43までの「おすすめCurrent Task中心のExecution Map」から、
Canovia全体の情報・機能へ辿るためのL0 Intent Hubへ変更する。

V44.0で分離した:

- Navigation Graph
- Attention State
- Map Level
- L3 Execution Projection

をそのまま利用し、L0専用のGraph / Attention / Projectionを追加する。

## L0 fixed structure

L0はRecommendation結果から生成しない。

常に次の5 Nodeを持つ。

- 中央: Space Station
- 計画
- 実行
- 振り返り
- 共同

原則:

> おすすめだからNodeが存在するのではない。おすすめだから目立つ。

V44.1ではPersonalized Satelliteはまだ追加しない。
L0固定NodeだけでNavigation Layerとして成立させる。

## Space Station

V44.1ではSpace Stationの「場所」を先に確立する。

既存機能への入口:

- Inbox
- AI Chat

をContextual Classic Surfaceに集約する。

V44.2で追加するもの:

- Capture
- screenshot / external information intake
- content interpretation
- Context routing candidate
- user confirmation
- Companion integration as a central hub

そのためV44.1では自動MutationやContext routingは行わない。

Space StationはMap中央に固定するが、RecommendationのPrimary Nodeではない。

- `center_node_id = intent:space-station`
- `primary_node_id = null`

とし、「中央にある = 今おすすめされている」を意味させない。

## Intent Nodes

### 計画

既存:

- My Plans
- Plan creation

への入口。

将来L1/L2へSemantic Zoomする前のDomain entryとして扱う。

### 実行

V43までのExecution Mapへ接続する。

`/map?level=l3`

L3は削除・再実装せず、そのまま再利用する。

### 振り返り

既存:

- Timeline
- Achievements

への入口。

Evidence / 実績 / 過去のContextはL0で独立Nodeを増やさず、このIntent内部へ集約する。

### 共同

既存の共同Planへ辿る入口。

V44.5で:

- Shared Plan
- members
- GitHub
- review待ち
- 相手待ち
- 自分のnext action

などをCanoviaの目的ベース表現へ再投影する。

## Architecture

### IntentNavigationGraphService

L0のsemantic graphだけを構築する。

持つもの:

- Node identity
- Node type
- label / subtitle
- canonical action
- Contextual Classic Surface
- semantic edge

持たないもの:

- position
- size
- importance
- state
- edge strength

DashboardGuidanceServiceは参照しない。

### IntentMapAttentionStateService

L0の固定Spatial Grammarを投影する。

- Space Station = center
- Plan = upper-left
- Execution = upper-right
- Reflection = lower-right
- Collaboration = lower-left

V44.1では固定Attention presetを利用する。

Recommendation / usage / urgencyによる動的Attentionは後続Versionで追加する。

### IntentMapProjectionService

L0 composer。

1. semantic Navigation Graph
2. Attention State
3. direct navigation
4. projection key

を合成する。

### MapProjectionService

V44.1以降:

- L0 Intent -> IntentMapProjectionService
- L3 Execution -> ExecutionMapProjectionService

をrouteする。

`build()` はCompanion等の後方互換APIとしてL3を返し続ける。

### CanoviaMapController

public `/map`:

- default = L0
- `?level=l3` = L3 Execution

L1/L2はまだ公開しない。

## Spatial Memory

V44.1ではL0の固定配置だけを導入する。

Focus時も既存Living Map Engineを再利用し、

- Plan = Future方向
- Execution = Action方向
- Reflection = Past方向
- Collaboration = Input側
- Space Station = Center

として既存one-hop Focus layoutへ接続する。

本格的なLevel間Semantic ZoomとDock継承はV44.3で実装する。

## Visual grammar

L0では宇宙モチーフを情報構造として使う。

- Space Station: 中央Hub、円形、大きい
- Intent: planet / moon風の円形Node
- orbit: hierarchy / belonging
- constellation edge: Space Stationとのsemantic relation
- glow: Attention

V44.1ではRocket / Personalized Satellite / future dashed objectはまだ追加しない。

## Classic Surface boundary

L0 Nodeを選択すると既存Contextual Classic Surfaceを利用する。

複雑な操作は既存画面へ遷移する。

Map内Mutationは追加しない。

L0ではContextual Companion formをまだ表示しない。
Space StationとCompanionの統合はV44.2で扱う。

L3 Companionは従来どおり維持する。

## Living Reevaluation

L3:

既存V42.2 semanticsを維持する。

L0:

Level navigation自体はMutationではないため、
L0 -> L3の遷移ではpending reevaluationを作らない。

Inbox / Plan等のClassic Surfaceへ移動した場合は従来どおりpending reevaluationを利用できる。

## Telemetry

既存Map telemetry event typeを再利用する。

新しいsafe structural metadata:

Node type:

- `space_station`
- `intent`

position role:

- `space-station`
- `intent-plan`
- `intent-execution`
- `intent-reflection`
- `intent-collaboration`
- `intent-context`

user text / title / contentは保存しない。

## Compatibility

削除しないもの:

- Classic Home
- V43 L3 Execution Map
- Focus Mode
- Contextual Classic Surface
- Living Reevaluation
- L3 Companion
- Primary Action direct launch
- non-Primary direct navigation
- no-JS fallback
- existing Map telemetry

V42〜V43 regression testは`?level=l3`へ明示的にscopeし、旧機能の維持を検証する。

## Non-goals

V44.1では以下をしない。

- L1 / L2 UI
- Semantic Zoom animation
- Space Station routing intelligence
- auto mutation
- Personalized Satellite
- usage-based promotion
- GitHub integration
- Graph DB
- absolute position persistence
- AI layout
- user content telemetry

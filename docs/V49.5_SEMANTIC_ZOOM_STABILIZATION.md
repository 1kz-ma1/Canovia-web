# V49.5 Semantic Zoom Stabilization

> **V49.6 update:** Semantic ZoomをContainer Nodeの具体化に限定し、leaf Nodeはdetail-firstへ固定した。arrival後のparentは半透明・縮退してcontextへ退き、childrenは一段小さいvisual scaleで展開する。zoom-out thresholdは0.82から0.70へ下げ、軽い縮小では階層を戻さない。詳細は `docs/V49.6_SEMANTIC_EXPANSION_CLARITY.md` を参照。

## 目的

V49.4でcamera zoom / semantic selection分離、LOD、screen-space Node sizingを導入した。

残る操作不安定要因は:

- ready / open境界付近でtargetが点滅しやすい
- pinch midpointが移動すると、地図上の注視点が少しdriftする
- In-place Expansion後、Node数やcard size次第でchild同士が重なる

の3点。

V49.5ではSingle-Surface移行前のgesture stabilizationとして:

1. semantic arm hysteresis + dwell
2. fixed world-anchor pinch
3. local collision resolution

を追加する。

## 1. Semantic Arm Hysteresis

### Desktop

V49.4:

- ready: scale >= 1.34
- semantic open: 1.42

V49.5:

- ready表示: >= 1.34
- candidate dwell: 120ms
- semantic open: >= 1.46
- armed release: < 1.28

Desktopではpinch focusが同じzoomable Node近傍に120ms留まった場合だけarmedにする。

```text
1.34到達
  -> ready LOD

同じNodeを120ms狙う
  -> armed

1.46到達
  -> semantic expansion
```

armed後はscaleが1.34を少し下回っても即解除しない。

```text
armed
1.34 -> 1.31 -> 1.30
  -> armed維持

1.28未満
  -> release
```

これによりthreshold付近のfinger jitterでglowが点滅しない。

### Candidate change

pinch focusが別Nodeへ移った場合:

- previous armed解除
- dwell timer reset
- 新Nodeで120ms再計測

### Desktop open threshold

Desktop semantic openだけ1.46を使用する。

Mobile / PWAは既存の1.42を維持する。

## 2. Fixed World-Anchor Pinch

### 問題

従来のtouch pinchは:

1. gesture開始midpointでzoom transform計算
2. current midpointとの差をpanとして加算

していた。

数学的には近いが、scale clamp / pan clamp / frame timingが別々に適用されるため、gesture中に注視点がdriftする余地があった。

### V49.5

gesture開始時に:

> 指の中点の真下にあるMap world coordinate

を1回だけ計算する。

```text
world_x = (screen_x - camera_x) / scale
world_y = (screen_y - camera_y) / scale
```

各pointer moveでは:

- target scale
- current midpoint
- fixed world anchor

からcamera x/yを直接逆算する。

```text
camera_x = current_screen_x - world_x * target_scale
camera_y = current_screen_y - world_y * target_scale
```

これにより2本指中点が移動しても、同じworld pointが現在の指中点の下に残る。

Desktop precision pinchも同じworld-anchor helperを利用する。

### Clamp

Map boundary clampが必要な場合のみanchor preservationよりboundary safetyを優先する。

## 3. Local Collision Resolution

### Scope

collision resolverは全Mapへ常時適用しない。

対象:

> In-place Semantic Expansion後のcurrent child projectionのみ

L0 / normal constellation / fixed Intent placementには適用しない。

### Input

current expanded Nodesについて:

- x/y %
- rendered card width/height
- current counter-scale
- viewport size

を使う。

### Parent lock

selected semantic parent:

`semanticExpansionLayoutState.anchorId`

はlocked nodeとする。

collision resolution中も絶対に移動しない。

これは:

> 箱を開いたら親箱が別の場所へ逃げる

状態を防ぐため。

### Child displacement

overlapしたpairだけ:

- x overlap
- y overlap

を計算し、必要移動量の小さい軸へ押し広げる。

両方childなら半分ずつ動かす。

片方がlocked parentならchildだけ全量動かす。

### Defaults

Desktop:

- padding: 18px
- iterations: 6
- viewport boundary: 8px

Mobile:

- padding: 10px
- iterations: 6
- viewport boundary: 4px

Node数が少なく衝突しない場合、canonical expanded positionを変更しない。

## 4. Runtime State

追加runtime state:

- semantic arm candidate id
- semantic arm candidate since

永続化しない。

既存:

- semantic armed Node
- semantic expansion layout state
- camera

と同様current Map runtimeだけ。

## 5. Interaction Contract after V49.5

### Desktop pinch

```text
pinch on blank
 -> camera only

pinch near Node
 -> camera
 -> ready
 -> same target 120ms
 -> armed
 -> scale 1.46
 -> open in place
```

### Mobile / PWA

- pinch behavior remains
- open threshold 1.42
- fixed world anchorだけ共通改善

### Click / tap

explicit semantic selection。

dwell / 1.46 gateは要求しない。

### +/- and double click

camera only。

## 6. Validation

Pure helper validation:

### Hysteresis

- scale 1.36 / 80ms -> false
- scale 1.36 / 140ms -> true
- armed / scale 1.30 -> true
- armed / scale 1.24 -> false

### Thresholds

- mobile 1.42 -> in
- desktop 1.44 -> none
- desktop 1.46 -> in

### World anchor

1000x800 viewport:

- original screen point: 700,300
- zoom後reconstructed: 700.00004, 300.00004

誤差0.001px未満。

### Collision

selected parent:

- before 50,50
- after 50,50

child only outward displacement。

## 7. Persistence / Telemetry

新規:

- DB persistenceなし
- sessionStorage persistenceなし
- Telemetry fieldsなし
- migrationなし

gesture dwell timeやcollision coordinatesを保存しない。

## 8. Non-goals

- Map Single-Surface Architecture
- inertia / momentum
- spring physics
- global force-directed layout
- canonical Node coordinate mutation
- camera persistence
- AI collision / gesture inference
- mobile semantic selection contract変更

V49.5は現在のProjection Architectureで可能なgesture stabilizationを完了させる段階とする。

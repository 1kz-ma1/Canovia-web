# V58.65 — OverviewのRelevant-onlyな表示

## Context

Overviewの初期実装はStudy/Development/CareerのSummaryを3件常に描画し、実際に利用していないCareer、Inbox 0件、重要な変化0件でも大きな空カードを表示した。Global Current ActionとModeのCurrent Actionも重複し、未測定のReadinessが目立つ状態になっていた。

## 実装ルール

- Mode Summaryは**現在のアクターがアクセスできるPlanを持つものだけ**表示。未使用ModeはMode switcherと初回ユーザー向けの`CHOOSE A WORKSPACE`に残し、Overviewの常設カードにはしない。
- 該当するPlanがない場合はMode Summaryのセクション・ナビゲーションアンカーを表示しない。
- 未整理Inboxが**1件以上**の時だけInboxカードとアンカーを表示。重要な変化も**1件以上**の時だけChangesカードとアンカーを表示。両方0ならセクション全体を省略する。
- 初回でまだPlanがない場合はMode選択案内を優先し、空のGlobal Current Actionカードを表示しない。
- Global Current Actionに対応する測定可能なReadinessのスコアがまだない場合、`未判定`とGapだけの**独立したReadinessカードを描画しない**。GlobalのAction自体は存在すれば表示する。
- Planはあるが観測EvidenceがまだないModeは、**そのPlan名とWorkspaceリンク**だけでも意味があるためカードを維持。未測定のReadinessスコアや「リリースセットアップ中」といった断定を避け、現況確認を案内する。
- 同じPlan・Domain・Action kindがGlobalに表示されている場合、Study公式シラバスの設問・Mode内のActionタイトルを**繰り返さない**。
- 権限外のPlan/Inbox情報を表示しない。実際のPlan/Taskに書込みを伴わない。新規の学習・開発・Career判断モデルは導入しない。

## 検証

`OverviewWorkspaceV545Test`, `OverviewRelevanceV5865Test`, `OfficialExamScopeAwareStudyV5864Test` により、初回利用、Studyだけ、複数Mode、他人の非公開Plan、未整理Inboxの件数と所有者スコープ、未観測Readiness非表示、重複Action非表示を検証。

後続P0.4の計画導線改修とP1.3のスポットライト実装時にも、Overviewの**関連性フィルタはデフォルト維持**とする。

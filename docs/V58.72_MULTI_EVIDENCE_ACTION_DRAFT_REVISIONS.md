# V58.72 Multi-evidence Plan Draft / explicit revision preview

## Status
V58.71 extended; P1.2 remains **IN PROGRESS**, not production verified.

### Inputs / boundaries
- Owner may choose 2–5 existing WorkLogs of the **same Plan** to compose a
  proposed next-action review. Also works for the existing one-source V58.71 draft.
- The source is an immutable snapshot of each log's task title / recorded outcome,
  with the original work_log_id and activity date. The log might later be edited
  or deleted; the draft retains what it observed *at proposal time*.
- WorkLogs are user-entered records, **not** proof of objective mastery or
  verified provider Evidence. Proposal text is a transparent deterministic
  comparison prompt; it never asserts inferred strengths, weakness or causality.
- Another Plan's source log ID is 404. Duplicate/empty/malformed selections
  are rejected before mutation. Cap 5 sources per draft.
- Owner may add unused WorkLogs to a **proposed** draft; preview is read-only
  and displays before/after candidate and newly added source records.
- Apply requires same status, revision, current candidate fingerprint, and
  evidence fingerprint as the preview. This avoids clobbering human edits and
  silently switching changed evidence. DB transaction + lock + unique revision
  key make stale retries safe. The ledger persists the before/after and added
  source snapshots. Dismissed/accepted drafts are immutable.
- No existing Plan/Task or progress is changed by composition, preview, apply.
  Task creation remains V58.71 owner acceptance only. Authorization remains
  owner-only even in collaborative Plans.
- No AI calls and no cost, no feature/release level changes.

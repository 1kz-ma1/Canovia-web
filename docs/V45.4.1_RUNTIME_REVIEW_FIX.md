# V45.4.1 Runtime Review Fix

## Purpose

V45.4 merge後にMap Runtimeをコードレビューし、
テスト成功だけでは拾いにくい状態不整合・操作上の違和感・描画コストを補正する。

新機能は追加しない。

## Findings and fixes

### Focus / Space Station Dock exclusivity

Problem:

Node Focus中にSpace Station Dockを開くと、
SurfaceはDockへ切り替わる一方で`activeFocusId`が残る経路があった。

これによりruntime上:

```text
activeFocusId != null
activeDockId != null
```

になり得た。

Fix:

Dockを開く前にFocusをclearする。

逆方向は既存どおり、
Focusを開く前にDockをclearする。

したがってContext stateは常に排他的になる。

```text
Focus XOR Dock
```

Browser backで以前のFocus entryへ戻った場合は、
popstateからFocusを再構築する。

### Dock history state

Problem:

FocusからDockへpushStateすると、
既存history stateをspreadしていたため
`canoviaMapFocus` IDがDock entryにも残っていた。

Fix:

`mapDockHistoryState()`で:

- canoviaMapFocusを削除
- canoviaMapDockを設定
- canoviaMapFocusDepthは維持

する。

Depthを残す理由はBack/Forward telemetryの階層判定を壊さないため。

### Mobile Node switch

Problem:

Mobile stable selectionでNode AからNode Bへ切り替えるたび、
全Nodeへclass / aria / focus CSS property更新を行っていた。

Fix:

Mobile selectionへ最初に入るときだけ全Nodeをnormalizeする。

以後の切替は:

- previous selected node
- next selected node

だけを更新する。

同じNodeを再タップし、
Context Surfaceが既に開いている場合はSurface cloneも行わない。

Desktop one-hop Focusは全Node visibilityが変わるため従来処理を維持する。

### Manual gesture priority

Problem:

Zoom / Reset animationのRAF commitがpending中に
ユーザーがMapへ触れた場合、
logical Map stateと画面commitのタイミングが一瞬ずれる可能性があった。

Fix:

最初のpointerdownで:

1. pending Map frameをflush
2. view animation timerを停止
3. animation classを解除
4. viewport geometryをrefresh
5. manual gesture開始

とする。

ユーザーの直接操作をcosmetic animationより優先する。

### Backdrop blur during gesture

Problem:

Fullscreen Top BarとGesture Controlsには
backdrop-filter blurがあり、
背後のMap Sceneが移動するたびにbackdrop再計算が発生し得る。

Fix:

Gesture中だけMap Pageへ
`is-map-gesture-active`
を付ける。

Gesture中:

- Top Bar backdrop blur off
- Gesture Controls backdrop blur off
- Top Bar shadow simplified

pointerup / cancel / destroyでclassを解除し、
静止時Visualへ復帰する。

### Decorative glyph tooltip

Problem:

V45.3 Glyphは`aria-hidden=true`の装飾なのに、
英語のPresentation labelを`title`へ持っていた。

これによりhover時だけ
"Current Action Rocket"等の内部Visual Grammar名が表示された。

Fix:

decorative Glyphからtitleを削除。

不要になった
`MapNodeVisualGrammar::label()`
も削除する。

Node semanticsは既存label / eyebrow / actionで伝える。

### Stale DOM query

V45.1でClose処理をdelegated clickへ移した後に残っていた
unused `closeButton` queryを削除した。

### Mobile spatial aspect ratio

Problem:

V45.0ではMobile CanvasへNodeを収めるため、
L0/L1/L2のpositionをx/yともpercentageで固定していた。

縦長Viewportでは同じpercentageでも実pixel距離が異なる。

例:

```text
390 x 700 viewport

x 23% = 約90px
y 21% = 約147px
```

そのためsemantic上は同じringでも、
画面上では縦方向へ引き伸ばされて見えていた。

Fix:

`buildMobileBaseLayout()`へ実Viewport width / heightを渡す。

Ring radiusをpixelで決めてから:

- x percent = radius / viewport width
- y percent = radius / viewport height

へ別々に変換する。

これによりL0 Intent / Satellite ring、
L1/L2 hierarchy orbitはrendered pixel上でほぼ同じ半径になる。

Server / Desktop attention coordinatesは変更しない。

### Mobile Node proportions

Fullscreen + Pan/Zoom導入後は、
すべてのNodeをPhone widthへ押し込む必要がない。

Mobile Node shellをsemantic shapeごとに再定義する。

- Space Station: 1:1
- Intent Planet: 1:1
- Personalized Satellite: 約1.38:1
- Hierarchy child: 約7.5rem × min-height 4.9rem
- Hierarchy parent: 約8.4rem × min-height 5.6rem
- Execution:既存weightを維持しつつminimum widthを少し広げる

Planet / Stationは円形そのものが意味を持つため1:1を維持する。

Satellite / hierarchyは文字情報とVisual Grammarを読みやすくするため
横方向を優先する。

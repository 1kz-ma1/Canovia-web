# V58.20 Release Level Foundation

## Goal

Early Accessへ向けて、既存Feature Flag / Entitlementを置き換えず、その上に整合済みProduct構成としてRelease Levelを実装する。

Canonical product contract:

- `docs/CANOVIA_RELEASE_LEVEL_SPEC.md`
- `docs/CANOVIA_MONETIZATION_SPEC.md`

## Scope

V58.20で実装する:

- ReleaseLevel enum
- public release level config
- Super Admin専用release preview session
- user-specific release level override
- ReleaseLevelService
- release-level route middleware
- WorkspaceModeRegistryとの接続
- CareerをLevel 3 Beta Expansionとして段階公開
- Admin settingsからpreview level変更
- Economy Inspectorからuser level変更
- regression tests

## Compatibility

Deploy直後のDefault Public LevelはLevel 4 Internal Previewとする。

理由:

> Foundation導入だけで現在利用可能な画面を突然隠さない。

Early Access準備が整った時点でenvironment:

```text
CANOVIA_PUBLIC_RELEASE_LEVEL=1
```

または:

```text
CANOVIA_PUBLIC_RELEASE_LEVEL=2
```

へ下げる。

## Boundaries

```text
Feature Flag
= individual runtime switch

Release Level
= coherent product maturity surface

Entitlement
= paid/access right

Ownership
= resource authorization
```

互いを統合しない。

## Initial Workspace minimum

```text
Overview     0
Study        1
Development  1
Career       3
```

CareerのPlan data自体は削除しない。
Level 3未満では専用Workspaceへのpublic entryを止め、Overviewへフォールバックする。

## Admin preview

Existing Free / Premium preview:

> entitlement / plan experience preview

V58.20 release preview:

> product maturity / publication preview

別Session keyで保持し、同時利用可能とする。

## User override

Userごとにnullable `release_level_override` を持つ。

- null: Public Level継承
- 0-3: explicit staged access
- 4: User override不可

Internal PreviewはSuper Admin previewだけに限定する。

## Route safety

Career専用GETはLevel不足時にOverviewへ戻し、Beta準備中を表示する。

Career mutationはLevel不足時404として実行しない。

## Non-goals

V58.20では実装しない:

- Public LevelのDB管理
- automatic promotion
- percentage rollout
- Premium / Pro runtime migration
- Pricing UI
- Career UI完成
- Level 1 / 2の全Feature inventory確定

# V58.26 Capability Activation Foundation

## Goal

V58.25 Personalization Bootstrapで得た:

```text
Need
→ Value Preview
→ Interest
```

を、実際のCapability利用まで安全に接続する。

Phase 2 contract:

```text
Need
→ Preview
→ Interest
→ Readiness
→ Setup
→ Completed
```

GitHub Integrationを最初の実例とする。

## Scope

V58.26で実装する:

- generic `CapabilityActivationService`
- setup lifecycle state persistence
- setup started / completed / abandoned telemetry
- Development Workspace guided activation card
- GitHub readiness owner / next action表示
- exactly-one Repository auto-candidate
- existing GitHub Workflowへのhandoff
- connected stateのobserved_context記録
- Release Gate contract
- tests

実装しない:

- GitHub接続処理の再実装
- automatic GitHub App install
- Repositoryの勝手な選択
- multi-capability catalog
- AI inference
- Phase 3 Living Profile update engine


## Source provenance

```text

```

```text

```

Actual connected fact:

```text

```

Phase 3でContext Update Candidateを作るための観測事実として保持するだけ。

## Guided readiness

Development WorkspaceでCapability Activation cardを表示する。

表示対象:

- interest = yes
- eligible + interest未回答
- setup進行中
- connected

非表示:

- interest = no
- abandoned
- unrelated actor

Steps:

```text
Need
Preview
Interest
Readiness
Setup
```

各stepは現在地を示すだけで、完了を強制しない。

Examples:

```text
READY
```

既存 `GitHubIntegrationReadinessService` /

## Repository candidate

Plan内のGitHub Repository Artifact:

### 0件

Repository登録へ誘導。

### 1件

候補として自動選択。

```text
repository_auto_candidate = true
```

ただしGitHub接続自体は自動実行しない。

### 2件以上

自動選択しない。

既存GitHub Workflowで対象を選ぶ。

## Setup lifecycle

### start

```text
POST /capabilities/github_integration/plans/{plan}/setup/start
```

条件:

- auth
- L1+
- editable Development Plan
- GitHub capability access
- GitHub interactive runtime ready
- interest=yes

実処理:

- activation.stage = setup_started
- candidateを記録
- telemetry
- existing GitHub Workflowへredirect

### abandon

```text
POST /capabilities/github_integration/plans/{plan}/setup/abandon
```

- activation.stage = abandoned
- Development自体は継続可能
- activation cardは常駐させない
- interest回答は書き換えない

### completed

既存GitHub接続が:

```text
connection state = ready
```

になった事実をDevelopment Workspaceで検知する。

Then:

- activation.stage = completed
- observed_contextへconnected fact
- capability_setup_completed telemetry
- self_reported contextは維持
- Guidanceは自動変更しない

## Telemetry

Server-side:

- capability_setup_started
- capability_setup_completed
- capability_setup_abandoned

Metadata:

- capability
- repository count
- auto candidate
- repository artifact id

Repository URLやuser free textは送らない。

## Security

- auth required
- Plan edit authorization
- Development Plan only
- unsupported capability key -> 404
- runtime/access gate before lifecycle start
- server-side observed connection only
- automatic external installなし

# V56.3 Question Exposure Rotation

## Goal

V56.3 improves Question Bank repetition control before expanding the official AP corpus further.

V56.2 made authentic IPA questions the preferred source when coverage is sufficient.
V56.3 makes the selector use that corpus more evenly so General Practice / Exam Mode
does not fall back into the same short sequence after several 10-question blocks.

The authority boundary stays unchanged:

```text
V56.0 Study Phase / Weakness Policy
→ Question Mix / focus buckets
→ V56.2 Pack coverage + priority
→ V56.3 deterministic exposure rotation inside the selected Pack
→ Canovia Core / Native AI only when coverage requires fallback
```

AI is not used to decide repetition or question order.

## Current problem

Before V56.3, Question Bank repetition avoidance is:

```text
same Plan + same Task
→ latest 8 StudyPracticeSessions
→ question_id is recent / not recent
```

That leaves three problems.

1. Practice history on another Task in the same qualification Plan is ignored.
2. Repetition is binary; one prior exposure and many prior exposures are treated the same.
3. Once most or all questions in a small Pack are marked recent, deterministic ordering can
   return to `sort_order` and create a familiar repeated sequence.

This matters immediately for the first IPA official Pack because it has 35 curated questions
and Canovia currently uses 10-question General / Exam blocks.

## Scope

V56.3 changes Question Bank ordering only.

It does not change:

- V56.0 phase selection
- weakness confirmation / graduation / re-entry
- Question Mix quotas
- domain round-robin
- Pack coverage
- Pack `selection_priority`
- official → Core → AI fallback
- grading
- Question data
- database schema

## Plan-wide exposure memory

Question exposure is derived from durable `StudyPracticeSession.selected_questions`.

The selector reads a bounded history for the current Plan, regardless of Task.

Initial defaults:

```text
exposure_history_session_limit = 24
recent_session_window = 3
```

These values are selection-policy defaults, not learning-science constants.

A question exposure record contains:

- `exposure_count` within the bounded history
- `last_seen_session_offset`
  - 0 = latest prior Session
  - larger = older
  - null = unseen in the bounded history
- `recent`
  - true when seen within the latest `recent_session_window` Plan Sessions

Only selected questions with a real Question Bank `question_id` contribute.
Native/external generated items with null question IDs are ignored.

## Selection precedence

Existing bucket authority remains first.

```text
Primary quota
→ Secondary quota
→ Diagnostic quota
→ balanced fill when bank-only mode requires it
```

Within each topic/domain group, candidates are ranked by:

1. not seen in the recent Plan-wide window
2. lower exposure count
3. longer time since last exposure
4. stronger focus score when a focus score applies
5. existing difficulty preference
6. `sort_order`
7. question id

This is a preference, not a hard exclusion.

If a narrow weakness bucket does not contain enough fresh questions, previously seen questions
remain eligible so reinforcement can still satisfy the requested Question Mix.

## Broad-practice behavior

For General Practice / Exam Mode, focus buckets are empty and the existing diagnostic
domain round-robin remains active.

Expected behavior with a 35-question official Pack and 10-question blocks:

```text
Block 1 → mostly unseen questions
Block 2 → prefer questions not used in Block 1
Block 3 → prefer questions not used in Blocks 1–2
Block 4 → consume remaining unseen questions first, then the least-exposed / oldest questions
later blocks → rotate by exposure count and recency instead of resetting to the same sort order
```

The selector does not promise zero repetition when the corpus is smaller than accumulated demand.

## Weakness Reinforcement behavior

Weakness matching still constrains the eligible pool before exposure ordering.

Therefore:

```text
confirmed DNS weakness
→ DNS-matching questions remain the eligible focus pool
→ fresh DNS questions are preferred
→ repeated DNS questions are allowed when needed
```

V56.3 must not weaken V56.0's bounded reinforcement / graduation policy.

## Durable selection metadata

New Question Bank selections keep the existing provenance fields and additionally persist
selection exposure diagnostics in `selected_questions`:

- `selection_exposure_count`
- `selection_last_seen_session_offset`
- `selection_recent`

Provider payload also exposes the bounded rotation settings and number of history Sessions considered.

This is diagnostic state only. It is not a new mastery signal.

## Selector version

Question Bank selector version changes from:

```text
bank-v2-balanced
```

to:

```text
bank-v3-exposure
```

Historical Sessions keep their stored selector version unchanged.

## Compatibility

No migration is required.

Historical `selected_questions` without the new exposure fields remain valid because V56.3 derives
new exposure state from `question_id`, which already exists for Question Bank selections.

Hybrid sessions also contribute when their `selected_questions` contain real Question Bank IDs.

## Tests required

V56.3 must verify:

1. a Question Bank Session on another Task in the same Plan affects the next selection
2. fresh questions are preferred over recently exposed questions when enough coverage exists
3. when every candidate is recent, lower exposure count wins
4. when exposure counts tie, the question seen longer ago wins
5. selector version is `bank-v3-exposure`
6. existing Primary / Secondary / Diagnostic quotas remain valid
7. existing domain round-robin remains valid
8. V56.2 official Pack priority and Core fallback remain valid
9. Hybrid Question Assembly remains valid
10. V56.0 General / Exam behavior remains valid

## Definition of Done

V56.3 is complete when:

1. repetition memory is Plan-wide rather than Task-local
2. the selector distinguishes frequency and recency of prior exposure
3. broad practice rotates through a finite official corpus without repeatedly resetting to the same sequence
4. narrow weakness practice can still repeat questions when coverage requires it
5. no database migration or AI selector is introduced
6. specification, selector metadata, and tests agree

## Non-goals

V56.3 does not add:

- another official AP year
- full 80-question official import
- diagram/image question support
- full-length timed mock exams
- spaced-repetition scheduling
- per-question mastery state
- persistent lifetime exposure counters
- AI-selected repetition policy

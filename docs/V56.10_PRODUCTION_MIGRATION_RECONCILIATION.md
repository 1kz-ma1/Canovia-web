# V56.10 Production Migration Reconciliation

## Goal

Finish recovery of the production migration ledger after Render exposed more than one physically-created table whose Laravel migration record was missing.

## Incident progression

The production database drift is not isolated to one table.

Observed in Render:

1. `intelligence_decision_traces` already existed while migration `2026_10_04_000200` was pending.
2. After V56.8 safely reconciled that migration, the next pending migration exposed the same condition for `intelligence_reasoning_runs`.
3. A separate transient Aiven communication timeout was handled by V56.9.

This indicates historical deploy interruption left multiple DDL operations applied while Laravel did not persist the corresponding migration-ledger row.

## Recovery policy

All migrations introduced after the first observed drift point are made safely re-runnable.

For create-table migrations:

- if the table does not exist, create it exactly as before
- if it exists, compare its columns with the migration's expected column contract
- accept only a complete existing table
- fail loudly when an expected column is missing

For add-column migrations:

- add the column only when it is absent
- leave an already-existing column untouched

For the two-table Study Scope migration:

- validate each existing table independently
- create only the missing table
- this allows recovery from a migration interrupted between the two CREATE TABLE statements

## Safety invariants

V56.10 does not:

- drop production tables
- delete or rewrite production rows
- mark a partial table as complete
- bypass Laravel migrations
- alter fresh-install schema definitions
- change feature semantics

The existing V56.9 bounded retry remains responsible only for transient database connectivity failures. Deterministic schema mismatches still fail immediately.

## Validation

Validation must cover:

- fresh migration chain
- re-running every covered migration against a fully-applied schema
- recovery of a partially-applied two-table Study Scope migration
- V56.9 startup retry
- V56.8 migration recovery
- Intelligence, Action Home, and Workspace regressions

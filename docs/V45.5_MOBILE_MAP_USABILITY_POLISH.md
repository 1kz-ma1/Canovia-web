# V45.5 Mobile Map Usability Polish

## Goal

V45.4.1以前のスマホ実機動画をレビューし、
「Mapとしては動くが、情報密度・Node衝突・Chromeの主張が強い」状態を改善する。

対象:

- L3 Execution node collision
- Mobile axis label clutter
- Node内small action pill
- Top Bar density
- Zoom controls footprint
- Context Surface initial height
- Bottom Sheet drag-handle ambiguity
- Space Station capture density
- Spatial Dock footprint
- Semantic Zoom loading continuity

Navigation Graph / Attention State / canonical dataは変更しない。

## L3 mobile execution layout

V45.4.1まではL3のみServer projection coordinatesをそのままMobileでも使用していた。

Nodeを自然な横長比率へ戻した結果:

- Primary Action
- Tool
- Inbox

が近接し、動画ではPrimary ActionとToolが重なっていた。

V45.5ではMobile L3をrole-based fixed slotsへ再投影する。

390x700相当:

- Goal: upper center
- Plan: upper left
- Next Task: upper right
- Primary Action: center
- Inbox: far left
- Tool: far right
- Evidence: lower center

Primary ActionからTool / Inboxまで約152pxのhorizontal distanceを確保する。

Server / Desktop coordinatesは変更しない。

## Axis labels

Mobile L3では:

- FUTURE
- PAST
- INPUT
- ACTION

の常時表示を隠す。

方向文法はNode placementそのもので維持する。

Desktopでは従来どおり表示できる。

## Node content density

MobileではMap上に詳細を詰め込まない。

非External Nodeのsmall direct-open pillを非表示にする。

Node body tap:

```text
Node
  -> Context Surface
  -> canonical action
```

を基本とする。

External Toolは遷移先がCanovia外であることを明示するため、
external actionだけ残せる。

Node subtitle / Contextを見る micro-copyはMobile Map上では非表示。

完全な情報はContext Surfaceで表示する。

## Top Bar

Mobile Fullscreen Top Barはさらにcompact化する。

- kicker非表示
- current context titleは1行ellipsis
- Classic / Map switcherを小型化
- L0-L3 depth dotsは非表示
- breadcrumbを優先

Hierarchy自体やSemantic Zoom URLは変更しない。

## Gesture controls

縦3段:

```text
-
reset
+
```

から小型横並びへ変更する。

Map viewportの右上を大きく占有しないことを優先する。

Pan / Zoom bounds自体は変更しない。

## Context Surface

Mobile default:

- max 38dvh / 21rem

Expanded:

- max 76dvh / 40rem

へ変更する。

Mapの位置感覚を残したまま概要を確認し、
必要なときだけ「広げる」で詳細を見る。

以前のdecorative drag handleは、
実際のdrag interactionがないのにSwipe可能に見えるため非表示にする。

Close / Expand buttonは維持する。

## Space Station density

Captureのprimary pathはText input。

URL / Screenshot / PDFは:

`URL・スクリーンショット・PDFを追加`

detailsへ折りたたむ。

入力済み / validation error時は自動open可能。

canonical Inbox capture behaviorは変更しない。

## Spatial Dock

Mobile L1-L3ではSpatial Dockを小型icon buttonへ変更する。

- label text非表示
- Capture / AI text非表示
- aria-label維持
- bottom/right safe-area維持

Spatial Memoryの位置は変えない。

## Edge readability

Mobileではedge opacity / stroke widthを少し下げる。

Node backgroundをよりopaqueにして、
center-to-center edgeがNode本文の後ろで目立ちにくくする。

Graph relation自体は変更しない。

## Semantic Zoom loading

問題:

Map L0 -> L1 -> L2 -> L3でuncached navigationが120msを超えると、
global route-loading overlay:

- full-screen dim
- backdrop blur
- loading pill

が表示され、Spatial continuityが切れていた。

V45.5ではMap -> Map navigationだけ
global overlayを使わない。

代わりにcurrent Mapを残し:

- Scene opacityを少し下げる
- Top Bar下に細いloading indicator

を出す。

Next projection取得後にInstant Navigationで置換する。

Map semantic zoom linkへ`data-route-lock-skip`を付け、
legacy global route lock overlayを発火させない。

Classic / Map switchもInstant Navigationへ任せる。

## Runtime / privacy

新しいpersisted stateは追加しない。

保存しない:

- L3 mobile slot coordinates
- loading animation state
- compact chrome state
- Context Surface height
- attachments details state

Telemetry contractも変更しない。

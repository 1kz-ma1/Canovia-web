# V58.38 Guidance Level Change Candidate — Foundation

Status: CONTRACT ONLY. No runtime activation.

Guidance Level is a user choice. Observed activity may inform a future suggestion but must never silently mutate it.

## Required activation safeguards

- A candidate must record current level, proposed level, evidence revision, source, and creation time.
- Any level change requires explicit user confirmation.
- Reject stale confirmation if the user's current level differs from the candidate baseline.
- Dismissed candidates remain dismissed until meaningfully stronger, independently validated evidence is available.
- Do not repeatedly prompt for unchanged evidence.
- Do not infer experience, code quality, or seniority from repository activity or structure.
- No modification to Plan, Task, self-reported experience, or feature entitlement.
- Activation requires regression tests for confirmation, dismissal, stale state, repeated refresh, and authorization.

## Boundary

Existing V58.32 candidate lifecycle and V58.37 development evidence are active. Guidance-change proposals are not yet active. A product decision is needed for eligibility and proposed-level policy before activation.

# V51.9.7 Action Home Density & Plan Swipe

## 背景

iPhone実機確認で、Action Homeに4つの改善点を確認した。

1. 「確認したい変化」が縦方向を占有し、Primary Actionより主張が強い
2. 1分など短いWork SessionのPlan update signalが蓄積し、すぐ片付ける導線がない
3. 遅れ気味PlanのCTA「実行を見直す」が抽象的
4. Active WorkSession中はIn Focusが単一カードになり、以前の「他Planを横スワイプして確認する」導線が失われている

V51.9.7ではHomeを「今やること」優先へ戻しつつ、履歴を壊さずattentionだけ整理できるようにする。

## 1. Attention rail density

「確認したい変化」はPrimary contentではなくsecondary attention railとして扱う。

Desktop:
- 2列compact grid

Mobile:
- horizontal rail
- card width `min(84%, 21rem)`
- scroll snap
- scrollbar hidden
- 1画面に縦積みしない

Section:
- kickerを `NEEDS ATTENTION` から `CHECK` へ弱める
- count badgeをquiet stylingへ
- border/backgroundのred/amber intensityを下げる
- card padding / typographyを縮小

signalそのものは最大6件の既存contractを維持する。

## 2. Pending update dismiss

Plan update signalだけquick dismiss `×` を持つ。

dismissは削除ではない。

保持:
- WorkSession
- WorkLog
- actual_seconds / actual_minutes
- Timeline / Recent Activity history
- TaskEvidence等の既存履歴

変更:
- `needs_plan_update=false`
- WorkSession.metadataへ `plan_update_dismissed_at` を記録

`plan_updated_at` は更新しない。実際にPlanへ反映したわけではないため。

UIはfetchでdismissし:
- cardを即remove
- 件数を即更新
- 0件になったらsection自体をremove

通信失敗時は通常form submitへfallbackする。

## 3. Plan attention CTA wording

Plan status signalはExecution scoped Planへ遷移する既存URLを維持する。

CTA:
- 遅れ気味 / 期限切れ → `次のTaskを見る`
- 作業時間不足 → `優先Taskを見る`

旧 `実行を見直す` は使わない。

## 4. Active Focus horizontal Plan deck

Active WorkSessionがある場合も他Planを見られるようにする。

先頭:
- active WorkSession
- `IN FOCUS` / `PAUSED`
- `作業へ戻る`

続き:
- Dashboard GuidanceのOther Plan候補
- active Planと同じPlanは除外
- 最大4 Plan
- Task title + Plan identity
- `このPlanを見る` でPlan scoped Executionへ

Mobile:
- horizontal scroll
- 92% card width
- scroll snap

Active WorkSession自体を終了・切替する動作は追加しない。
横スワイプは「他Planを確認する」ためのbrowse interactionとする。

## 5. Action Home signal schema

schema versionを2へ更新。

Plan update signalのみoptional:
- `dismiss_url`
- `dismiss_label`

ActionHomeProjectionService自体は引き続きread-only projection。
dismiss writeはWorkSessionController endpointが担当する。

## 6. Regression contract

testsで以下を固定する。

- 1分completed WorkSessionをdismissしてもWorkSession / WorkLogは残る
- needs_plan_updateだけfalseになる
- dismiss metadataが残る
- Homeにquick × formが出る
- delayed CTAは `次のTaskを見る`
- `実行を見直す` は出ない
- active session中でもOther Plan guidanceがfocus railに出る
- active PlanはOther Plan候補から除外
- attention railがmobile horizontal scroll contractを持つ
- JS dismissはfull reloadなしでcard/countを更新できる

## DB migration

なし。

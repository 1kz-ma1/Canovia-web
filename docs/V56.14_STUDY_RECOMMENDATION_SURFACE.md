# V56.14 Study Recommendation Surface

## Goal

Turn V56.13 State First from a descriptive Workspace into an actionable Study surface.

For practice-oriented Study Plans, the Workspace should answer:

~~~text
What exact study set does Canovia recommend next?
Why?
What will the next Practice session actually do?
~~~

The recommendation must come from the same deterministic Strategy authority used by Study Practice.

## Authority

Canonical policy:

~~~text
StudyPracticeAttempt history
+
Task intent
+
V56.0 Exam Convergence
+
V56.4 Routing / Mastery / Cooldown
↓
StudyPracticeStrategyService
↓
Study Workspace Recommendation
~~~

Workspace must not implement a second question-allocation policy.

## Recommendation service

Add a read-only StudyWorkspaceRecommendationService.

Inputs:

- Plan
- selected navigation Task
- current actor identity

Responsibilities:

1. find actor-scoped recent StudyPracticeAttempts for the same Plan / Task
2. detect actor-scoped resumable READY / IN_PROGRESS StudyPracticeSession
3. if a resumable Session exists:
   - use its stored selection_context.strategy
   - do not build a new Strategy
   - present continuity / resume semantics
4. otherwise:
   - call StudyPracticeStrategyService::build()
   - return a bounded presentation array

Workspace GET must not:

- generate questions
- call the question provider
- create a StudyPracticeSession
- create a StudyPracticeAttempt
- mutate Task progress

## Surface

Register:

~~~text
study_recommendation
~~~

Recommended placement:

~~~text
Goal Summary
Current State
Missing Context when needed
Study Recommendation
Readiness / Gap when meaningful
Weaknesses
Recent Results
Study Methods
~~~

For a practice-oriented current action, Study Recommendation replaces the generic Current Action card to avoid duplicate CTAs.

Non-practice flows such as:

- school-test Scope gate
- memorization Recall
- no executable Task

continue using the generic Current Action surface.

## Presentation

The card should expose only policy-relevant information.

Example broad AP set:

~~~text
TODAY'S RECOMMENDATION

分野横断演習
10問

現在: 総合演習 / 横断探索

2問  弱点の再確認
2問  定着確認
6問  横断・未探索

DBは直近で十分確認済み
NWは低露出なので優先

[10問始める]
~~~

Example focused remediation:

~~~text
弱点補完
5問

3問  重点弱点
1問  関連弱点
1問  確認問題
~~~

Example Exam Mode:

~~~text
Exam Mode
10問

本番を意識した横断10問
~~~

## Mix labels

The display layer may translate Strategy buckets, but may not change their counts.

### Broad / General

- primary → 弱点の再確認
- secondary → 定着確認
- diagnostic → 横断・未探索

### Weakness Reinforcement

- primary → 重点弱点
- secondary → 関連弱点
- diagnostic → 確認問題

### Diagnosis

- diagnostic → 現在地診断

### Exam Mode

- diagnostic → 本番横断

## Context

Bounded optional context:

- primary topics
- secondary / retention topics
- cooldown topics
- mastered topics
- suppressed parent topics
- preferred parent topics

Do not dump raw routing policy JSON into the UI.

## Resume boundary

If a resumable Session exists:

~~~text
Workspace
→ stored Session Strategy
→ "途中の演習を続ける"
→ canonical Study Practice URL
→ V56.5 Resume Fast Path
~~~

Do not show a newly calculated recommendation above an already-fixed Session.

## Consistency guarantee

The guarantee is policy consistency, not a stale immutable preview.

When no Session exists:

- Workspace and Practice both use StudyPracticeStrategyService
- Practice may recompute if new Evidence is created between viewing and starting

When Session exists:

- stored Session Strategy is authoritative

## Scope

Initial V56.14 recommendation is intended for practice-oriented Study types:

- certification_exam
- score_exam
- general_learning
- school_test only after its required Scope gate is satisfied

Do not force Practice recommendation onto:

- memorization
- skill-learning flows whose next action is practical Evidence rather than question practice

## Validation

At minimum:

1. AP broad Task shows Strategy label / 10-question mix from StudyPracticeStrategyService.
2. displayed counts exactly equal Strategy question_mix.
3. weakness reinforcement uses focused labels without changing counts.
4. cooldown / retention context is bounded and displayed when present.
5. Exam Mode displays Exam Mode semantics.
6. Workspace recommendation CTA targets existing Study Practice route.
7. Workspace GET does not create Practice Session / Attempt.
8. resumable Session uses stored Strategy and resume wording.
9. resumable Session does not build a new Strategy.
10. school test without Scope still shows Scope gate, not recommendation.
11. memorization still prefers Recall.
12. V56.13 State First tests remain green.
13. V56.4 Routing / V56.0 Convergence tests remain green.

## Non-goals

V56.14 does not:

- add Study Method Recommendation
- add baseline-score storage
- add Learning Type override
- add AI recommendation prose
- add new question-generation policy
- change Study Practice question selection
- change V56.5 Resume Fast Path
- add migrations

# V51.6 Surface Refinement Phase 1

## 目的

実機で確認した Constellation / Execution の情報密度と操作距離を改善する。

V51.6 Phase 1 は新しいSurfaceを増やさず、既存の責務を明確化する。

- Constellation: Plan全体の構造把握と、選択PlanのTask構造確認
- Execution: 今実行するTaskの決定と、同じ実行タイプ内の候補切替

## 1. Constellation Overview Density

未選択時のUniverseはPlan数に応じて表示範囲を圧縮する。

raw projectionの `orbit` は安定位置として維持し、表示時だけ中心からの距離へdensity factorを掛ける。

表示係数:

- 1-2 Plan: 0.52
- 3-4 Plan: 0.68
- 5-6 Plan: 0.82
- 7+ Plan: 1.0

これにより少数Plan時に52rem固定の巨大空間を使わない。

1-6 PlanではStageをviewport内へ収め、7+ Planのみwide stageを許可する。

## 2. Selected Constellation Workspace

Plan選択後はUniverse内の小さなzoomではなく、専用Selection Workspaceへ切り替える。

### Upper Palette

`data-constellation-focus-palette`

役割:

- 選択PlanのConstellationを大きく表示
- Main Starを直接選択
- 選択StarのTask Groupを同じPalette内で確認
- Task title / status / progress / remaining minutes / next actionを確認

星を選んでもDialogへ遷移しない。

### Lower Palette

`data-constellation-detail-palette`

役割:

- Plan title
- completion
- completed Task / total Task
- Main Star count
- status
- Execution handoff
- Plan detail
- Plan operation

旧左下固定Inspectorは廃止する。

## 3. Selection Scale

Overview上のPlan constellationとSelected Workspaceは別レイアウトとして扱う。

Selected Workspaceでは星座graphをoverviewより明確に大きくする。
「少し拡大する」のではなく、選択状態へSurfaceが切り替わったと認識できるサイズ差を持たせる。

## 4. Task Group Detail

ConstellationProjectionServiceのStar task projectionへ:

- next_action_note
- description

を追加する。

Task Group panelは現在Starを初期選択し、Star tapでfragmentを差し替える。

DB変更なし。

## 5. Execution Recommendation Rail

ExecutionのPrimary recommendationは維持する。

ただし「別候補を見る」button / collapsed candidate shellを廃止する。

Primary recommendationの下へ:

`data-execution-recommendation-rail`

を常時表示し、同じExecution Mode内の候補をhorizontal snap railとして表示する。

候補生成ルール:

1. Primary recommendationを決定
2. Primaryとは別Planで同じExecution ModeのTaskを優先
3. 各Planから最大1件を候補化
4. priority score順
5. 足りない場合のみ同Mode全体から補完
6. Task重複は禁止

Plan contextからExecutionへ来た場合も、PrimaryはそのPlanを尊重しつつRailには他Plan候補を出せる。

## 6. Timer Boundary

Timerはexecution actionが `timer` の場合だけPrimary CTAとして表示する。

specialized action:

- study_activity
- execution_orchestration
- career_workspace

ではTimer buttonを表示しない。

ExecutionModeServiceの `supports_timer` もspecialized modeではfalseにする。

Offline active timer resume UIは既存work session継続のため維持する。

## 9. Non-goals / Phase 2

Phase 1では以下を行わない。

- PlanごとのConstellation shape grammar刷新
- deterministic branch / ring / arc / cluster generator

- recommendation modelのscoreロジック変更
- streaming / autonomous execution

Constellation shape diversityはPhase 2で扱う。

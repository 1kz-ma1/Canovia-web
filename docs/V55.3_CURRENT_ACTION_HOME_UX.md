# V55.3 Current Action Home UX Refinement

## Goal

V55.3 continues the pre-iOS UX Completion phase.

Action Home must answer one question first:

```text
What should I do now?
```

After V53/V54/V55, the Home Intelligence card can contain the same State / Readiness / Gap information already available in a specialized Workspace.

That is useful context, but Home must not become a miniature Study / Development / Career Workspace.

## Surface responsibility

### Home

Home owns:

- one Current Action
- one primary execution CTA
- a compact explanation of why this Action is current
- browsing other Plan candidates
- attention signals

### Specialized Workspace

Study / Development / Career Workspace owns:

- full Readiness presentation
- State detail
- Biggest Gap detail
- domain metrics
- State Change
- history
- setup/onboarding

## Home Intelligence card hierarchy

New order:

```text
Plan context
→ Current Action
→ short Action intent
→ Primary CTA
→ Specialized Workspace CTA
→ compact judgment context
→ expandable Why now?
```

Home no longer renders separate large Readiness / Current State / Biggest Gap panels inside the Current Action card.

Instead render one compact context strip:

- Readiness label + display
- Current State only when distinct from Readiness
- Biggest Gap label

The full details remain available in the specialized Workspace.

## Workspace handoff

`PlanIntelligencePresentation` gains:

- `workspaceUrl`
- `workspaceLabel`

Adapters provide the canonical specialized Workspace:

Study:

```text
/workspace/study?plan_id=...
label = Study Workspace
```

Development:

```text
/workspace/development?plan_id=...
label = Development Workspace
```

Career:

```text
/workspace/career?plan_id=...
label = Career Workspace
```

`detailUrl` remains the domain operation/detail surface used by the shared detailed summary.

This keeps:

```text
Home → specialized Workspace
Workspace → domain operation/detail
```

clear.

## CTA deduplication

Home must never render two CTAs to the same URL.

Rules:

1. Primary Action CTA is always first.
2. Workspace CTA appears only when `workspaceUrl !== actionUrl`.
3. Generic Home titlebar link becomes `ほかの候補を見る` when Intelligence owns the primary Action.
4. Without Intelligence, the existing `実行を開く` wording remains.

## Why-now disclosure

The collapsed Home surface shows only compact judgment context.

Expanded `なぜ今これ？` retains:

- Action intent
- Decision summary
- confidence
- Task projection note if relevant

No Decision or Evidence detail is removed from the specialized Workspace/history surfaces.

## Compatibility

Preserve:

- Plan priority semantics
- Task guidance alternatives
- horizontal Plan browsing
- active WorkSession behavior
- Action Home attention rail
- offline snapshot
- Study explicit POST Action execution
- Development routing
- Career operation routing
- telemetry semantics

# V58.33 Study Review Cycle Personalization

## Goal

StudyのLiving Profileを、単なる演習回数だけではなく「時間を空けて再演習している」という実利用へ追従させる。

V58.33が観測するのは復習行動であり、記憶保持・習熟・合格可能性そのものではない。

Core principle:

> Spaced practice is observable behavior. Retention is not automatically proven by it.

## Source of truth

- `StudyPracticeAttempt`
- `docs/V58.28_STUDY_BEHAVIOR_PERSONALIZATION.md`
- `docs/CANOVIA_PERSONALIZATION_SPEC.md`

No migration is added.

## Deterministic threshold

同じauthenticated user / Study Planについて、直近12件の評価済み演習を対象にする。

Review Cycleを観測する条件:

- assessed attempts >= 5
- distinct practice days >= 2
- first / latest observed practice span >= 3 calendar days

同日に5回解いただけではReview Cycleと判定しない。

このthresholdは初期のdeterministic heuristicであり、retentionを証明する学習科学上の基準ではない。

## Observed Context

`observed_context.study_behavior.review_cycle`:

- `stage = spaced_review_observed`
- `plan_id`
- `assessed_attempt_count`
- `recent_attempt_window_count`
- `distinct_practice_days`
- `span_days`
- `recent_average_score_percent`
- `first_attempt_at`
- `latest_attempt_at`
- `observed_at`

Scoreは表示・今後の判断材料となるObserved Factとして保持するが、V58.33のReview Cycle発火条件には使わない。

## Trust boundary

V58.33は以下を行わない。

- retention / masteryの自動認定
- self-reported Study stageの書き換え
- Guidance Level変更
- Plan / Task変更
- Study strategy自動変更
- exam readiness再分類
- score thresholdによる能力評価
- AI inference

## Duplicate behavior

一度Candidateを作成した後も、新しい評価済み演習でObserved metricsは更新する。

ただし以下は重複生成しない。

- Context Update Candidate
- Auto Applied event

V58.28の`study_practice_assessed` refresh triggerを再利用し、V58.33専用の重複refresh eventは追加しない。

## Release Gate

Minimum:

`L1 Early Access Core`

Manual review key:

- `study_review_cycle_personalization`

Manual checks:

- 5回すべて同日では発火しない
- 5回以上 + 2日以上 + 3日以上のspanで発火
- Growth Experienceが表示される
- 「定着・習熟の判定ではない」と明示
- self-reported Study stage保持
- Guidance保持
- later attemptでmetrics更新
- Candidate / Auto Apply telemetry重複なし
- mobile / desktop

- forgetting curve estimation
- weakness-level spaced review

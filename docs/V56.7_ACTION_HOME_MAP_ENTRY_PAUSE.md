# V56.7 Action Home Map Entry Pause

## Goal

Temporarily remove the user-facing Map / Explore entry from Action Home while keeping the Map implementation intact.

The current priority is functional clarity around:

- Workspace selection
- Current Action
- Study / Development execution flows
- stable mobile real-device use

Map remains available as an implemented surface, but it is not part of the primary Home decision path for now.

## Product decision

Action Home must not render the Home / Explore surface switcher.

This removes the large surface-navigation strip above the Action Home hero and prevents Map from competing with the primary execution-oriented flow.

The change is intentionally reversible.

## Preserved Map capability

Do not delete or rewrite:

- `/map`
- `map.index`
- Map graph projection
- semantic zoom
- Space Station
- Map telemetry
- Map personalization
- fullscreen Map shell
- direct Map URLs
- the Map-side Home fallback / surface navigation

If a user reaches Map directly, the existing Map-side navigation may remain so they can return to Home safely.

## Action Home visual scope

V56.7 does not resize or redesign the Action Home hero.

The hero is visually large on mobile, but functional work takes priority for now. Its density can be tuned later as a separate visual pass after the Workspace / Study / Development entry flow is stable.

## Validation contract

Home:

- no `data-canovia-surface-nav`
- no Explore entry
- remains `data-canovia-surface="home"`
- Current Action / Action Home behavior is unchanged

Map:

- direct `/map` remains available
- Map-side fallback/navigation remains available
- Map runtime and telemetry are unchanged

## Non-goals

V56.7 does not:

- delete Map
- redirect `/map`
- remove Map code
- change Workspace Mode
- change Current Action ranking
- resize the hero
- change Study / Development Workspace behavior

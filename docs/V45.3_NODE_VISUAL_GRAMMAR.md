# V45.3 Node Visual Grammar

## Goal

Canovia MapのNodeを「すべて同じ丸いカード」から脱却させ、
Nodeの役割を文字だけでなくシルエットでも識別できるようにする。

V45.3はPresentation Layerのみを変更する。

変更しない:

- Navigation Graph
- Attention State
- Map Projection
- canonical node type
- position_role
- node coordinates
- Semantic Zoom
- Gesture state
- Telemetry

## Principle

> 意味はGraphが決め、見た目はVisual Grammarが翻訳する。

Visual Grammarは新しいsource of truthではない。

例えばTaskはGraph上では最後まで:

`type=task`

であり、Primary TaskをUI上でRocketとして描画しても:

`type=rocket`

には変更しない。

## MapNodeVisualGrammar

`App\Support\MapNodeVisualGrammar`

をPresentation-only resolverとして追加する。

input:

- node.type
- node.state
- node.position_role

output:

- visual kind

Visual kindはBlade/CSSでのみ使用する。

Projection arrayへvisual_kindを書き戻さない。

## Visual kinds

### station

source:

- space_station

meaning:

- Capture
- Companion
- Inbox routing
- central hub

visual:

- docking ring
- cross docking arms
- diamond core

### planet

source:

- intent
- domain
- intent_context

meaning:

- broad semantic area
- place the user can enter

visual:

- planetary body
- orbital ring

Intent roleごとにaccentを変える。

- Plan: blue
- Execution: violet
- Reflection: green
- Collaboration: pink

色だけに依存せず、planet silhouetteは共通する。

### moon

source:

- plan

meaning:

- bounded plan context inside a broader domain

visual:

- smaller planetary body
- crater marks
- no large orbital machinery

L2 Plan / L3 Planの両方で同じvisual familyを使う。

### star

source:

- goal

meaning:

- desired destination
- direction rather than immediate action

visual:

- eight-point goal star
- subtle outer orbit

### rocket

source:

- task when:
  - state=primary
  - or position_role=now

meaning:

- current executable action

visual:

- launch body
- small window
- exhaust marker

Current TaskだけをRocketにする。

### beacon

source:

- non-primary task

meaning:

- next / future action

visual:

- diamond action marker
- outer signal ring

Current Actionとの差を明確にする。

### module

source:

- tool

meaning:

- execution mechanism
- tool / workspace

visual:

- hexagonal module
- connector points

### archive

source:

- evidence

meaning:

- completed / observed past evidence

visual:

- circular archive frame
- stored record lines

### inbox-dock

source:

- inbox

meaning:

- unprocessed incoming information

visual:

- receiving tray
- incoming arrow

### satellite

source:

- satellite_plan
- satellite_tool

meaning:

- promoted shortcut
- existing Context appearing at L0 through Attention

visual:

- central body
- two solar panels

Satellite is not a new canonical entity.

### crew-station

source:

- collaboration_hub

visual:

- linked people / units inside orbit

### crew

source:

- collaboration_context
- collaboration_item

visual:

- linked participants

### context

unknown / fallback types.

## DOM

各NodeへPresentation metadataとして:

- `data-map-visual-kind`
- `visual-{kind}` class
- `data-map-node-glyph`

をrenderする。

Glyphは:

```html
<span class="canovia-map-node-glyph" aria-hidden="true">
    <span class="canovia-map-node-glyph-core"></span>
</span>
```

の軽量DOMだけを追加する。

SVG assetや画像requestは追加しない。

## CSS strategy

Glyphは主に:

- border
- border-radius
- linear/radial gradient
- clip-path
- pseudo-elements

で描く。

V45.3で避ける:

- continuous animation
- large filter blur
- canvas rendering
- WebGL
- external icon packages
- additional image request

V45.4 Runtime Performanceを阻害しないことを優先する。

## Node shell

GlyphだけでなくL3の一部Nodeは外形も少し変える。

Examples:

- Current Task / Rocket:
  - tall rounded launch silhouette
- Tool / Module:
  - tighter technical corner radius
- Evidence / Archive:
  - asymmetric archival capsule
- Inbox / Dock:
  - receiving dock silhouette
- Plan / Moon:
  - softer orbital container

ただしhit target自体は従来Node rectangleを維持する。

clip-pathでNode本体を切り抜かない。

理由:

- tap targetを減らさない
- text clippingを避ける
- Context Surface interactionを壊さない

## Selection

Mobile selected node / Desktop focus nodeでは
glyph scaleをわずかに上げる。

Selected nodeにはvisual accent由来のouter haloを付ける。

Continuous pulseは使わない。

## Mobile

V45.0 / V45.1 / V45.2を維持する。

Mobileではglyphを小さくするが削除しない。

特にL0では:

- Space Station
- Intent Planet
- Artificial Satellite

を文字を読む前に区別できることを重視する。

Nodeサイズ・mobile coordinatesは変更しない。

## Accessibility

Visual Grammarは補助情報であり、
Nodeの意味は既存:

- eyebrow
- label
- accessible link label
- Context Surface

で引き続き伝える。

Glyphは`aria-hidden=true`。

色だけで意味を区別しない。

## Telemetry

visual_kindをMap Telemetryへ追加しない。

既存:

- node_type
- position_role
- action_role

だけを使用する。

理由:

visual_kindはUI releaseによって変更可能なPresentation detailであり、
behavioral semantic dimensionではない。

## Projection privacy / stability

Projection keyへvisual_kindを追加しない。

Node appearanceを変更しても
Graph/Attention Projectionのidentityは変わらない。

## Tests

固定する:

- structural fields -> visual kind mapping
- Primary Task -> rocket
- non-primary Task -> beacon
- Plan -> moon
- Satellite -> satellite
- Inbox -> inbox-dock
- L0 rendered data-map-visual-kind
- Projection nodeにvisual_kind/glyphを追加しない

# V55.2 Qualitative Readiness UX

## Goal

V55.2 is the first UX Completion step after Career becomes a public Workspace Mode.

It fixes a semantic mismatch introduced when the shared Intelligence presentation, originally built for numeric Study / Development Readiness, is reused by Career.

Career intentionally has:

```text
readiness.score = null
```

because Career Process Readiness is qualitative and must not become a hiring-probability or employability score.

The UI must therefore not render:

```text
Process Readiness
未判定

現在地
観測中
```

for the same state.

## Shared presentation contract

`PlanIntelligencePresentation` gains an explicit presentation semantic:

```text
qualitativeReadiness
```

Numeric domains:

- Study
- Development

continue to render:

```text
Readiness score
+
Current State
```

Qualitative domains can render:

```text
Readiness state
```

without a duplicated Current State tile.

V55.2 uses Career as the first qualitative domain.

## Display behavior

### Numeric

```text
qualitativeReadiness = false

readinessDisplay()
→ score/100
→ 未判定 only when score is genuinely unavailable
```

`hasDistinctStateDisplay() = true`

### Qualitative

```text
qualitativeReadiness = true

readinessDisplay()
→ stateLabel
```

`hasDistinctStateDisplay() = false`

Career:

- no Career signal → 未観測
- Career signal exists → 観測中

No synthetic number is created.

## Surfaces

The shared contract applies to:

- Action Home Intelligence card
- Overview Global Current Action
- Overview Mode summary
- shared Intelligence summary partial
- Career Workspace

Views must not branch on `domain === career` simply to decide Readiness display semantics.

Domain-specific labels and decisions remain in adapters.

## UX density

When Readiness and Current State are semantically the same qualitative value, render one status tile instead of two.

This reduces duplicate information and keeps Current Action / Biggest Gap visually stronger.

Numeric Study / Development layouts remain unchanged.

## Safety

V55.2 does not:

- add a Career score
- infer employability
- estimate hiring probability
- change Decision policy
- change State calculation
- change persistence
- add AI traffic
- add provider traffic

## Performance

Presentation-only change.

No new database query.
No migration.
No new client request.

# V41.20 — Canovia Instant Navigation\n\n## Goal\n\nHomeのPlan切替のような「待たずに画面が変わる」体験を、\n主要なCanovia画面へ段階的に拡張する。\n\n対象:\n\n- Home `/`\n- Inbox `/inbox`\n- Roadmap `/roadmap`\n- Timeline `/timeline`\n- Calendar `/calendar`\n\n管理画面、AI演習、設定、Plan編集などはこのStepでは通常navigationを維持する。\n\n## Architecture\n\n全面SPA化はしない。\n\nLaravelを引き続きserver-side source of truthとし、\n共通Shellだけブラウザに残してPage領域を差し替える。\n\nHard load:\n\n`Laravel full HTML -> Canovia Shell + Page`\n\nCore navigation:\n\n`tap -> in-memory cached Pageを即描画 -> history.pushState -> Laravelをbackground revalidate`\n\nCache miss:\n\n`tap -> Laravel GET -> Page描画`\n\ncache miss時だけ従来のloading overlayを120ms後に表示する。\n\n## Stable shell\n\n`layouts.app` に以下の境界を追加した。\n\n- `data-canovia-main`\n- `data-canovia-page`\n- `data-canovia-companion-slot`\n- `data-mobile-section-label`\n- `data-canovia-nav-key`\n\nPage領域には:\n\n- flash status\n- guest protection\n- sync status\n- page content\n- offline snapshot\n\nを含める。\n\nCompanion entryはPageとは別slotとして同期し、\nRoadmap等で現在Contextが変わっても古いentry contextを残さない。\n\n## Prefetch\n\nCore pageを開いた後、主要nav destinationを1件ずつbackground prefetchする。\n\n- Save Data時は自動prefetchしない\n- 2G相当では自動prefetchしない\n- pointer / focus / touch intentでもprefetch可能\n- 同一URLの重複fetchはinflight mapで抑止\n- cacheはmemory only\n\nユーザー固有HTMLをlocalStorage / IndexedDBへ永続保存しない。\n\n## Human-action boundary / analytics\n\nPrefetchは実際の閲覧ではない。\n\n`X-Canovia-Instant-Navigation: prefetch` を付与し、Homeではprefetch時:\n\n- DashboardViewedを記録しない\n- RecommendationShownを記録しない\n- UserStateSnapshotを書き込まない\n\n実際にcached pageへ移動した後、\n`X-Canovia-Instant-Navigation: navigate` でbackground revalidateし、\n実訪問として通常のserver-side処理を通す。\n\nPerformance logにも `instant_navigation=prefetch|navigate` を追加する。\n\n## Dynamic lifecycle\n\nShellのglobal listenerは残し、Page swap後だけ:\n\n`canovia:page-ready`\n\nを発火する。\n\nV41.20ではHomeとRoadmapのpage-specific interactionを再初期化する。\n\nHome:\n\n- Plan tab\n- task view event\n- navigation context\n- dashboard idle signal\n- current tab state restoration\n\nRoadmap:\n\n- map/list view\n- map stop detail\n- plan pager swipe / keyboard\n- overview action\n- mobile supporting-link density\n\noffline snapshotもswap後に再保存する。\n\n## History\n\n`history.pushState` と `popstate` に対応する。\n\nブラウザBack/ForwardでもHard reloadせず、\nmemory cacheがあればPageを即復元する。\n\n## Correctness boundaries\n\n- POST / mutationはinterceptしない\n- non-core page navigationは通常browser navigation\n- external link / download / new tabはinterceptしない\n- core pageでもcache miss時は通常のloading feedbackを残す\n- fetch/parse失敗時は `window.location.assign` へfail open\n- auth redirect等でcore responseでなくなった場合もfull navigationへfallback\n\n## Current limitation\n\nV41.20はFull HTMLをbackground fetchして必要Page部分を抽出するPhase 1。\n\nそのためLaravel側のPage生成コスト自体は残る。\nただしユーザーはcached Pageを先に見るため、server待ち時間をnavigation latencyから分離できる。\n\n次段階では必要に応じて:\n\n- Core fragment endpoint\n- shared core context payload\n- server queryの共通化\n- stale pageのsilent refresh\n\nへ進められる。\n\n## Validation\n\n- Vite production build\n- JS syntax check\n- Laravel view cache\n- Core 5 surface shell contract\n- Prefetch side-effect suppression\n- Normal Home observability preservation\n- V41.17〜V41.19 performance regressions\n- Dashboard / Roadmap / Inbox regressions\n- Instant Start regression\n

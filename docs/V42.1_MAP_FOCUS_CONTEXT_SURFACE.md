# V42.1 Focus Mode + Contextual Classic Surface

## Goal

Mapを「見るだけの図」から、必要な情報と操作へ最短で到達するContext Navigationへ進める。

V42.1では以下を成立させる。

1. Nodeを選択する
2. 選択Nodeが中央へ移動する
3. 直接つながる1-hop Nodeだけを残す
4. 選択Contextに必要なClassic Surfaceを表示する
5. 実操作は既存Classic画面へ委譲する

## Focus Mode

通常Mapでは空間の意味を固定する。

- Future = 上
- Past = 下
- Input = 左
- Action = 右
- Now = 中央

Focus Modeでは選択Nodeだけを一時的に中央へ置く。
周辺Nodeは1-hopだけ残し、役割の方向性をできるだけ維持して再配置する。

例:

- Plan / Goal / Next Task -> 上
- Evidence -> 下
- Inbox -> 左
- Tool -> 右
- Current Taskは、選択対象との関係に応じて重ならない側へ退避

Focusで非表示になったNodeは削除しない。
Focus解除で元の決定論配置へ戻す。

## Navigation history

Focus選択はURL hash \`#focus=<node id>\` とブラウザ履歴へ載せる。

これにより:

- Node AをFocus
- Node BへFocus
- Back
- Node Aへ戻る
- Back
- 全体Mapへ戻る

という操作が成立する。

直リンクでFocus hashを開いた場合も表示を復元する。
JavaScriptが使えない場合はNodeの本来のhrefへ遷移する。

## Contextual Classic Surface

Map内へ既存Detail画面を丸ごと埋め込まない。

表示内容は:

- Context種別
- タイトル
- 要約
- 最低限の状態
- そのContextで必要なClassic Action

のみ。

Mobile:
- Bottom Sheet

Desktop:
- Side Panel

複雑な入力・編集・実行は既存画面へ遷移する。

## Safety boundary

Contextual SurfaceにはV42.1時点で更新フォームを置かない。

既存の:

- Controller
- authorization
- validation
- mutation service

を迂回しないため、MapはNavigation Layerのまま維持される。

## Projection additions

Nodeに \`classic_surface\` を追加する。

構造:

- kind
- title
- summary
- meta[]
- actions[]
  - label
  - url
  - primary

この情報も永続化しない。
MapProjectionServiceが既存EntityとPolicyから都度生成する。

## Non-goals

V42.1では以下を行わない。

- Map内でTask更新
- Map内でEvidence登録
- Companion Context接続
- Mutation後の自動Living再評価
- 任意Nodeの自由配置
- Graph専用DB

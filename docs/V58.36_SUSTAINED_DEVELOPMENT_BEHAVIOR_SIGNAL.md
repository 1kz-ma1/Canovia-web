# V58.36 Sustained Development Behavior Signal

## Goal

Development Personalizationが短期の活動量だけでなく、時間をまたいだ継続的な開発行動をEvidenceとして扱えるようにする。

これはexperience levelの推定ではない。

## Deterministic observation

Development GitHub observationsの直近90日から:

- distinct active days
- first-to-last activity span

を観測する。

Sustained signal:

```text
active days >= 6
AND
activity span >= 28 calendar days
```

Evidence key:

`sustained_development_activity_28d_6_days`

## Signal policy

Sustained signal単独ではsignal strength 2まで。

signal strength 3には、sustained signalに加えてrecent PR / Commit observations >= 2、または既存のstrong activity条件を要求する。

したがってcalendar durationだけでadvanced supportをhigh confidenceにしない。

## Observed Context

```text
development_behavior.active_day_count_90d
development_behavior.activity_span_days_90d
```

を保存する。

## Trust boundary

Repository activityは以下を意味しない。

- user authorship
- code quality
- seniority
- experience level
- professional status

V58.36は変更しない:

- self-reported development experience
- Guidance Level
- Plan / Task
- high-risk confirmation requirement
- V58.32 dismissal / reopen contract
- V58.35 confidence calibration mapping

## Privacy / telemetry

free textやrepository contentを新規保存しない。
集約されたcount/spanだけをLiving Profile observed Contextへ保存する。

## Migration

None.

## Manual review

`sustained_development_behavior_signal`

Check:

- six active days spanning >= 28 days creates sustained evidence
- same-day / short-window volume does not create sustained evidence
- sustained-only signal strength is 2
- recent PR/Commit evidence can combine with sustained signal
- experience and Guidance remain unchanged

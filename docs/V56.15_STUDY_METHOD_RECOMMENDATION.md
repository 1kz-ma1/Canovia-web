# V56.15 Study Method Recommendation

## Goal

V56.14 decides the exact next Practice strategy when Practice is the right learning method.

V56.15 adds the layer above that:

```text
What should the learner do next?
+
How should the learner study it?
```

The Study Workspace must select the **learning method** before selecting the detailed execution inside that method.

Canonical flow:

```text
Learning Type
+
Current Learning State
+
Task semantic fit
+
Practice Strategy / Routing State
+
Recall / Resource availability
↓
Study Method Recommendation
↓
method-specific execution
```

## Existing authority to reuse

V41.10 already provides `StudyActivityPolicyService` for Task-semantic fit:

- `question_practice`
- `recall`
- `resource_study`

V56.15 must not replace that service with a duplicate classifier.

Instead:

```text
StudyActivityPolicyService
= "what method fits this Task semantically?"

V56.15 StudyMethodRecommendationService
= "given the current Study State, which method should be primary now?"
```

## Method candidates

Initial methods:

- `question_practice`
- `recall`
- `resource_study`
- `scope_organization`
- `practical_evidence`

Question Practice may expose a variant:

- `diagnosis`
- `broad_practice`
- `focused_remediation`
- `exam_mode`
- `resume`

These variants come from V56.14 / StudyPracticeStrategyService. They are not a second Practice routing policy.

## Deterministic priority rules

### 1. Resume continuity

An unfinished actor-owned StudyPracticeSession is authoritative.

```text
resumable Session
→ question_practice / resume
```

Do not switch an unfinished Session to Recall or Resource Study merely because later heuristics would choose another method.

### 2. School-test missing Scope

```text
school_test
+
confirmed Scope missing
→ scope_organization
```

Reason: the test range materially changes the learning allocation.

### 3. Memorization learning

```text
memorization
→ recall
```

Recall is preferred over generic generated questions.

### 4. Skill learning

```text
skill_learning
→ practical_evidence
```

The primary action should be practical Task execution / evidence, not generated question practice.

### 5. Exam Mode

```text
Practice Strategy phase = exam_mode
→ question_practice / exam_mode
```

Exam Mode outranks resource detours and ordinary retention routing because the convergence policy has already selected the exam-window behavior.

### 6. Repeated knowledge / concept gap

Among the latest actor-scoped attempts for the selected Plan / Task:

- inspect the latest 3 attempts
- count distinct attempts containing `knowledge_gap` or `concept_gap`
- require at least 2 attempts

Then:

```text
repeated knowledge/concept gap
→ resource_study
```

unless an unfinished Session or Exam Mode is authoritative.

This prevents “more questions” from being the default response to repeated missing knowledge.

### 7. Retention due

If the Strategy reports retention-due topics:

```text
retention_due_topics present
→ recall
```

unless unfinished Session / Exam Mode / repeated knowledge gap has higher priority.

Recall can be recommended even if no card is currently due; the Recall page can create/import material if the deck is not prepared yet.

### 8. Task-semantic fit

If none of the state overrides apply, use the existing V41.10 primary activity:

- question practice
- recall
- resource study

### 9. Cooldown / mastered

Cooldown and mastered topics must not trigger deliberate focused drilling.

V56.15 does not implement separate cooldown math; V56.4 remains authoritative.

The method recommendation may explain that repeated drilling is intentionally paused while broad Practice or another method is selected.

## State evidence

V56.15 may read:

- V56.14 Practice recommendation
- actor-scoped StudyPracticeAttempts
- StudyRecallItems
- Plan / Task Resources
- V56.13 learning type and resolved state
- V41.10 Study Activity fit

It must not create or mutate any of these on Workspace GET.


## UI composition

### When primary method is Question Practice

Render:

1. Study Method Recommendation
2. V56.14 Study Recommendation

The method surface is compact and V56.14 owns the detailed question mix CTA.

### When primary method is not Question Practice

Render:

1. Study Method Recommendation with primary CTA

Do not render V56.14 Practice recommendation as the primary recommendation.

The existing generic Current Action card should not duplicate the method CTA.

### Other Study Methods

The existing `study_methods` surface should use the method recommendation alternatives rather than a static unordered set.

This remains an escape hatch. Canovia recommends one method but does not prohibit the others.

## Implementation / Validation

Implemented:

- `StudyMethodRecommendationService`
  - wraps V41.10 `StudyActivityPolicyService` instead of replacing it
  - reads actor-scoped latest Practice Attempts for repeated structured knowledge/concept gaps
  - reads V56.14 Practice phase / retention / cooldown / resume state
  - reads Recall item state and Plan Resource availability
  - selects Question Practice / Recall / Resource Study / Scope Organization / Practical Evidence
- method priority
  - unfinished Practice Session remains authoritative
  - school-test missing Scope selects Scope Organization
  - memorization selects Recall
  - skill learning selects Practical Evidence
  - Exam Mode remains Question Practice
  - repeated knowledge/concept gap in >=2 of latest 3 Attempts selects Resource Study
  - retention due selects Recall
  - otherwise V41.10 Task-semantic fit remains authoritative
- Scope compatibility
  - legacy Scope-based Study Intelligence cannot reintroduce Scope as a universal no-Scope certification gate
- `study_method_recommendation` Workspace surface
  - primary method, reason, method variant and CTA
  - Question Practice delegates detailed allocation to V56.14
- ranked `study_methods` alternatives
  - alternatives are State-aware instead of a fixed unordered menu
- skill-learning Missing Context
  - practical baseline now routes to Guided Execution instead of generated Practice
- Execution Setup
  - Practice provider selection is shown only when Question Practice is primary
- Study Activity page
  - uses the same V56.15 State-aware recommendation as Study Workspace
  - no contradictory static V41.10 recommendation after State overrides

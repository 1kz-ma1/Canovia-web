# V51.3 Action Home

## 目的

Primary HomeをPlan browser / per-Plan dashboardから切り離し、Canoviaを開いた直後の問いだけに答える。

> 今、何をすればいい？

HomeはPlanの構造を読む場所ではない。全体像はConstellation、実行方法はExecution、履歴はTimelineへ分離する。

## Surface Responsibility

Primary order:

1. Active Work Session
2. Next Action / Recommendation
3. Important Changes / Alerts
4. Continuity
5. Small utility actions
6. Small Timeline preview
7. Collapsed daily context

Homeから次をPrimary presentationとして外す。

- Plan tab browser
- Planごとの詳細Dashboard
- Plan-specific Surface Modules
- Roadmapの詳細表示
- 全Planカード一覧

Planの詳細へ潜ることより、今必要なActionを選ぶことを優先する。

## Action Home Projection

ActionHomeProjectionService は既存のcanonical stateからread-only signal projectionを生成する。

schema version: 1

signal sources:

### Plan update required

完了 / 中断したWork Sessionに needs_plan_update=true が残っている場合。

Action: Plan Review Assistant

### Plan attention

既存 PlanProgressService の状態:

- 遅れ気味
- 期限切れ
- 作業時間不足

をHome上のattention signalとして表示する。

ActionはPlan detailではなくExecution /navigate?plan_id=... へhandoffする。

### Plan status transition

Homeはsessionに直近のPlan statusだけを保持する。

action_home.plan_statuses

前回Home表示から状態が変わり、現在attention状態になった場合、STATUS CHANGED として「予定通り → 遅れ気味」のように変化を明示する。

これは通知履歴の永続DBではない。Homeの直近Contextを比較するための短命session snapshotである。

Instant Navigation prefetchではsnapshotを更新しない。

### Collaboration change

既存 PlanActivityLog を利用する。

- collaborative Planのみ
- 過去14日
- 最大4件
- 現在ユーザー自身の操作は除外

Homeには「誰が何を変えたか」を小さなsignalとして表示する。

詳細履歴そのものはTimeline / Collaboration contextの責務であり、Homeへ全activity feedは持ち込まない。

## Recommendation

既存 DashboardGuidanceService のobjective priorityを維持する。

Homeでは:

- 最優先Task
- 他Planの候補
- Primary execution action
- なぜこの行動か

だけを表示する。

Plan titleはContext labelであり、HomeからPlan detailへ入るPrimary navigationにはしない。

Specialized actionは既存契約を維持する。

- Study Activity / AI Practice
- Career Workspace
- Artifacts / Resources
- Guided Execution
- Timer fallback

Execution Modeを選び直す必要がある場合は /navigate?plan_id=... へhandoffする。

## Empty Home

Planが存在しない場合、HomeのPrimary ActionはPlan作成。

DOM: data-action-home-create-prompt

Plan一覧や空のRoadmapを先に見せない。

## Collaboration controls

共同計画そのものの一覧をHomeへ展開しない。

data-home-collaboration はcompatibilityを維持しつつ、参加などのmanagement actionだけをcollapsed disclosureに置く。

共同計画の重要な変化はAction Home signalsへ上げる。

## Timeline preview

Homeには直近WorkLogを最大3件だけ表示する。

役割は「最近の動きがある」ことを軽く確認する入口であり、全履歴はTimelineへ渡す。

## Daily context

今日の実績 / 目安残り / streak / behavior state / week summaryはcollapsed「今日の状況」に置く。

これらはNext Actionより上に出さない。

## Existing compatibility

次は維持する。

- Dashboard Guidance / Recommendation logic
- Work Session
- offline snapshot
- Home Surface Preference / Legacy Context Map compatibility
- Plan Surface Engine assets
- Plan-specific Surface Modules

ただしPlan-specific Surface ModulesはPrimary Homeでは描画しない。Execution / Plan contextで再利用する。

## Persistence

DB migrationなし。

追加永続状態なし。

session action_home.plan_statuses のみをstatus transition検出に利用する。

## DOM contract

- data-action-home
- data-action-home-schema="1"
- data-action-home-active-session
- data-action-home-create-prompt
- data-action-home-guidance
- data-action-home-signals
- data-action-home-signal
- data-action-home-continuity
- data-action-home-utilities
- data-action-home-recent

Homeから次を除外する。

- data-dashboard-tab
- per-Plan data-dashboard-panel
- data-plan-card-url

## Non-goals

V51.3では行わない。

- Timeline Achievement Constellation
- Constellation completion event
- Companion Palette内chat
- notification read/unread DB
- status changeの長期履歴
- HomeでのPlan detail browser
- Inbox再設計
- Plan-specific Execution Workspaceの追加再設計

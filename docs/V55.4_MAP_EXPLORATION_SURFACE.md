# V55.4 Map Exploration Surface Reframe

## Goal

V55.4 continues pre-iOS UX Completion by removing the obsolete contract that treats Classic Home and Canovia Map as two interchangeable Home surfaces.

The current product model is:

```text
Home
→ what should I do now?

Workspace
→ what is the current domain state and why?

Map / Explore
→ how is Canovia structured and what is related?
```

Map remains a major Canovia surface, but it is not the default Home.

## Canonical entry contract

Home:

```text
/
route = home
role = Now / Current Action
```

Explore:

```text
/map
route = map.index
role = spatial exploration / whole-system navigation
```

Authentication entry always resolves to Home after the first-run gate.

A legacy Map preference must not redirect:

- login
- authenticated guest middleware
- protected Home links

to `/map`.

## Legacy HomeSurfacePreference

`HomeSurfacePreference` remains temporarily as a compatibility shim because old installed clients may still have:

- cookie `canovia_home_surface`
- localStorage `pacekeeper.ui.home_surface`

V55.4 no longer uses those values to choose the canonical Home route.

```text
HomeSurfacePreference::url()
→ always route('home')
```

No migration is needed.

Old cookie/storage may remain until ordinary browser cleanup. They are inert.

## User-facing settings

Remove:

```text
ホームの既定表示
Classic / Map
```

from Settings.

The user no longer needs to understand Map as a Home preference.

Theme / accent / density remain unchanged.

## Surface navigation UI

The existing compact switcher implementation is retained for layout compatibility but redefined as a surface navigator.

User-facing labels:

```text
SURFACES
Home
Explore
```

It must not say:

- HOME SURFACE
- Classic
- Map as an alternate Home

DOM contract becomes:

- `data-canovia-surface-nav`
- `data-canovia-surface="home"`
- `data-canovia-surface="explore"`

Legacy `data-home-surface-*` UI contracts are retired.

## Map top bar

L0 Map copy explicitly describes Explore:

```text
Canovia Explore
全体像・関係性・過去/共同/実行Contextを空間的に辿るSurface
```

The L0 primary CTA remains a semantic zoom into Execution context but is labeled as exploration rather than as the primary way to start work.

Example:

```text
実行Contextを探索
```

Home remains the place to start the recommended Current Action.

## Shell semantics

Mobile section label:

```text
Explore
```

instead of `Context Map`.

Map fullscreen shell, safe area, Map telemetry, semantic zoom and navigation graph are unchanged.

## JS cleanup

Remove active Home preference behavior from `app.js`:

- no `resolveHomeSurface()`
- no `persistHomeSurface()`
- no rewriting Home links
- no settings preference click handlers

The legacy helper module may remain temporarily for backwards-compatible tests/utilities, but is not mounted by the product runtime.

## Compatibility

Preserve:

- `/map`
- Map projections
- L0/L1/L2/L3 hierarchy
- Space Station
- semantic zoom
- direct node navigation
- Map telemetry
- fullscreen Map shell
- Instant Navigation
- Map personalization
- Roadmap spatial surfaces
- old cookie encryption exception during compatibility window

## Non-goals

V55.4 does not:

- redesign Map nodes
- change Map graph authority
- change Semantic Zoom thresholds
- change Map gestures
- merge Map into Workspace Modes
- make Map the default Home
- delete legacy preference storage immediately
- change Current Action selection

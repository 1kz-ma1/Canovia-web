# V56.2 IPA Official Question Pack

## Goal

Canovia Study Practice should prefer authentic published AP past questions when
the official corpus can satisfy the current practice demand.

V56.2 introduces the first official IPA past-question pack without replacing the
existing Canovia Core derived/original pack.

Canonical order:

```text
Study Phase / Weakness Policy
→ deterministic Question Bank selection
→ IPA official question when coverage is sufficient
→ existing Canovia Core question when official coverage is insufficient
→ Native AI only for remaining uncovered seats
```

AI does not choose the next official question.

## Source

Initial source:

- 令和7年度 秋期 応用情報技術者試験 午前 問題
- 令和7年度 秋期 応用情報技術者試験 午前 解答例
- publisher: 独立行政法人情報処理推進機構 (IPA)

The 2026 CBT transition changes the name `午前試験` to `科目A試験`.
IPA states that the tested knowledge/skills, multiple-choice format, number of
questions and examination time are unchanged.

The source therefore remains valid authentic Subject A practice material.

## Usage boundary

IPA's published guidance states that public past questions may be used in
educational problem sets without individual permission or a usage fee, while
copyright remains with IPA and source attribution is required.

Canovia therefore stores and renders attribution for every official question.

Every question keeps:

- source_type = official
- source_reference
- source year
- source period
- exam code
- source section
- question number
- problem PDF URL
- answer PDF URL
- publisher
- transcription / layout note

The initial pack only normalizes PDF layout into Canovia's answer UI.
It does not intentionally rewrite the tested meaning.

This is a content limitation, not an exam-policy limitation.

## Selection priority

Question Bank currently selects one matching published Pack for a practice
request.

V56.2 adds Pack metadata:

```json
{
  "selection_priority": 100
}
```

The coverage resolver uses this only after:

1. qualification match
2. whether the Pack is actually available for the current requested count/focus

Therefore:

```text
official Pack available
→ official Pack preferred

official Pack lacks enough matching weakness questions
→ existing Canovia Core Pack may win

neither Pack fully covers demand
→ Hybrid leaves uncovered seats for Native AI
```

A high priority Pack cannot override an unavailable Pack decision.

## General Practice

For V56.0 General Practice / Exam Mode the official Pack has enough questions to
supply a 10-question block.

The existing balanced selector is reused.

Each official question's first broad tag is one of:

- テクノロジ
- マネジメント
- ストラテジ

so the existing domain round-robin can spread General Practice across the
available official domains.

## Attribution UI

The existing Study Practice question UI already renders:

```text
出典：{source_reference}
```

V56.2 reuses that path.

No separate legal banner or management UI is required.

## No AI dependency for selection

The selection decision remains deterministic:

```text
V56.0 phase
+ question mix
+ focus topics
+ Pack coverage
+ Pack priority
+ recent question avoidance
+ domain round-robin
```

AI is used only if Hybrid assembly still has missing seats.

## Compatibility

- no database migration
- existing Question / QuestionPack schema reused
- existing Canovia Core pack preserved
- existing published Pack behavior unchanged when selection_priority is absent
- absent priority defaults to 0
- official Pack is imported through the normal bundled Draft → Review → Publish gate

## Tests

V56.2 must verify:

1. official bundled Pack is discoverable
2. 35 official questions import as Draft
3. every question is source_type=official
4. every question has source attribution and provenance
5. official answers match the published answer key
6. official Pack wins General Practice when both official and Core Packs are available
7. Core Pack still wins a narrow weakness request when official coverage is insufficient
8. selected rendered questions expose source_reference
9. no Native AI is needed when official General Practice coverage is sufficient
10. existing Question Bank / Hybrid / V56.0 tests remain green

## Non-goals

V56.2 does not add:

- all historical AP years
- diagram/image question support
- automatic PDF scraping in production
- AI-selected official questions
- Subject B official corpus
- automatic online source refresh
- unrestricted third-party question import

Those can be layered after the first official Pack is validated in real AP use.

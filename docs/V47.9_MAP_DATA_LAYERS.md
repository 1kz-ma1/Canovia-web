# V47.9 Map Data Layers MVP

## 目的

Classic UIが持つ「進捗・期限・状態などを一覧で素早く確認できる」強みを、Mapを情報カード化せずに吸収する。

基本形は:

```
Clean Map
  + 必要なData LayerだけON
```

とする。

Node本文はNavigation / 意味の識別に使い、補助データは任意Overlayとして重ねる。

## MVP Layers

V47.9で扱うLayer:

- 進捗
- 期限
- 状態
- Evidence
- Dependency
- 優先度

担当者はTaskにcanonicalな担当者fieldが存在しないため、MVPでは表示しない。PlanArtifactのassigned_user_id等をTask担当者として推測しない。

## Canonical source

`MapDataLayerProjectionService` が既存Map Projectionへpresentation-onlyの `overlay` metadataを付与する。

Task:

- `progress_percent`
- `status`
- `evidences()->count`
- `dependencyIds()`
- `priority`

Plan:

- `deadline`
- `priority`

人間向けsummary文字列はparseしない。

DB更新、Migration、新Entityは行わない。

## 推測禁止

Data Layerは事実表示だけを行う。

以下は推測しない。

- Dependencyがある → blocked
- Next Task → ready
- deadlineが過去 → overdue
- Evidenceが存在 → progress増加
- GitHub merge → Task完了
- CI failure → progress減少
- priority値 → AI recommendation理由

`ready / blocked / overdue` 等のderived stateをoverlayへ追加しない。

## Projection contract

Nodeに表示可能なcanonical dataがある場合:

```php
'overlay' => [
    'progress' => ['percent' => 40],
    'status' => ['value' => 'doing', 'label' => '進行中'],
    'evidence' => ['count' => 1],
    'dependency' => ['count' => 1, 'task_ids' => [123]],
    'priority' => ['value' => 2, 'label' => 'P2'],
]
```

Plan deadline:

```php
'deadline' => [
    'date' => '2026-10-31',
    'label' => '10/31',
]
```

Graph rootには:

```php
'data_layers' => [
    'schema_version' => 1,
    'available' => [...],
    'default_enabled' => [],
]
```

を追加する。

## Default

全Layer OFFをdefaultとする。

Mapを開いた瞬間はV47.8/V47.7までのClean Mapを維持する。

ユーザーが `表示情報` controlから必要なLayerだけONにする。

## Device-local preference

設定は:

`canovia.map.data-layers.v1`

としてlocalStorageへ保存する。

schema versionは1。

壊れたJSON / version mismatchは安全にdefaultへ戻す。

保存するのは全Map depth共通のLayer preferenceであり、現在の階層に存在しないLayerも保存から消さない。

例:

- L3で進捗ON
- L2で期限ON
- L3へ戻る

この場合、進捗ONを維持する。

Plan / Taskのcanonical stateへ表示設定を保存しない。

Map Page / Preset導入時にこのpreferenceを統合できる構造とする。

## UI

Control:

`resources/views/map/partials/extensions/surface-controls.blade.php`

Node Overlay:

`resources/views/map/partials/node-data-layers.blade.php`

CSS:

`resources/css/map/data-layers.css`

JavaScript:

`resources/js/map-data-layers.mjs`

OverlayはNodeの子要素として描画するため、#153のmobile box fitting後もNodeと一緒に移動する。

pointer-eventsは持たず、Leaf click / drag / pinch / Semantic Zoomを阻害しない。

## Visual forms

- progress: percentage + small progress ring
- deadline: compact date badge
- status: explicit status label
- Evidence: count badge
- Dependency: explicit prerequisite count
- priority: P1/P2... badge
- Dependency edge: explicit `blocks_until_done` / `dependency` edgeだけ強調

Layer OFF時はbadgeをDOMから削除せずCSSで非表示にする。

## #153 presentation compatibility

Primary Taskは引き続きCanvas上で:

`おすすめ`

だけを表示する。

具体Task名はDetail Paletteへ置く。

Data Layerはその本文契約を変更しない。

非Primary Leafの具体名＋短い役割表示も維持する。

## V47.8 compatibility

Global Navigationのowner fileへ変更を加えない。

- `extensions/global-navigation.blade.php`
- `css/map/navigation.css`

はV47.9では変更しない。

Data Layer controlは別extension boundaryを使う。

## Non-goals

- Map Page / Preset
- user account/server側Layer preference
- 担当者推測
- derived ready/blocked/overdue
- Roadmap Map
- Space Station再設計
- drag & drop
- AI layout
- billing / entitlement

## Verification contract

Tests should cover:

- canonical values projected correctly
- canonical state remains unchanged
- unsupported derived states are absent
- default OFF
- localStorage invalid value recovery
- cross-depth preference retention
- recommendation stays role-only
- Global Navigation remains present

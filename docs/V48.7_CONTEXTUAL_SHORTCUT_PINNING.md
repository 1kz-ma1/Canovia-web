# V48.7 Contextual Shortcut Pinning

> **V48.8 update:** automatic candidate setに既存Reflection Lens「最近の実績」を追加した。V48.7のContextual Pinは引き続きPersonal Planだけを対象とし、Reflection Shortcutはautomatic attentionのみ。詳細は `docs/V48.8_REFLECTION_CANDIDATE_EXPANSION.md` を参照。

## 目的

V48.6でserver-side Pin contractは完成したが、Pin操作は既にL0へpromotionされたPersonalized Shortcutからしか到達できなかった。

そのためsignalが弱くShortcutがまだ存在しないPlanは、技術的にはPin可能でもUIから固定できない。

V48.7では、既存のL2 / L3 Plan ContextからL0 Shortcut Pinを管理できるようにする。

## Principle

Pin候補を増やすのではない。

既存のPersonal Plan candidate identityを、canonical Plan Nodeから操作可能にするだけ。

```text
L2 / L3 Plan Node
        ↓
shortcut_pin presentation metadata
        ↓
Pin / Unpin
        ↓
V48.6 account preference
        ↓
L0 Personalized Shortcut Projection
```

Plan / Task自体は変更しない。

## Contextual projection

`MapShortcutPinProjectionService` がlevel-specific Projectionの後にPlan Nodeへpresentation-only metadataを追加する。

対象:

- type = plan
- user自身がowner
- Personal Plan

Shared Planには付与しない。

metadata:

```text
shortcut_pin:
  node_id
  eligible
  pinned
  status
```

status:

- available
- pinned
- inactive

## Eligibility

V48.6と同じ。

eligible:

- user自身のPersonal Plan
- 未完了Taskを1件以上持つ

Pin済みPlanがeligibilityを失った場合:

- L0 Shortcutには出さない
- preferenceは自動削除しない
- Plan Contextでは `inactive` として表示
- ユーザーが固定を解除できる

これによりsilent preference mutationを行わない。

## UI

eligible + not pinned:

- 「このPlanを全体へ固定」

eligible + pinned:

- 「全体Mapの近道として固定されています」
- 「全体への固定を解除」

inactive + pinned:

- 「固定設定は残っていますが、現在は全体Mapの表示対象外です」
- 「全体への固定を解除」

Pin / Unpin後のredirectはV48.6と同じくL0。

目的は操作結果としてShortcutが出た / 消えたことを即確認できるようにすること。

## Projection key

Plan Context上のPin stateもLiving Map / Instant Navigationでstale表示しないよう、shortcut pin metadataをProjection keyへ含める。

absolute positionやcanonical graph relationは変更しない。

## Privacy

保存先はV48.6の既存account preferenceのみ。

追加保存しない:

- Plan title
- Task title
- signal values
- score
- absolute position
- user content

なし。

V48.6の `users.map_personalization_preferences` を再利用する。

## Non-goals

- candidate種の追加
- Task-bound ToolのL0昇格
- Shared PlanのShortcut化
- AI layout
- automatic Pin
- absolute position保存
- drag & drop
- canonical Plan / Task mutation

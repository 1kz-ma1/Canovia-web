# V47.5 Semantic Zoom Spatial Continuity

## 目的

V47.3で確立した「Container Node本体 = Semantic Zoom」を、
画面切替としてではなく **選択したNodeの内側へ潜る空間操作**として知覚できるようにする。

V47.5ではNavigation Graphやcanonical dataを変更せず、
Map Projection間の短命なvisual continuityだけを追加する。

## Interaction

### Zoom In

Container Nodeをクリックしたとき:

```text
clicked Node
  -> departure toward Map center
  -> next Projection arrives
  -> same semantic Node if present, otherwise next center Node
  -> surrounding Nodes / Edges emerge
```

優先するarrival anchor:

1. 次Projectionに同じNode IDが存在する場合はそのNode
2. 存在しない場合は `data-map-is-center=1` のcenter Node
3. geometryを解決できない場合は既存shell-level Semantic Zoom animationへfallback

これによりL2 Plan -> L3でPlanがCurrent Taskへ「変身」して見えることを避ける。
L3に同じ `plan:<id>` が存在する場合はそのPlan Nodeをcontinuity anchorとして使い、
Current Task / Tool / Evidence等が新Projectionとして周囲に現れる。

### Zoom Out

戻る操作では現在Projectionのcenter Node geometryをdeparture sourceとする。

遷移先では、遷移前routeへSemantic ZoomするNodeをstructural URLで検索する。

```text
current center
  -> parent Projection
  -> Node whose zoom-in destination == previous structural route
```

一致Nodeを解決できない場合は既存shell-level zoom-outへfallbackする。

## Transition Payload

`sessionStorage` の既存 `canovia.map.semantic-transition.v1` を拡張する。

保持可能:

- direction
- from_depth
- left_at
- from_route
- source_node_ref
- source_rect
  - left
  - top
  - width
  - height
  - viewport_width
  - viewport_height

保持禁止:

- Plan / Task title
- description
- Evidence summary
- user input
- AI output
- Artifact title / URL本文
- Node label / subtitle

`from_route` と `source_node_ref` はMap hierarchyを接続するstructural referenceとしてのみ使用する。
payloadはarrival時に即削除し、10秒を超えたstale payloadも削除する。

DB、cookie、BehaviorEvent、Projection Keyにはgeometryを保存しない。

## Geometry

Departure時のNodeは現在のviewport座標を `getBoundingClientRect()` から取得する。

Arrival時はviewport sizeが変わっている可能性があるため、
source rectを新しいviewport比率へscaleしてからtarget rectとの差分を計算する。

transform:

- x = source center x - target center x
- y = source center y - target center y
- scale = sqrt(source area / target area)

scaleは `0.52 .. 1.9`、x/y translationは各 `±2400px` へclampし、
極端なNode size差やsessionStorage改変で画面全体を覆うtransitionを防ぐ。

## Visual Sequence

### Departure

- selected anchorだけz-indexを上げる
- zoom-inではMap center方向へ少し拡大
- zoom-outでは少し縮小
- sibling Node / Edgeはopacityを下げる

### Arrival

- anchorはsource geometryからcanonical positionへ移動
- sibling Nodeは少し遅れてscale + fade-in
- Edgeも遅れてfade-in
- hierarchy orbitもzoom-in時だけemerge

最終座標は常にserver/clientの既存Map layoutであり、
animation終了後にgeometry overrideは残さない。

## Reduced Motion

`prefers-reduced-motion: reduce` の場合:

- node-to-node continuity animationを実行しない
- Nodeのcanonical positionを維持する
- 既存Map操作を阻害しない

## Gesture / Focus Compatibility

V47.3の以下の契約を維持する。

- Pan / Pinch直後でもinteractive Nodeはclick可能
- Focus中に別Nodeへ切替可能
- Context SurfaceはInspector
- Container Node bodyはSemantic Zoom
- gesture runtime transformはDBへ保存しない

Semantic transition中もpointer-eventsを無効化しない。

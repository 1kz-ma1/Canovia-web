# V58.35 Personalization Confidence Calibration

## Goal

Living Profile Candidateの `confidence` を、曖昧な固定値ではなく観測Evidenceの強さから決定する。

V58.35はAI推論を追加しない。現在のdeterministic signalを校正する小さなActive sliceである。

## Contract

High-impact Candidate `development_advanced_support` では:

```text
signal_strength = 1 -> confidence = low
signal_strength = 2 -> confidence = medium
signal_strength = 3 -> confidence = high
```

Candidateには次を保存する。

```text
confidence_calibration.version
confidence_calibration.confidence
confidence_calibration.signal_strength
confidence_calibration.evidence_count
confidence_calibration.basis[]
```

Calibration versionはV58.35で `1`。

## Trust boundary

Confidenceは「自動適用してよい」という意味ではない。

```text
risk = high
-> confirmation_required = true
```

はconfidenceに関係なく維持する。

V58.35は以下を変更しない。

- self-reported Context
- Guidance Level
- experience level
- Plan / Task
- Entitlement / Release Level
- confirmed / dismissed semantics

## Evidence revision compatibility

V58.32のEvidence revision contractを維持する。

- pending Candidateは新しいEvidenceでconfidenceを再校正できる
- dismissed Candidateはsignal strengthが強くなった時だけreopenする
- same-strength fingerprint changeだけではreopenしない
- confirmed Candidateは自動reopenしない

## Release review

Manual review key:

`personalization_confidence_calibration`

Check:

- strength 1 -> low
- strength 2 -> medium
- strength 3 -> high
- calibration metadata persists
- high confidenceでもhigh-risk confirmationは必須
- dismissal / reopen contract is unchanged
- self-reported Context / Guidance remain unchanged

## Migration

None.

## Deferred

- domain-specific calibration policies
- confidence decay over time
- cross-domain evidence weighting
- Guidance Level update candidate
- Plan-direction update candidate

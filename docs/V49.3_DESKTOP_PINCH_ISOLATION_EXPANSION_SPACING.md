# V49.3 Desktop Pinch Isolation / Expansion Spacing

## 目的

V49.2実機確認で、Desktop precision touchpadのpinchが:

- Canovia Map zoom
- Chrome / Browser page zoom

の両方として解釈される余地があり、ユーザーから見ると操作境界が曖昧だった。

特にbrowser page zoomが誤って変わった後もMap側が `Ctrl+wheel` を消費すると、同じpinch gestureでbrowser倍率を戻せない状態になり得る。

またIn-place Semantic Expansionは位置関係を維持できるようになった一方、desktopの展開半径が狭く、Node自身の高さに対してvertical spacingが不足するケースが確認された。

V49.3では:

1. Map上のdesktop pinchをbrowser zoomから分離
2. Browser zoomが変わった場合のescape pathを保証
3. Desktop semantic expansionの余白を拡大

する。

## 1. Desktop pinch isolation

Chrome系desktop browserではprecision touchpad pinchが `Ctrl + wheel` 相当でdeliveryされる。

V49.2まではMap Shellのbubble listenerで:

```js
event.preventDefault()
```

していた。

V49.3ではMap page mount中、document capture phaseで先に判定する。

条件:

- `ctrlKey = true`
- event cancelable
- targetがcurrent Map Shell内
- browser zoom recovery modeではない

この場合のみdefault browser zoomを抑止する。

Map Shell外のgestureはbrowserへ渡す。

### Keyboard / browser menu

以下は奪わない:

- Ctrl + +
- Ctrl + -
- Ctrl + 0
- Browser menu zoom

つまりMap surface上のprecision pinchだけをMap gestureとして扱う。

## 2. Browser zoom recovery mode

JavaScriptからbrowser page zoomを強制的に100%へ戻すことはしない。

Map mount時の `window.devicePixelRatio` をbaselineとして保持する。

```text
current DPR / baseline DPR
```

の差が8%を超えた場合:

```text
data-map-browser-zoom="external"
```

とし、Mapは `Ctrl+wheel` を消費しない。

これによりユーザーは同じpinch gestureでbrowser page zoomをbaselineへ戻せる。

baseline付近へ戻るとMap pinch captureを再開する。

### 意図

```text
Normal
pinch on Map
 -> Map zoom
 -> Browser zoom is prevented

Unexpected browser zoom
 -> DPR changes
 -> Map releases Ctrl+wheel
 -> user pinches browser back
 -> DPR returns to baseline
 -> Map capture resumes
```

### 制約

Map mount前からbrowser zoomが変更済みの場合、その倍率をbaselineとして扱う。

これはユーザーが意図的に125%等を利用している可能性があるためで、Canovia側から100%を推測・強制しない。

## 3. Expansion spacing

V49.2:

- desktop factor: 0.62
- mobile factor: 0.72

V49.3:

- mobile / PWA: 0.72 unchanged
- desktop normal height: 0.80
- desktop viewport height <= 720px: 0.84

計算式自体は変更しない。

```text
child = source + (child - targetCenter) * factor
```

factorを大きくすることでselected boxからchildまでのlocal radiusを広げる。

### 理由

1365x637級のdesktop viewportでは、0.62だとvertical child distanceがNode card heightと近くなり:

- selected parent
- project item
- create item

等が視覚的に重なる。

低いdesktop viewportだけ0.84まで広げることで、PWAの良好な配置を変えずにdesktopのみ改善する。

## 4. Input precedence

Map Shell内では:

### Ctrl+wheel / precision pinch

Map zoomを優先する。

input / textarea上でもpinchはMap gestureとして扱う。

### ordinary wheel

従来どおり:

- input / textarea: controlへ
- workspace palette: card scroll
- map scene: camera pan

を維持する。

## Persistence

新規永続化なし。

browser zoom baseline / recovery stateはcurrent Map runtimeのみ。

TelemetryへDPR / browser zoom倍率を保存しない。

## Migration

なし。

## Non-goals

- Browser zoomをJSから強制reset
- Browser menu / keyboard zoom無効化
- Mobile PWA gesture変更
- Map Single-Surface Architecture
- absolute camera persistence
- absolute Node position persistence

# V51.9.8 Web Real-device Finish

## Purpose

Web版をiPhone実機で仕上げる最終段階として、Primary Surface共通のmobile shell / horizontal rail / virtual keyboard / constellation swipe挙動を安定化する。

このversionでは機能追加よりも「iPhoneで触ったときに邪魔になる小さな違和感」を減らすことを優先する。

## 1. Safe-area and mobile dock clearance

Canoviaはすでに `viewport-fit=cover` とtop/bottom safe-areaを持つ。

V51.9.8ではさらに:

- mobile header left/right paddingへ `safe-area-inset-left/right`
- mobile tabbar left/right insetへ `safe-area-inset-left/right`
- mobile main content bottom clearanceをsingle token化
- `html.scroll-padding-bottom` をmobile dock clearanceと同期

する。

`--canovia-mobile-dock-clearance`:

`calc(7rem + env(safe-area-inset-bottom))`

これにより:

- anchor / scrollIntoView targetがbottom tabbarの裏へ入りにくい
- landscape notch端末でもheader/tabbarがphysical safe areaへ入り込まない
- Primary Surface間でbottom clearanceがずれにくい

## 2. Virtual keyboard behavior

fixed bottom tabbarはフォーム入力中には操作対象ではない。

VisualViewport APIが利用できる場合:

1. focus targetがinput / textarea / select / contenteditable
2. baseline viewportとの差が120px超

をvirtual keyboard openと判定する。

open中:

- `html[data-canovia-keyboard="open"]`
- mobile tabbarをopacity 0 + pointer-events none + translateY
- main bottom paddingをkeyboard向けに縮小

とする。

focusout / VisualViewport resize / orientation changeで状態を再評価する。

VisualViewport非対応browserでは従来挙動のままfallbackする。

## 3. Horizontal rail contract

以下のPrimary horizontal railsをiOS touch scroll前提で統一する。

- Home guidance
- Home active focus deck
- Home attention rail
- Execution mode switcher
- Execution Plan switcher
- Execution recommendation rail
- Constellation Task Group rail

共通:

- `-webkit-overflow-scrolling: touch`
- `overscroll-behavior-inline: contain`
- `touch-action: pan-x pan-y`

Card/item系には `scroll-snap-stop: always` を追加する。

目的はnested horizontal railで:

- page vertical scrollを失わない
- rail overscrollが隣Surfaceへ伝播しにくい
- fast swipeでもsnap pointを飛びすぎない

こと。

## 4. Constellation Plan swipe interruption

Selected Constellation graphのPlan swipeはsingle-touch gestureだけを扱う。

追加:

- multi-touch開始時はgesture state reset
- `touchcancel` 時もreset

iOSのgesture cancellation後にstale startX/startYが残り、次のtouchendで誤切替する可能性を閉じる。

既存threshold:

- horizontal >= 72px
- vertical <= 48px
- interactive element startはignore

は維持する。

## 5. Long copy resilience

mobile実機で長い日本語Task名 / Next Actionがcard横幅を押し広げないよう、主要Surfaceへ:

- `overflow-wrap: anywhere`
- `text-wrap: pretty`
- `min-width: 0`

を追加する。

対象:

- Home guidance/focus/attention
- Execution recommendation
- Constellation Task item/detail heading

## 6. Compatibility boundary

- Instant Navigation routing
- Constellation Plan switching URL

- Service Worker

- DB schema

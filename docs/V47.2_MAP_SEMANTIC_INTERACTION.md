# V47.2 Map Semantic Interaction

## 目的

Canovia MapのNodeクリックを「Contextを選択してから別ボタンで進む」操作から、
**Nodeの意味に応じてその場で次の抽象度へ進む空間操作**へ整理する。

V47.2ではMapのNavigation Graphやcanonical dataを作り直さず、
既存のSemantic Zoom / Focus / Context Surface / Spatial Memoryの責務を整理する。

## Interaction Contract

### Container Node

次の階層を持つNodeはContainerとして扱う。

- L0 Intent
- L1 Domain / Collaboration Purpose
- L2 Plan / internal Collaboration Item
- Personalized Satellite等、明示されたdirect navigationを持つNode

`navigation_kind=zoom-in` のContainer Nodeは、Node本体のクリックをSemantic Zoomとして扱う。

```text
Node click
  -> Semantic Zoom
  -> clicked NodeのContextが次階層のcenterになる
  -> より具体的なNode / Actionが周囲へ展開される
```

右下の「潜る」chipは明示的なaffordanceとして残すが、Navigation Gateにはしない。

### Leaf Node

Execution Task / Evidenceなど、現在のProjection内で詳細確認や複数操作を持つNodeは従来どおりFocus対象とする。

```text
Leaf Node click
  -> Focus / selection
  -> Context Inspector
  -> detail / secondary action
```

Context SurfaceはV47.2以降、階層Navigationの前提操作ではなく **Context Inspector** として扱う。

### Direct / External Node

`direct` / `satellite` / `external` の明示Navigationを持つNodeはNode本体から直接destinationへ進める。
external destinationは従来どおり別tabで開き、Canovia canonical stateを暗黙変更しない。

## Focus Switch

Focus中に表示されている別Nodeをクリックした場合、一度全体表示へ戻る必要はない。

```text
Focus A
  -> click B
  -> selected/focus = B
  -> Inspector = B
```

同一Projection内のFocus切替では新しいBack履歴を積まず、現在のFocus history entryをreplaceする。

## Gesture直後のClick

Pan / Pinch後のghost click抑止はMap Sceneの非interactive backgroundだけへ適用する。
以下は抑止期間中でも即時操作可能とする。

- Map Node
- Zoom / Reset controls
- Spatial Dock
- link / button / form controls

これにより、ズームやパン直後に別Nodeを押しても反応しない症状を防ぐ。

## Collaboration Empty Projection

共同PurposeへSemantic Zoomした結果、該当Itemが0件の場合でもcenter Nodeだけのdead-end Projectionにはしない。
Projection-onlyのNEXT OPTIONを周囲へ出す。

- 共同Planを確認
- Space Stationで整理

これらはDB Entityではなく、その時点のNavigation Projectionである。新しいcanonical recordは作成しない。

## Spatial Memory

既存のMap -> Map Instant Navigationとsemantic departure / arrival animationを維持する。
親Nodeを選択したときに、その意味Contextを次画面の中心として見せることで、
「別画面へ移動した」よりも「そのNodeの内側へ入った」と認識できる遷移を優先する。

V47.2ではabsolute positionやnavigation historyをDBへ保存しない。

## Compatibility

- Navigation Graph / Attention State separationは維持
- L3 Execution semanticsは維持
- Living Reevaluation / Projection Keyは維持
- Space Station Spatial Dockは維持
- ReflectionのDomain -> Plan hierarchy自体はV47.2では変更しない
- external Tool stateを推測しない
- 新しいAI判断を追加しない

## Non-goals

- Map専用canonical Entityの追加
- Node positionの永続化
- Reflection専用Navigation Graphの新設
- Map全体のvisual redesign
- AIによるlayout生成
- payment / billing / entitlement変更

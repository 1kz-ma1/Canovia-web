# V49.2 In-place Semantic Expansion

## 目的

V49.0 / V49.1でContinuous Semantic Zoomを導入したが、Projection切替時のSpatial Continuityは:

1. 選択Nodeを画面中央へ移動
2. 旧兄弟Nodeを消す
3. 次Projectionを中央基準で再構成

という挙動だった。

そのため操作感は「ズーム」より:

> 箱を選んだら箱が中央へ飛び、別画面へ切り替わる

に近かった。

V49.2ではSingle-Surface Architectureへ移行する前段として、URL / Projection境界を維持したまま見え方を:

> 箱へ近づく → 箱はその場に残る → 一段具体的な内容が箱の中から展開する

へ変更する。

## Interaction model

### Before

```text
A   B   C

zoom B
   ↓

        B
     /  |  \
   b1  b2  b3
```

Bが画面中央へ移動し、A/Cは消える。

### V49.2

```text
A       B       C
       zoom
        ↓
A    [ B ]      C
      ↙ ↓ ↘
    b1 b2 b3
```

- Bのworld positionを維持
- A / Cの位置もambient contextとして維持
- B配下だけをBの近傍へ展開
- camera transformも引き継ぐ
- 次Projection全体を中央へrecenterしない

## Selected box anchoring

V47.5ではdeparture時に:

```text
viewport center - selected node center
```

を計算してselected Nodeを画面中央へtranslateしていた。

V49.2ではこのtranslateを廃止する。

departure時:

- x translation = 0
- y translation = 0
- zoom-inは1.045程度のpulseのみ
- sibling / edgeを完全に消さない

Nodeはworld上の同じ場所に留まる。

## Child projection placement

次Projectionのserver-side座標contractは変更しない。

client runtimeでarrival時に:

1. 前levelで選ばれたNodeのworld positionを取得
2. 新Projectionのcenter Nodeをその位置へ合わせる
3. centerからchildまでの相対ベクトルを縮小
4. childをselected box周辺へ展開

計算:

```text
child_x = source_x + (child_x - target_center_x) * factor
child_y = source_y + (child_y - target_center_y) * factor
```

factor:

- desktop: 0.62
- mobile: 0.72

MobileはNode boxが大きいため、desktopより少し広い半径を維持する。

## Ambient sibling context

zoom-in直前のsceneから、selected Node以外の表示NodeとEdgeをcloneする。

このcloneは:

- serverへ送らない
- DBへ保存しない
- sessionStorageへraw contentを保存しない
- current `window` memoryだけに置く
- Instant Navigation後の新sceneへambient layerとして差し込む
- pointer-eventsなし
- current Projection graph / telemetry / focus対象に含めない

目的は操作ではなく:

> さっきまで周囲にあった箱が、その位置にまだ存在している

というSpatial Memoryの維持。

兄弟Contextの直接branch switchingはV49.2のNon-goal。

## Camera continuity

Semantic Transition payloadへ追加するのは数値だけ:

- source map x/y
- camera x/y/scale

camera値は:

- x/y: 0.1px単位
- scale: 0.68〜2.2

に正規化する。

raw title / subtitle / user contentはsessionStorageへ追加しない。

Instant Navigation時は同じcamera transformを次Projectionへ適用する。

fallback full reloadではambient DOM layerは失われるが:

- source position
- camera

はsessionStorageから復元できるため、selected branchのin-place配置は維持できる。

## Child emergence

arrival時のchild Nodeは最終位置で突然fade-inするのではなく、selected box中心から:

```text
opacity 0
scale 0.58
selected box center
    ↓
final child position
scale 1
opacity 1
```

へ展開する。

これにより「別Mapが表示された」ではなく「箱の内容が開いた」ことを表現する。

## Resize / Mobile

Semantic Expansion layout stateはruntime内に:

- selected source world position
- target center Node id
- expansion factor

だけを保持する。

viewport resize / mobile layout recalculation時も、server base layoutを再計算したあと同じlocal expansion transformを再適用する。

absolute coordinatesは永続化しない。

## Zoom-out

zoom-outはV49.1のauthoritative parent routeを維持する。

親Projectionには元の兄弟Nodeがcanonicalに存在するため、ambient cloneは親へ戻る際に破棄される。

cameraはtransition payloadから引き継ぎ、親sceneへ戻ったときも不要な中央recenterを行わない。

## Persistence / privacy

永続化なし。

sessionStorage:

- direction
- source structural node ref
- source rect
- source x/y
- camera x/y/scale
- route/depth

Window-only transient memory:

- sibling visual DOM clone

保存しない:

- sibling title/contentのsessionStorage serialization
- camera DB persistence
- absolute Node coordinates
- AI layout state

## Non-goals

- Map Single-Surface Architecture
- URL hierarchy removal
- 全level同時DOM保持
- ambient siblingの直接操作
- nested ancestor stackの永続保持
- drag & drop layout
- absolute spatial position persistence
- AI layout

V49.2はSingle-Surfaceへ移行する前のUX bridgeであり、canonical Map data modelは変更しない。

## Tests / validation

JS geometry contract:

- selected center remains at prior source position
- child relative radius is compressed
- camera snapshot is numeric and bounded
- child animation origin is selected box center
- V49.1 semantic thresholds remain unchanged

さらにV8で実際の `living-map.mjs` をsyntax compileし、helper outputsを確認する。

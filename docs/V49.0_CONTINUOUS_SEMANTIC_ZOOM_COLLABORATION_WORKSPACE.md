# V49.0 Continuous Semantic Zoom / Collaboration Project Workspace

## 目的

Canovia Mapの階層移動を「別画面へ移動する操作」から、地図アプリのように縮尺によって情報粒度が切り替わる操作へ近づける。

V49.0の2本柱:

- Continuous Semantic Zoom
- Collaboration Project Workspace

## Continuous Semantic Zoom

URL / Projection hierarchyは維持する。L0〜L3を巨大な単一DOMへ常時描画せず、見た目は同じcanvas上のcamera scaleとして連続させ、thresholdを跨いだ時だけInstant Navigationで次Projectionへ交換する。

### Camera / gesture

- runtime transform: `translate3d(x, y, 0) scale(scale)`
- scale: 0.68〜2.20
- Desktop trackpad two-finger scroll: pan
- Desktop precision pinch: Ctrl+wheelをpointer中心zoomとして処理
- Mobile / touch: Pointer Eventsのone-finger pan / two-finger pinch
- camera pan / scale / pinch midpointは永続化しない

### Semantic threshold

- `scale >= 1.62`: zoom in
- `scale <= 0.72`: zoom out
- それ以外: 同じsemantic level

zoom-inはfocus pointへ最も近い`direction=in` Nodeを選ぶ。zoom-outはcurrent center Nodeの`direction=out`を優先する。destinationが存在しない場合は同levelに留まる。

### Click / tap

Container Nodeのclick / tapも既存Semantic Zoom routeを使う。cached projectionでもcamera movementが見えるよう、Reduced Motion以外ではdestinationをprefetchし、selected Nodeをcenter方向へ動かした後、120msでProjectionを交換する。arrival時はV47.5 geometry continuityを継続する。

## Collaboration Project Workspace

V44.5〜V48.9のPurpose-first構造をProject-firstへ変更する。

```text
L0 共同
  -> L1 Shared Projects
       -> Project A
       -> Project B
       -> + 共同計画を作る
            -> L2 Project Workspace
                 -> 制作ファイル / 成果物 Palette
                 -> 参加メンバー Palette
                 -> 最新情報 Palette
```

共同Planが1件だけでもL1 Project selectionを維持する。これにより共同という場所の直下にProjectがあるmental modelと、常設の+ Project導線を固定する。

### L1 Shared Projects

閲覧可能な`is_collaborative=true` Planを直接表示する。Project Nodeにはrole / member count / review count / waiting count等のstructural summaryを表示できる。

`+ 共同計画を作る`は既存`/plans/create/manual?collaborative=1`へ遷移し、logged-in userでは既存Plan formの共同計画checkboxを初期ONにする。新しい作成flowは増やさない。

### L2 Project Workspace

selected Shared Planだけをsemantic centerとして残し、operational informationはPalette layerとして表示する。Map Sceneは低opacityで背後に残し、Projectの空間Contextだけ維持する。

V49.0 MVP Palette:

- 制作ファイル / 成果物
- 参加メンバー
- 最新情報

この3カードはMap用に複製せず、Classic Collaboration画面からshared Blade partialへ切り出し、ClassicとMapの両方で同じpartialをrenderする。

Desktopでは成果物を大きく、右にメンバー / 最新情報を配置する。Mobileでは1列vertical scrollへ落とす。

### Review Waiting Shortcut

V48.9 Review Waiting Satelliteはexplicit `collaboration_state=review` truthを維持する。destinationはL2 Purposeではなく、review itemを持つProjectだけに絞ったL1 Shared Project selectionへ変更する。GitHub URL等からreview状態を推測しない。

## Permissions / Projection

既存PlanOwnershipServiceを維持する。閲覧不可能なShared PlanはProject candidateにならない。L2 Projection Keyにはselected plan ID、member/artifact/activity count、latest artifact/activity timestampのstructural digestを含め、Palette更新のstale表示を防ぐ。

## Non-goals

- 全hierarchyの単一DOM常時展開
- camera position永続化
- AI zoom target selection
- inertia / momentum physics
- Palette drag & drop / absolute position persistence
- GitHub remote status inference
- collaboration state自動Mutation
- Classic Collaboration廃止
- Task / Artifact canonical model変更

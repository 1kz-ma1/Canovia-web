# V58.64 — 公式試験範囲と本人の未測定理解度を分離

## 原因

旧Studyロジックは`confirmed_scope_count=0`を無条件に`capture_scope`と解釈し、
応用情報技術者試験（AP）でも「試験範囲を確定する」を最優先推薦した。
これは「ユーザーがCanoviaに登録した範囲がない」事実を「公式試験範囲は未確定」に取り違えたもの。

## 出所を確認した現行仕様

- 公式情報: IPA `https://www.ipa.go.jp/shiken/syllabus/gaiyou.html`
- AP（レベル3）シラバス: **Ver.7.2**（2026-01-08掲載）。試験要綱: **Ver.5.6**（2026-07-06掲載）。
- 2026年度CBT試験: `https://www.ipa.go.jp/shiken/2026/ap_koudo_sc_kikan.html`
- **2027年度の新試験制度向けシラバス案は、2026年度のAP確定出題範囲ではない**。このSliceでは意図的に扱わない。
- データのローカル登録日・出典・適用年度を`StudyOfficialExamReferenceService`に明示。一般資格すべてへの適用を装わず、**確実に認識できるAPだけ**を先行サポート。

## 実装上の境界

`Plan.title`/`description`でAPを認識し、学習タイプが資格試験である場合のみ
`official_exam_reference`を`StudyIntelligenceStateBuilder`のfactsに供給。

- **official_reference**: IPA公式URL・適用年度・シラバス版・確認日。
- **user_confirmed_scope**: 今までどおり`StudyScopeItem`の本人が明示確認した項目だけ。公式参照ありでも`confirmed_scope_count`は水増ししない。
- **observed_practice**: 本人の演習・Recall Evidenceがない限り理解度は未測定。Exam Readinessを勝手に数値化しない。
- スコープ0件かつAP参照あり: `establish_official_exam_baseline`を第一候補にし、演習できる既存Taskがあれば実行、なければ本人がボタンを押した場合のみTaskを投影して演習へ進む。
- 「試験範囲を確定する」等の古いTaskを診断Taskとして再利用しない。
- School Test等の本人ごとに範囲が異なるPlanは従来どおり`capture_scope`。
- 出典未登録のほかの資格試験では、未確認の公式範囲をあると偽らない。対象は今後レビュー済みカタログへ追加する。
- OverviewのAPセットアップ表示も「理解度未確認」に修正。
- 権限変更・既存Plan/Task/StudyScopeへのバックフィル・自動書換えは行わない。

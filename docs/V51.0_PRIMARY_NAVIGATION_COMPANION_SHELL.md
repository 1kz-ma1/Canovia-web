# V51.0 Primary Navigation & Companion Shell

> **V51.1 implemented:** Constellation Roadmap is now the Primary `/roadmap` presentation. The universe starts unselected, centers Space Station, compresses Tasks into Main Stars, and opens Task Lists only after Star selection. See `docs/V51.1_CONSTELLATION_ROADMAP.md`.
>
> **V51.2 implemented:** Execution is now Mode-aware (Study / Development / Career / General). See `docs/V51.2_EXECUTION_WORKSPACE_MODES.md`.
>
> **V51.3 implemented:** Home is now an Action / Alert Surface rather than a Plan browser. See `docs/V51.3_ACTION_HOME.md`.
>
> **V51.4 implemented:** Timeline now integrates Work / Collaboration / Plan completion events and a compact Achievement Constellation. See `docs/V51.4_TIMELINE_ACHIEVEMENT_CONSTELLATION.md`.

## 目的

Canoviaの各ページ責務を再整理し、Primary Navigationを4つのSurfaceに固定する。

```text
Home
Constellation
Execution
Timeline

+ Floating AI Companion
```

AIは5番目のページとして扱わず、どのSurfaceからでも呼べる横断Control Surfaceとする。

InboxはPrimary Navigationから外すが、機能・Route・データは削除しない。

## Surface Responsibility

### Home

問い:

> 今、何をすればいい？

責務:

- おすすめTask
- 状態変化
- 遅れ
- Plan未作成時の作成促進
- 共同計画の重要な変化
- 再計画や更新が必要な通知

HomeはPlan一覧Navigationを主目的にしない。

Primary route:

`/`

Legacy Map Home preferenceは互換目的で残すが、Primary NavigationのHomeボタンは常にClassic Homeへ入る。

### Constellation

問い:

> 全体はどうなっていて、今どこ？

Primary route:

`/roadmap`

V51.0では既存Roadmapを入口として維持し、V51.1以降でConstellation UIへ置き換える。

将来構造:

```text
Space Station
  ├ Plan creation
  ├ Plan update
  └ management operations

Plan Constellations
  └ Main Stars
      └ Task Groups
          └ Task List
```

Roadmapは「次に何をするか」を決めるSurfaceではない。

### Execution

問い:

> 実際に何を、どう進める？

Primary route:

`/navigate`

V51.0では既存Recommendation / Work Session flowをExecutionの暫定Surfaceとして再利用する。

将来はPlan特性に応じたExecution Modeを持つ。

例:

- Development
- Study
- General
- Career

2種類以上のMode対象Planがある場合は、Execution内または遷移前後でModeを切り替えられるようにする。

### Timeline

問い:

> 何が起きた？何を積み上げた？

Primary route:

`/timeline`

V51.0では現状維持。

将来:

- Constellation completion
- collaborative activity
- achievements
- evidence

との接続を追加する。

### Inbox

役割は再検討中。

V51.0では:

- Route維持
- capture / routing機能維持
- Primary Navigationからのみ外す

### AI Companion

問い:

> 今見ているCanoviaについて相談・操作したい

AIはPrimary Navigationに置かない。

UI:

- Bottom Navigationより少し上の右下Floating Orb
- Tapで大型Palette
- 現在Contextを表示
- Existing Companion Threadへ接続

V51.0ではPalette shellのみを共通化し、会話本体は既存Companion画面へ接続する。

## Primary Navigation Order

Desktop / Mobile共通:

1. Home
2. 星座
3. 実行
4. タイムライン

Nav keys:

```text
desktop-home
desktop-constellation
desktop-execution
desktop-timeline

mobile-home
mobile-constellation
mobile-execution
mobile-timeline
```

旧:

- desktop-inbox
- mobile-inbox
- desktop-roadmap
- mobile-roadmap

はPrimary Navigation contractから外す。

## Instant Navigation

Home / Roadmap / Timeline等のInstant Fragmentでも新Nav keyを返す。

Legacy MapはPrimary Home扱いしない。

Map Fragmentのmobile section label:

`Context Map`

Constellation入口であるRoadmap:

`星座`

## Companion Palette Contract

Shared partial:

`resources/views/layouts/partials/companion-palette.blade.php`

DOM:

```text
data-companion-shell
├ data-companion-palette-open
└ data-companion-palette
   ├ current context
   ├ existing Companion entry form
   └ recent conversations link
```

PaletteはMapを含むPrimary/legacy Surfaceから利用可能。

Focus ModeとCompanion自身の画面では表示しない。

## Companion Context

既存:

- CompanionEntryService
- Thread reuse
- Plan/Task context
- mutation candidate review
- source route/path

を維持する。

V51.0では新しいAI mutation logicを追加しない。

## Onboarding

新規OnboardingはRoadmap/ConstellationでPrimary Surface案内を完了する。

旧 `inbox-nav` / `today-nav` stageは、保存済みOnboarding stateを壊さないためExecutionへ着地させるcompatibility aliasとして残す。

Inboxは新しいPrimary Navigation onboardingには含めない。

## Staged Implementation

### Phase 1 — V51.0

- Primary Navigation 4本化
- InboxをPrimary Navから外す
- Roadmap labelを星座へ変更
- NavigationをExecution暫定Surfaceへ変更
- Floating Companion Palette shell
- Instant Navigation contract更新
- Onboarding互換

### Phase 2 — Constellation Roadmap

- Roadmap専用Map UI
- 中央Space Station
- Plan Constellation
- Plan select / semantic zoom
- Star完成数 `(3/5)`
- Star -> Task List
- completion illumination
- stable spatial layout

### Phase 3 — Execution Workspace

- Execution Mode classification
- Development / Study / General等
- Mode switch
- multiple specialized Plan handling
- current task execution handoff

### Phase 4 — Action Home

- HomeをAction/Alert中心へ整理
- Plan detail navigation densityを下げる
- collaboration notifications
- Plan creation/update prompts

### Phase 5 — Timeline / Achievement

- Constellation completion event
- Achievement Constellation entry
- Timeline integration

### Phase 6 — Companion Deep Integration

- Palette内chat
- current surface context
- contextual shortcuts
- candidate review
- apply flow
- no full-page context loss

## Non-goals of V51.0

- Constellation rendering
- Star generation
- Execution Mode classification
- Home content redesign
- Timeline redesign
- Inbox deletion
- Embedded Palette chat
- Home Surface Preference deletion
- Legacy Map deletion

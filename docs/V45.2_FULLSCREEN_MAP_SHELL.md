# V45.2 Fullscreen Map Shell

## Goal

Canovia Mapを通常ページ内のコンテンツではなく、
画面そのものを占有するNavigation Surfaceとして扱う。

Mapモードでは:

- 通常Desktop Headerを表示しない
- 通常Mobile Headerを表示しない
- Mobile Bottom Navigationを表示しない
- Footerを表示しない
- ページスクロールを使わない
- Map viewportを100dvhで固定する
- 上部のMap専用Top Barだけを固定表示する
- Classic / Map切替をTop Bar右上へ置く

とする。

## Why

V45.0 / V45.1でMobile Map自体は縦長ProjectionとPan / Zoomを持ったが、
通常Page Shell内に置かれていたため、

- Mapへ到達するためにpage scrollが必要
- Mapの位置とbrowser viewportを合わせる操作が必要
- Bottom NavigationがMap viewportを圧迫
- Map panとpage scrollが別操作として共存
- Spatial UIなのに通常Document UIの制約を受ける

という問題が残っていた。

Fullscreen Shellではbrowser pageを固定し、
空間移動をMap Scene内へ統一する。

## Shell boundary

Map route:

`body[data-route-name="map.index"]`

をFullscreen状態のsourceとする。

Map route中だけ:

- body height = 100dvh
- body overflow = hidden
- app-main = viewport fixed
- app-main max width / padding = none

とする。

通常App ShellのDOMは削除しない。

理由:

Instant Navigationで

```text
Classic -> Map -> Classic
```

と遷移した際に、Header / Bottom Navを再生成せず復帰できるため。

Map時だけCSSで以下を非表示にする。

- .desktop-app-header
- .mobile-app-header
- .mobile-tabbar
- footer

Instant Navigationは既存どおり
`document.body.dataset.routeName`を更新するため、
fragment navigationでもFullscreen stateが同期する。

## Fullscreen structure

```text
100dvh
+------------------------------------------------+
| Map Top Bar                                   |
| Current Context                 Classic | Map |
| Breadcrumb / Depth                            |
+------------------------------------------------+
|                                                |
|                                                |
|                 MAP VIEWPORT                   |
|                                                |
|       pan / pinch / semantic navigation        |
|                                                |
|                                                |
+------------------------------------------------+
```

Document scrollingは使わない。

## Map Top Bar

既存Map HeroをFullscreen Top Barへ縮小する。

表示:

- current level kicker
- current Context label
- Classic / Map switcher
- breadcrumb
- hierarchy depth

非表示:

- long description
- Map help prose
- Hero shortcut button group

Hero shortcutはMap Node / Context Surface / breadcrumbと機能が重複するため、
Fullscreen modeでは表示しない。

## Classic / Map switch

既存`home-surface-switcher`を再利用する。

Mapページ内での位置:

- Top Bar right
- always visible
- Map current stateを表示

Fullscreen variantでは:

- HOME SURFACE labelを非表示
- BETA badgeを非表示
- compact pills

とする。

Classicを選択すると既存`route('home')`へ戻る。

HomeSurfacePreferenceのcanonical behaviorは変更しない。

## Hierarchy

V44.3 Semantic ZoomのbreadcrumbをTop Bar内へ移動する。

追加のpage rowとしては持たない。

表示:

- breadcrumbs
- L0-L3 depth track

幅390px以下ではdepth trackを省略し、
breadcrumbを優先する。

Semantic Zoom URL / hierarchy metadataは変更しない。

## Map viewport

Top Barの残り全部をMapへ割り当てる。

```css
grid-template-rows:
  auto
  minmax(0, 1fr)
```

Map Workspace / Shell:

- width 100%
- height 100%
- min-height 0
- border radius 0
- no outer page margin

V45.0の固定rem CanvasはFullscreen routeでは上書きする。

## Gesture model

V45.1をそのまま維持する。

Page scrollがなくなるため、

- 1 finger = Map Pan
- 2 fingers = Pinch Zoom
- + / reset / -
- Node tap

へ操作が明確に分離される。

Pan / Zoom boundsはV45.1から変更しない。

## Context Surface

Desktop:

Context Surfaceをgrid side columnにしない。

Map widthを維持したまま、
右側floating panelとしてoverlayする。

理由:

- Node selectionでMap geometryを動かさない
- Spatial Memoryを維持
- fullscreen viewportを常にMapへ渡す

Mobile:

Bottom Sheetを維持する。

Bottom NavigationがMap modeでは存在しないため、
bottom offsetはsafe-area + small marginまで下げる。

## Space Station Dock

V44.3 Spatial Dockを維持する。

Mobile Bottom Navigation削除後は、
safe-area bottomを基準に右下へ配置する。

## Sync / notices

常設sync-status chipはMap modeでは非表示。

Map reevaluation statusはMap内overlayとして表示する。

Temporary session notice等は必要な場合のみ既存page layerに残せるが、
Map layout rowは消費しない。

## Instant Navigation

Map fragmentには引き続き:

- routeName = map.index
- Map page HTML
- home surface state

を含める。

既存Instant Navigation renderが:

`document.body.dataset.routeName = payload.routeName`

を実行するため、
full page load / instant transitionで同じCSS shell stateを得る。

新しいshell duplicationや第二Navigation systemは作らない。

## Persistence

Fullscreen shell stateはrouteから決定する。

保存しない:

- fullscreen boolean
- viewport height
- topbar size
- page scroll position

Mapを離れると通常App Shellへ自動復帰する。

## Compatibility

変更しない:

- Navigation Graph
- Attention State
- Map Projection
- L0 fixed Intent nodes
- Personalized Satellites
- Collaboration Purpose
- Semantic Zoom
- Mobile Pan / Pinch
- Space Station
- Contextual Classic Surface
- HomeSurfacePreference
- Classic Home
- Instant Navigation URL contract

## Performance boundary

V45.2ではRuntime最適化そのものは行わない。

ただしFullscreen化により:

- page scroll handling
- bottom navとのvisual competition
- context-open時のMap relayout

を減らす。

本格的なMap runtime optimizationはV45.4で扱う。

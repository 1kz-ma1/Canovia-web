# V58.73 Domain-aware typed Evidence → Action Draft

## Implemented slice
Use preexisting TaskEvidence for WorkLog-agnostic proposals:
- Study: explicit exercise, recall, resource and language activity records.
- Development: explicit PR, code, Issue, deployment, CI and quality gate events.
- Career: interview reflection and recorded selection results.
- The allowed types are **per Plan Domain** as determined by existing
  owner-confirmed domain overrides, not by collaboration status or broad
  keyword matching over the evidence.
- Owner sees at most 20 latest eligible typed evidence records; may choose
  1–5 and optionally mix WorkLogs up to five total. Source IDs are enforced
  server-side; another Plan / wrong domain is indistinguishable 404.
- Snapshots include kind, source, event type, original ID, display summary,
  and occurrence time. All facts remain sourced; an external-source label
  is not blanket confirmation that an external event was verified.
- Type-specific suggestions are deterministic **review prompts**, not AI
  interpretations or objective mastery / job-fit assessment.
- Typed additions can be previewed and explicitly committed to an existing
  proposed draft using V58.72 optimistic fingerprint/revision checks. A
  stale preview or edited evidence does not silently rewrite a proposal.
- Task creation remains V58.71 owner-only explicit acceptance, exactly once.
  No automatic changes to existing Tasks, Plan, progress, owner or team.
  No AI requests, additional model costs, or new database tables.

## Constraints and follow-up
Does not yet build a structured multi-task roadmap, does not infer causes,
does not auto-fetch external sources, and does not claim every native event
can be evaluated for correctness. P1.2 is in progress; the bounded optional
AI/structured proposals belong to another slice. P1.3 spotlight untouched.
Production deployment and real-device PWA/WKWebView checks still pending.

# V49.4 Semantic Zoom LOD / Camera-Selection Separation

> **V49.5 update:** Desktop semantic armへ120ms dwell + 1.28 release hysteresisを追加し、semantic open thresholdはdesktopのみ1.46へ変更した。Touch/desktop pinchはgesture開始時のworld coordinateを固定anchorとしてcameraを逆算し、In-place Expansion後だけparent lockedのlocal collision resolutionを適用する。Mobile/PWAのsemantic open 1.42は維持する。詳細は `docs/V49.5_SEMANTIC_ZOOM_STABILIZATION.md` を参照。

## 目的

V49.3までで:

- Continuous Semantic Zoom
- In-place Semantic Expansion
- Desktop pinch isolation
- expansion spacing

は成立した。

一方、実機操作ではまだ:

- cameraを少し拡大したいだけなのにsemantic navigationが発火する
- Node自身までscene scaleで大きくなり「地図」より「DOMを拡大」して見える
- semantic thresholdが不可視で、いつ箱が開くのか予測しづらい

という問題が残った。

V49.4ではSingle-Surface移行前の最後のUX整理として:

1. camera zoomとsemantic selectionを分離
2. Nodeをscreen-space size寄りに補正
3. zoom scaleに応じて情報密度を段階表示

する。

## 1. Camera zoomとSemantic Selectionの分離

### Desktop precision pinch

V49.3まではsemantic thresholdを跨ぐと:

1. pinch中心に最も近いzoomable Nodeを選ぶ
2. そのNodeへsemantic navigation

していた。

V49.4ではdesktopのみ:

> pinch中心が実際にNodeのbounding box近傍にある場合だけ

zoom-in candidateとして扱う。

Node近傍padding:

`28px`

つまり:

```text
空白をpinch
  -> camera zoomだけ

Node付近をpinch
  -> camera zoom
  -> ready LOD
  -> Nodeをarm
  -> semantic thresholdを跨いだら開く
```

となる。

### Mobile / PWA

V49.3時点で操作感に問題が出ていないため、mobile pinchのcandidate selection契約は変更しない。

### Click / Tap

Node本体のclick / tapは明示selectionなので従来どおりsemantic navigationを行う。

### +/- controls

Zoom buttonsは純粋なcamera zoomへ変更する。

- +: camera zoom in
- -: camera zoom out

button操作だけではsemantic levelを切り替えない。

階層Navigationは:

- Node click / tap
- Node近傍へのdesktop pinch
- mobile pinch
- 明示back action

へ限定する。

## 2. Level of Detail

camera scaleを4段階のLODへ変換する。

### overview

`scale < 0.90`

表示:

- glyph
- label

非表示:

- eyebrow
- subtitle
- direct-open action

### context

`0.90 <= scale < 1.16`

表示:

- glyph
- label
- eyebrow

非表示:

- subtitle
- direct-open action

### detail

`1.16 <= scale < 1.34`

表示:

- glyph
- label
- eyebrow
- subtitle
- direct-open actionを薄くpreview

direct-openはまだpointer interactionしない。

### ready

`scale >= 1.34`

表示:

- full Node information
- direct-open action

semantic zoom-in thresholdは既存の1.42を維持する。

そのため:

```text
1.34
  -> 「このNodeはさらに開ける」と視覚的に予告

1.42
  -> Node近傍pinchならsemantic expansion
```

という予兆区間を作る。

## 3. Semantic Armed State

desktop ready LODでpinch中心がzoomable Node近傍に入ると:

`is-semantic-armed`

を付ける。

armed Node:

- border強調
- cyan glow
- direct-openを完全表示

これによりthresholdを跨ぐ前に「この箱が開く」ことを示す。

cameraを引く / panする / 別位置をpinchするとarmは解除する。

## 4. Screen-space Node Sizing

Scene全体はcamera scaleで拡大縮小する。

ただしNode cardにinverse scaleを部分的に掛ける。

計算:

```text
counter = 1 / cameraScale ^ 0.72
```

clamp:

- min 0.62
- max 1.32

最終画面サイズ:

```text
scene scale * node counter scale
```

例:

- camera 1.0 -> Node 1.0x
- camera 2.0 -> counter 0.62 -> Node約1.24x
- camera 0.68 -> counter 1.32 -> Node約0.90x

つまり空間距離は大きく変化するが、Node UIは極端に巨大化・極小化しない。

### Mobile

PWA/mobileではcounter scaleを適用せず1.0とする。

既存の良好なmobile interactionを維持する。

## 5. Interaction Priority

Desktop:

### ordinary two-finger scroll

Map Scene:

- pan

Workspace Palette:

- card scroll

### precision pinch

- browser zoom isolationはV49.3を維持
- camera zoom
- Node近傍ならsemantic arm
- threshold 1.42でsemantic expansion

### click / tap

explicit Node selectionとしてsemantic expansion。

### double click

camera zoomのみ。

### +/- controls

camera zoomのみ。

## 6. Persistence

新規永続化なし。

runtime only:

- current LOD
- node counter scale
- armed Node id

保存しない:

- LOD
- armed state
- camera scale
- proximity target
- raw content

Telemetry contractも変更しない。

## 8. Non-goals

- Map Single-Surface Architecture
- URL hierarchy removal
- mobile gesture contract変更
- semantic threshold撤廃
- Node内容のserver-side LOD projection
- camera永続化
- absolute Node position永続化
- AI target selection

V49.4はSingle-Surface移行前に、現行Projection Architectureの操作感を地図型UIへ近づける最終UX layerとする。

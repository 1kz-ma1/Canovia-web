# V43.4 Map Primary Action Launch

## Goal

Mapを既定Homeとして使う時、Primary Actionが見えているのに実行まで2段階必要な摩擦を減らす。

従来:

Map Overview
→ 今やることを見る
→ Focus
→ Contextual Classic Surface
→ Primary Action

V43.4:

Map Overview
→ そのまま進める
→ existing execution destination

Contextが必要な場合だけ:

Map Overview
→ Contextを見る
→ Focus
→ Contextual Classic Surface

## Architecture boundary

Mapをmutation surfaceにはしない。

追加するのは既存の実行先へ直接移動するnavigationだけ。

Primary Actionの決定は引き続きDashboardGuidanceService由来のMapProjectionを使う。
Map専用の推薦ロジックは追加しない。

## Projection

MapProjectionServiceの返却値へ primary_launch を追加する。

current taskのContextual Classic Surfaceで最優先として既に決定しているactionを、そのままMap Overviewのdirect launchにも再利用する。

recommended toolがある場合:
- そのTool

ない場合:
- Plan

同じ判断を二重実装しない。

## Overview actions

Primary Actionがある時:

- そのまま進める: direct launch
- Contextを見る: Primary NodeへFocus

Focus中はdirect launchをtoolbarから隠す。
Contextual Classic Surface側には従来のPrimary Actionが残る。

## Telemetry

direct launchも既存 map_classic_action_opened を利用する。

metadata:

- action_role = primary
- node_type = task
- position_role = now
- is_primary = true

Focus前でもPrimary Nodeのmetadataを失わないよう、direct link自身へserver-authoritativeな構造属性を埋める。

user text / task titleはTelemetryへ送らない。

pending reevaluationにはPrimary Node IDを保持するため、実行先からMapへ戻った時のLiving Reevaluationも従来どおり機能する。

## Non-goals

- Map上でTask完了
- Map上でWorkSession mutation
- Map上でTask編集
- Map専用Tool推薦
- Focus / Companion / Classic Surfaceの削除

# V51.5 Companion Deep Integration

## 目的

Floating Companion Paletteを単なる入口から、現在のSurfaceを離れずに会話・変更候補確認・反映まで行えるCross-Surface Control Surfaceへ拡張する。

Primary Navigationは引き続き:

- Home
- Constellation
- Execution
- Timeline

の4 Surfaceとし、Companionを5番目のページへ昇格させない。

## UX Contract

Palette内で完結させる範囲:

1. Current Surface Context確認
2. Contextに対応するThreadのopen / reuse
3. Message送信
4. Assistant reply表示
5. Mutation Candidate review
6. Human Confirmによるapply / dismiss
7. Contextual shortcut
8. Full Companion pageへの任意handoff

通常の会話・Candidate確認のために現在のSurfaceから強制遷移しない。

## 1. Existing Logic Reuse

新しいAI conversation pipelineは作らない。

再利用する既存source of truth:

- CompanionEntryService
- CompanionConversationService
- CompanionContextService
- CompanionContinuityService
- CompanionMutationApplyService
- CompanionThread / CompanionMessage / CompanionMutationCandidate
- NativeAiGateway
- FeatureAccessService

Paletteは既存endpointへ `surface=palette` を付けて利用し、server-side rule / authorization / idempotencyを共有する。

## 2. Shared Thread Surface Projection

`CompanionThreadSurfaceService` を追加する。

責務:

- Thread / Messages / Candidate preload
- Context Snapshot
- Continuity signals
- Candidate review preview
- Message request id
- Candidate apply request id
- Source path

Full Companion pageとPaletteが同じprojectionを利用する。

## 3. Palette Open / Reuse

既存 `POST /companion/entry` を再利用する。

Paletteからは:

- entry_type
- plan_id
- task_id
- source_path
- source_route
- surface=palette

を送る。

CompanionEntryServiceの既存thread reuse contractを維持する。

通常request:
- Companion full pageへredirect

Palette request:
- JSON + rendered Palette Thread Fragment

## 4. Palette Message Send

既存 `companion.messages.store` を利用する。

Palette requestではredirectせず:

- updated thread fragment
- status message

をJSONで返す。

Native AI失敗時も現在ページを離れず、Palette内errorを表示する。

request_id idempotencyは既存契約を維持する。

## 5. Candidate Review / Apply

Palette内でCandidateについて次を確認できる。

- candidate title / summary
- target
- allowed changes
- blocked fields
- pending / applied / dismissed

Apply / Dismissは既存endpointを再利用する。

Human Confirm必須は維持する。

Execution Request Candidateをapplyした場合もPaletteを強制close/redirectせず、Executionへのhandoff linkだけ提示する。

## 6. Contextual Shortcuts

Thread contextからread-only shortcutを生成する。

Task context:
- Execution
- Task edit
- Plan Dashboard

Plan context:
- Execution
- Plan Dashboard

Global context:
- Home
- Constellation
- Execution
- Timeline

ShortcutはAI mutationではない通常Navigation。

## 7. Current Surface Context

Palette shellは既存:

- source route
- Plan
- Task
- entry type

を維持する。

Threadを開いた後はContext Snapshotから:

- scope
- Goal Context
- recent Evidence count
- pending Inbox count

をcompact表示する。

## 8. Progressive Enhancement

JavaScript有効時:
- Palette内非同期interaction

JavaScript無効時:
- 既存full-page Companionへのfallbackを維持する

既存Companion pageは削除しない。

## 9. Instant Navigation

Palette runtimeは:

- full load
- canovia:page-ready

の双方でmountする。

非同期fragment replacement後はevent delegationを使うため個別remount不要。

Instant NavigationでCurrent Surface Contextが変わった場合、新しいshellのentry formをsource of truthとする。

## 10. Security / Mutation

変更しない:

- thread ownership
- Plan / Task authorization
- Feature entitlement
- Native AI entitlement
- Candidate whitelist
- Human Confirm
- apply idempotency
- AI generated IDs discard
- Task progress / completionの直接変更禁止

## 11. DOM Contract

追加:

- data-companion-palette-session
- data-companion-palette-async-form
- data-companion-palette-status
- data-companion-palette-messages
- data-companion-palette-candidate
- data-companion-palette-compose
- data-companion-palette-suggest
- data-companion-palette-shortcuts

## 12. Persistence

DB migrationなし。

既存Companion Thread / Message / Candidateだけを利用する。

Palette専用のconversation stateは保存しない。

## Tests

最低限:

- Palette entry returns fragment without redirect
- existing normal entry redirect remains
- Palette message send returns updated conversation fragment
- Candidate remains unapplied until human confirm
- Palette apply uses existing whitelist and marks candidate applied
- Palette dismiss marks candidate dismissed
- Execution candidate returns handoff URL without forced redirect
- ownership isolation
- Palette DOM contract
- JS uses fetch and does not navigate for Palette form
- Instant Navigation still mounts Palette

## Non-goals

- streaming token UI
- voice conversation
- background autonomous mutation
- Companion as fifth primary page
- full Companion page deletion
- cross-device live synchronization
- automatic candidate apply

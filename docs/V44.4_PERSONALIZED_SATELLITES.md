# V44.4 Personalized Satellites

> **V45.6 update:** この文書はV44.4時点の初期仕様を記録しています。現在のL0 Satellite運用はV45.6で「最大2件・threshold 0.55・同一Intent 1件・Shared Plan除外・Task-bound Tool除外」へ更新されています。最新方針は `docs/V45.6_MAP_SIGNAL_DENSITY.md` を参照してください。

## Goal

固定L0 Intent Hubを壊さず、ユーザーが実際によく使う既存Contextを
最大4件までSatelliteとしてL0へ昇格する。

Satelliteは新しいcanonical entityではない。

```text
existing Plan / Tool
  ↓
candidate signals
  ↓
promotion score
  ↓
L0 Satellite attention
```

Satelliteから外れても元のPlan / ToolはCanovia内に存在し続ける。

## Principle

Navigation GraphとAttention Stateの境界を維持する。

固定L0 semantic graph:

- Space Station
- 計画
- 実行
- 振り返り
- 共同

はRecommendationや利用履歴で増減させない。

Personalized Satelliteは
「既存ContextをL0へpromotionするAttention表現」とする。

原則:

> おすすめだからEntityが存在するのではない。  
> よく使う / 重要だからSatelliteとして近くに現れる。

## Candidate sources

### Plan

未完了Taskを持つ、現在アクセス可能なPlanをcandidateにする。

Shared Planも同じPlan candidateとして扱うが、
importanceへ小さなcollaboration boostを加え、
L0では共同Intentへanchorする。

Plan Satelliteのdestinationは、
そのPlanを指定したL3 Execution Map。

```text
/map?level=l3&intent=...&domain=...&plan=<id>
```

Plan SatelliteはHierarchyを削除するものではなく、
既知Contextへのshortcutである。

### Tool

V44.4初期版では、
Tool単位で安全なusage signalを既に持つAI Practiceを対象にする。

条件:

- 資格学習Plan
- current active TaskでAI Practiceがprimary execution tool
- 過去30日でStudyPracticeAttemptが2件以上

Tool usageを観測できないToolを、
推測だけで「頻用Tool」として昇格しない。

GitHub / external collaboration tool等はV44.5で扱う。

## Candidate Service

`PersonalizedSatelliteCandidateService`

責務:

- existing Plan / Tool contextを列挙
- 4軸signalを算出
- canonical destinationを作る
- semantic anchorを指定する

責務外:

- rank
- max count
- position
- size
- glow
- edge strength
- AI判断

Candidateはvisual attention fieldsを持たない。

## Promotion Service

`PersonalizedSatellitePromotionService`

4軸を使ってpromotion scoreを算出する。

初期weight:

| Signal | Weight |
| --- | ---: |
| importance | 0.35 |
| usage frequency | 0.25 |
| recency | 0.20 |
| continuity | 0.20 |

```text
score =
  importance * 0.35
+ usage_frequency * 0.25
+ recency * 0.20
+ continuity * 0.20
```

各signalは0〜1へclampする。

初期promotion threshold:

`0.28`

最大表示数:

`4`

AIはrankingにもlayoutにも使用しない。

## Signals

### importance

既存`PlanPriorityService`のeffective priorityを0〜1へ正規化する。

```text
priority 1 -> 1.0
priority 2 -> 0.8
priority 3 -> 0.6
priority 4 -> 0.4
priority 5 -> 0.2
```

Shared Planはimportance内でsmall boostを受ける。
1.0を上限とする。

### usage frequency

過去30日の既存Behavior / WorkSessionを利用する。

主なsignal:

- WorkStarted
- WorkCompleted
- TaskViewed
- PlanTabViewed
- NavigationCompleted
- completed / interrupted WorkSession

新しい「Satellite用閲覧ログ」は作らない。

### recency

最後の実利用時刻をbucket decayする。

概念:

- 1日以内: strong
- 3日以内
- 7日以内
- 14日以内
- 30日以内
- それ以前: weak

利用履歴がまだないPlanは、
recently edited contextを弱いfallback signalとしてのみ扱う。

### continuity

単発利用ではなく継続中かを見る。

Plan:

- doing Task
- progress started
- 過去のactive days

AI Practice:

- recent attempt count
- attempt active days

を利用する。

## Satellite layout

絶対座標は保存しない。

promotion rankごとにL0外周の固定slotへProjectionする。

```text
slot 1 = top
slot 2 = right
slot 3 = bottom
slot 4 = left
```

position role:

- satellite-1
- satellite-2
- satellite-3
- satellite-4

Focus Modeでもslotの方向文法を維持する。

## Semantic anchor

Plan Satellite:

- Personal Plan -> 計画 Intent
- Shared Plan -> 共同 Intent

Tool Satellite:

- 実行 Intent

へsecondary edgeで接続する。

relation:

`personalized_shortcut`

Satellite edgeはcanonical relationではなく、
L0 Attention projectionである。

## UI

Plan Satellite:

- small planet / satellite
- amber系glow
- PLAN SATELLITE
- Shared PlanはSHARED SATELLITE

Tool Satellite:

- violet系glow
- TOOL SATELLITE

Satellite Nodeは通常Nodeと同じFocus / Contextual Classic Surfaceを利用する。

Direct action:

- Plan -> selected PlanのL3へ移動
- AI Practice -> existing Study Practice UI

Semantic Zoom hierarchyそのものは残す。

## Projection key

L0 projection keyには最終Satellite node / edgeも含む。

そのためimportance / usage / recency / continuityの変化で
Satellite promotionが変わればLiving Mapのprojection差分として検知できる。

新しいpersistent Satellite tableは作らない。

## Telemetry

追加structural values:

node_type:

- satellite_plan
- satellite_tool

position_role:

- satellite-1
- satellite-2
- satellite-3
- satellite-4

action_role:

- satellite

Map Telemetryへ保存しないもの:

- promotion score
- signal values
- Plan title
- Task title
- Tool usage detail
- user content

Clientから追加metadataを送ってもwhitelist外は破棄する。

## Privacy / persistence

保存しない:

- Satellite row
- absolute position
- ranking snapshot
- score history
- raw user content
- AI reasoning

既存BehaviorEvent / WorkSession / StudyPracticeAttemptを読み、
request時に決定的にProjectionする。

## Compatibility

維持するもの:

- L0 fixed Intent nodes
- Space Station center
- L1 Domain
- L2 Plan
- L3 Execution
- Semantic Zoom
- Spatial Memory / Space Station Dock
- V43 Execution behavior
- Focus Mode
- Contextual Classic Surface
- Living Reevaluation
- Classic Home / Home Surface preference
- Inbox / Companion Human Review boundary

Satelliteが0件でもL0は完全に利用可能。

## Non-goals

V44.4では以下を行わない。

- fixed Intentの動的削除
- AI ranking
- AI layout
- Graph DB
- Satellite position persistence
- manual pin UI
- external GitHub / Calendar / Slack projection
- SNS external account integration
- generic Tool usage inference without evidence
- automatic mutation

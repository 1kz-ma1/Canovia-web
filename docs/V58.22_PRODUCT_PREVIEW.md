# V58.22 Product Preview

## Goal

V58.21で意図的にBlockedにしていたLevel 2 Product Previewを実装し、
Early Access候補をL1からL2へ進める。

Canonical contract:

- `docs/CANOVIA_MONETIZATION_SPEC.md`
- `docs/CANOVIA_RELEASE_LEVEL_SPEC.md`
- `docs/CANOVIA_PRODUCT_SPEC.md`

## Product decision

Level 2はpaid capability unlockではない。

```text
L1 = stable core
L2 = future value preview
L3 = beta capability
L4 = internal capability
```

V58.22でも実利用可能なのはFreeのみ。

- Free: available
- Premium: Coming Soon
- Pro: Coming Soon
- Dev Pro: Coming Soon

価格、正式提供時期、AI利用枠は固定しない。
購入・checkout・決済導線は作らない。

## User surface

Canonical route:

```text
GET /product-preview
route = product.preview.index
minimum release level = 2
```

Product PreviewはguestでもPublic LevelがL2以上なら閲覧可能。
AccountユーザーにはL2以上のときだけアカウント設定からEntryを表示する。

L1以下:

- Account entryを表示しない
- direct URLはRelease Level middlewareで拒否 / fallback

## Presentation

4 Tierを表示する。

### Free — Execute

CanoviaのCore Loopを自分で進める。

### Premium — Guide

Canoviaが次の判断や軽量推論を支援する。

### Pro — Understand

教材 / Repository /履歴等を理解してContextを組み立てる。

### Dev Pro — Observe & Improve

Development専用追加Layerとして、公開後の実利用から改善Loopを支援する。

## Experience Preview

単純なfeature tableだけでなく、Study / Developmentそれぞれで
Tierごとの処理フローをステップ表示する。

将来Preview動画を追加するときも、このExperience構造を置き換え可能な
presentation contractとして維持する。

### Study

```text
Free
演習 → 採点 → 記録

Premium
履歴 → 弱点推定 → 次の演習最適化

Pro
教材 / 範囲 → 長期Context → 学習Plan再構築
```

### Development

```text
Free
Task / Repository → basic Prompt → external AI

Premium
PR / Issue → Rules / reasoning → guided Prompt

Pro
Repository search → Code / Spec / Test → Implementation Context

Dev Pro
Release → telemetry → Product Intelligence → improvement proposal
```

## Telemetry

server-side:

```text
product_preview_viewed
```

30分のsession windowで重複抑制する。

Safe metadata:

- authenticated
- release_level

ユーザー入力、Plan text、Prompt本文は保存しない。

## Release Gate

V58.22で `product.preview.index` が存在するため、
L2 automated gateは通過する。

Expected state:

```text
L1 -> manual review
L2 -> manual review
L3 -> manual review if Career contract remains structurally satisfied
L4 -> manual review if lower-level contracts remain satisfied
```

ただしManual Reviewが残るため、自動公開はしない。

## Early Access target

Planning targetを:

```text
L2 Product Preview
```

へ更新する。

これは `CANOVIA_PUBLIC_RELEASE_LEVEL` を変更しない。
Production Public Levelは引き続き別操作。

## Non-goals

V58.22では実装しない:

- pricing
- checkout / billing
- Premium / Pro entitlement migration
- interest / notification capture
- preview video media assets
- manual release checklist persistence
- Public Level Admin write
- automatic release promotion
- Career public promotion

# V43.0 Map Usability Baseline

## Goal

V42でLiving Mapの機能と計測基盤が揃ったため、V43では実利用時の認知負荷を下げる。

最初の区切りでは、Mapを開いた一画面で「今やること」が見え、周辺Contextは必要になるまで静かな状態を作る。

## Changes

### Compact Map toolbar

従来の大きな説明Heroを薄いtoolbarへ変更する。

- Living Goal Map / Canovia Map
- Mapの見方はdetailsでオンデマンド表示
- Primary Actionがある時だけ「今やることを見る」
- Classic Home fallback
- Roadmap

モバイルではRoadmapは下部Navigationに存在するためtoolbar内の重複リンクを隠す。

### One-tap NOW focus

「今やることを見る」は新しい実行面を作らない。

現在のPrimary NodeへFocusするだけで、その後の操作はV42.1のContextual Classic Surfaceを使う。

Telemetryは通常のPrimary Node Focusとして記録する。

### Visual hierarchy

- Primary Nodeはhaloを持つ
- 周辺Nodeは少し静かにする
- hover / keyboard focus / Focus Modeでは周辺Nodeも通常濃度へ戻す
- モバイルでは非Primary NodeのsubtitleをOverview中は隠す
- Primary subtitleは残す

### Viewport fit

固定的に大きいMapではなくviewport基準の高さへ変更する。

Desktop:
- clamp(34rem, 68dvh, 44rem)

Mobile:
- clamp(31rem, 100dvh - toolbar/navigation allowance, 38rem)

### Mobile Context Surface

Mapを見失わないことを優先する。

- Bottom Sheet最大高を58vhから46dvhへ縮小
- drag handle風の視覚手掛かり
- headerをsticky
- content paddingを圧縮
- Map下の説明noteはmobileでは隠す

## Boundaries

変えないもの:

- Primary Action決定ロジック
- Map Projection
- Map → Classic責務分離
- Companion Context
- Living Reevaluation
- Telemetry event semantics
- Classic Home

V43.0はUX baselineであり、Primary Homeへの昇格ではない。

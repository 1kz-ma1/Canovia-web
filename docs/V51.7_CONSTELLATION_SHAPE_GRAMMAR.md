# V51.7 Constellation Shape Grammar

## 目的

V51.6 Phase 1でConstellationの密度と選択後Surfaceを整理した後、Planごとの見た目が似すぎる問題を解消する。

Constellationは単なる装飾ではなく、Planを視覚的に識別するためのsignatureとして扱う。

## 1. Deterministic Shape Grammar

各Plan projectionへ `shape_key` を追加する。

同じPlan / 同じTask Group構造なら再表示しても同じshapeになる。
座標はDBへ保存しない。canonical Roadmapからread-only projectionとして生成する。

### Shape family

- singular: Main Star 1個
- binary: Main Star 2個
- arc: 弧
- ladder: 左右段差
- orbit: 楕円周回
- zigzag: 左右ジグザグ
- branch: 中央幹 + 左右枝
- fan: 起点/終点へ広がる扇
- cluster: 中心周辺へ非対称cluster

structural `pattern` は既存の dependency意味を表す値として維持する。

`shape_key` は表示geometry専用であり、patternと分離する。

## 2. Shape Selection

Main Star数とstructural patternを優先してshape familyを決める。

- 1 Star -> singular
- 2 Stars -> binary
- branch -> branch / fan
- converge -> fan / arc
- web -> cluster / orbit
- chain -> arc / ladder / orbit / zigzag

同patternのPlan同士でもPlan ID seedでfamilyを分散する。

shapeはユーザー評価・scoreではない。

## 3. Stable Geometry

Star index / dependency relationは維持する。

各shapeは 8-92% のsafe area内へ配置する。

PlanのTaskが変更されMain Star数自体が変わった場合はgeometry再投影を許容する。
単に画面を開き直しただけでは位置を変えない。

## 4. Overview / Selected Shared Shape

OverviewとSelected Workspaceは同じ `shape_key` / Star座標を使う。

Selected時だけscaleを大きくする。
選択時に別の形へ変えない。

DOM:

- data-constellation-shape="<shape_key>"

## 5. Task Group Rail

Selected Workspaceに `data-constellation-star-rail` を追加する。

Main Starを直接タップしづらい場合でも:

- 星域番号
- 完了数 / Task数
- current / complete state

を横スクロールで確認・選択できる。

Main Star tapとStar Rail tapは同じselected stateを共有する。

## 6. Previous / Next Plan

Selected Workspaceへ前後Plan navigationを追加する。

- data-constellation-plan-switcher
- data-constellation-previous-plan
- data-constellation-next-plan

Focus graph上でinteractive elementから開始していないhorizontal swipeも前後Plan切替として扱う。

誤操作防止:

- horizontal distance >= 72px
- vertical distance <= 48px
- button / a / input等から始まったgestureは無視

## 7. Existing Contracts

維持する:

- V51.6 compact overview density
- selected Focus / Detail palettes
- stable outer orbit
- Roadmap dependency edges
- Task Group projection
- Space Station
- Execution handoff
- Instant Navigation
- no DB migration

## 8. Non-goals

- physics simulation
- user draggable Star positions
- persisted custom geometry
- shapeによるPlan評価
- 3D/WebGL
- zoom/pinch navigation復活

# V47.8 Global Map Navigation

## 目的

Canovia Mapを深く潜ったときでも、現在地を見失わず、どの階層からでも最大抽象度のCanovia全体へ1操作で戻れるNavigation Contractを作る。

V47.8では新しいcanonical entityや階層を追加せず、既存の `graph.hierarchy` とSemantic Zoomを再利用する。

## User-facing Navigation Contract

Mapでは常に次の操作を保証する。

- マスを押す: 内側へ潜る / Leafなら詳細を見る
- 戻る: 1段外へ移動する
- 全体へ: どの深さからでもCanovia全体へ戻る
- 上位Path: 現在地より上の既存Contextへ直接戻る
- Space Station: 現在地を維持したまま入力・相談する

## Global Navigation

`resources/views/map/partials/extensions/global-navigation.blade.php` が常設Navigationを担当する。

表示内容:

- Home: `⌂ 全体へ`
- 現在地
- 上位Context path
- user-facing depth indicator

Homeでは自分自身へのリンクにせず、現在地として表示する。

## Depth labels

内部の `L0 / L1 / L2 / L3` はユーザー向けNavigationへ表示しない。

標準:

- 全体
- 領域
- Plan
- 実行

共同:

- 全体
- 共同
- 目的
- 実行

振り返り:

- 全体
- 振り返り
- 記録
- 詳細

内部の旧Hierarchy DOMは互換性と既存テストのため残し、CSSで視覚的に退役させる。

## Semantic continuity

Home / 上位Pathは既存の:

- `data-map-semantic-zoom`
- `data-map-zoom-direction="out"`
- sessionStorage transition

をそのまま利用する。

`living-map.mjs` のNavigationロジックはV47.8では変更しない。

これによりV47.5のSpatial Continuityと競合せず、#153のmobile box / pointer capture変更とも独立する。

## Merge boundary

V47.8のowner:

- `map/partials/extensions/global-navigation.blade.php`
- `css/map/navigation.css`
- `tests/Feature/GlobalMapNavigationV478Test.php`
- このdoc

原則触らない:

- `extensions/surface-controls.blade.php`
- `extensions/canvas-overlays.blade.php`
- `css/map/data-layers.css`
- `living-map.mjs`
- `MapNodePresentation.php`
- Roadmap

- canonical graph/projection

これによりV47.9 Data Layersと並行実装できる。

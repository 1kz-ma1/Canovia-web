# V58.15 Study Method Outcome Calibration

Status: implemented / validated  
Branch: `feature/v58-15-study-method-outcome-calibration`

## 1. Goal

Use V58.12 real-usage Activity observations as a bounded secondary
personalization signal for Study Method fit without converting descriptive
before/after data into unsupported causal claims.

```text
Task semantic fit
+ current Study state
+ V56.15 deterministic priority
+ repeated explicit Activity observations
→ bounded fit calibration
→ same Primary Method
→ calibrated fit / alternative ranking
```

V58.15 is the first feedback step from observed Study outcomes back into method
recommendation.

It intentionally does not auto-switch the Primary Method.

## 2. Causal boundary

V58.12 observations remain descriptive.

For example:

```text
Practice 55
→ Resource Study
→ Practice 72
```

means:

`after recorded Resource Study, the next comparable Practice was +17pt`

It does not prove:

`Resource Study caused +17pt`

Possible confounders still include:

- question difficulty;
- topic mix;
- outside study;
- elapsed time;
- sleep / attention;
- prior knowledge;
- unrecorded study.

V58.15 therefore uses only a small bounded calibration.

## 3. Eligible Activities

Only explicit non-Practice Activities are eligible:

- Recall;
- Resource Study;
- Listening;
- Dictation;
- Shadowing.

Question Practice is excluded.

V58.12 classifies an interval with no tracked Activity between two Practice
assessments as `question_practice`. That absence does not prove that only
Practice happened, so it is not a safe calibration source.

Also excluded:

- Scope Organization;
- Practical Evidence.

They are not currently represented by V58.12 comparable Activity observations.

## 4. Scope

Calibration uses only observations for:

- the same Plan;
- the same Task;
- the current actor.

Actor isolation continues to come from V58.12:

- authenticated actor → user_id;
- anonymous actor → actor_token.

No cross-Task, cross-Plan or population-wide learning is introduced.

## 5. Minimum evidence

Per eligible Activity:

```text
observation_count < 3
→ observing
→ adjustment 0
```

After at least three observations, only the latest at most five intervals are
used for calibration.

This keeps old history from dominating the learner's current pattern.

## 6. Robust center

Calibration uses the median score delta of the selected latest sample.

It does not use the arithmetic average as the calibration center.

Reason:

- one unusually easy follow-up Practice;
- one unusually difficult follow-up Practice;

should not disproportionately move the fit score.

## 7. Meaningful direction

Each sampled interval is classified:

```text
delta >= +5 → positive
delta <= -5 → negative
otherwise   → neutral
```

The dominant meaningful direction must cover at least:

`2 / 3`

of the selected sample.

If meaningful positive and negative directions conflict without reaching that
ratio:

`status = mixed`

and no fit adjustment is applied.

If the median absolute delta is below 5pt:

`status = neutral`

and no fit adjustment is applied.

## 8. Bounded adjustment

Raw calibration:

```text
raw_adjustment =
  round(median_delta / 5)

clamp to -5..+5
```

Evidence maturity:

```text
sample_strength =
  min(1, observation_count / 5)
```

Applied calibration:

```text
applied_adjustment =
  round(raw_adjustment * sample_strength)

clamp to -5..+5
```

Examples:

```text
3 observations
+10 / +15 / +20

median +15
raw +3
sample strength 60%
→ applied +2
```

```text
5 observations
+10 / +15 / +20 / +15 / +10

median +15
raw +3
sample strength 100%
→ applied +3
```

```text
3 observations
+15 / -10 / +1

conflicting meaningful direction
→ mixed
→ applied 0
```

## 9. Recommendation authority

V58.15 does not alter the selected Primary Method key.

V56.15 remains authoritative for:

- unfinished Practice resume continuity;
- School Test Scope;
- memorization → Recall;
- skill learning → Practical Evidence;
- Exam Mode;
- adaptive Recall;
- repeated knowledge/concept gap → Resource Study;
- retention due → Recall;
- Task-semantic fit.

Flow:

```text
select Primary Method
→ calculate deterministic state fit
→ apply bounded outcome calibration to fit_score
→ keep the same primaryKey
→ rank alternatives using calibrated fit
```

Therefore outcome calibration can:

- adjust displayed fit;
- reorder alternatives;
- expose personal observation context.

It cannot:

- automatically replace the Primary Method.

A future auto-switch policy requires a separate contract.

## 10. Method output

Each Study Method now exposes:

- `base_fit_score`;
- `fit_score`;
- `outcome_adjustment`;
- `outcome_signal_status`;
- `outcome_observation_count`;
- `outcome_sample_count`;
- `outcome_median_delta`;
- `outcome_direction_ratio_percent`;
- `outcome_note`.

Recommendation output also exposes:

`outcome_calibration`

with:

- minimum observation threshold;
- maximum sample size;
- meaningful delta threshold;
- maximum adjustment;
- primary-switch boundary;
- per-method signals.

## 11. UI

### Primary Method

When adjustment is non-zero, the recommendation shows:

`実利用補正 +N / -N`

with the observation note.

It explicitly says:

`このSignalだけでPrimary Methodは自動変更しません。`

### Alternatives

Alternative Study Method cards show the bounded outcome adjustment when non-zero.

Because alternatives are ranked after calibration, repeated personal observation
can change their order.

### Study Activity page

The fit list shows:

`base fit → calibrated fit`

when adjusted.

The V58.12 observation panel remains visible and now explains that:

- at least 3 comparable observations are required;
- latest at most 5 are used;
- fit adjustment is bounded to ±5;
- no causal claim is made;
- Primary is not auto-switched.

## 12. Question Practice exclusion

Question Practice receives:

- outcome_signal_status = excluded;
- outcome_adjustment = 0.

Even if V58.12 has multiple `question_practice` observation intervals, they are
not used for calibration.

This prevents "no tracked Activity Evidence" from being interpreted as clean
Practice-only intervention data.

## 13. Mutation / provider boundary

V58.15 is:

- DB-only;
- deterministic;
- read-only;
- provider-free.

It does not create or modify:

- TaskEvidence;
- Task progress;
- Task status;
- Practice Session;
- Practice Strategy;
- Recall items;
- mastery;
- Practice Reliability;
- billing.

No AI call.
No external provider call.
No migration.

## 15. Result

Canovia can now begin learning from an individual's own Study execution history
without turning noisy before/after data into a hard optimization policy.

The current hierarchy is:

```text
Task semantics / Study state
= authority

Repeated personal outcome observations
= bounded calibration

Primary auto-switch
= not allowed
```

This creates a safe bridge from observation to personalization while preserving
the deterministic Study Method policy.

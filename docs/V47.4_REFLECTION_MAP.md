# V47.4 Reflection Map

## 目的

振り返りIntentを、通常の Plan category -> Plan hierarchy から切り離し、
**過去の事実を「何を見返したいか」というLensから辿る専用Map**へ変更する。

V47.4では新しい履歴Entityを作らない。
既存のWorkLog / TaskEvidence / 完了Taskをrequest時に決定論的にProjectionする。

## Hierarchy

```text
L0 Intent
  -> L1 Reflection Lens
    -> L2 Reflection Record
      -> existing Plan / Timeline / Achievement
```

L1 Lensは固定4種類とする。

- 最近の実績
- Evidence
- 完了Task
- 振り返り記録

L2ではLensに該当する具体的な既存Recordを表示する。

## Canonical Sources

### 最近の実績

WorkLogとTaskEvidenceをoccurred / created timeで統合し、直近順で表示する。

### Evidence

TaskEvidenceをそのまま利用する。

AIやMapが過去の事実を生成しない。

### 完了Task

以下を完了としてProjectionする。

- status = done
- progress_percent >= 100

Taskの状態自体をMap側で変更しない。

### 振り返り記録

明示的に人が残したReflection系Evidenceだけを対象にする。

初期対象:

- guided_execution_reflected
- interview_review_completed

単なるWorkLogや時間経過からReflectionを推測しない。

## Navigation Contract

L1のLens NodeはContainerであり、
V47.3 Semantic Interactionに従ってNode本体クリックでL2へSemantic Zoomする。

L2 RecordはLeafであり、Map内にさらに人工的な深さを作らない。
Node本体から元のPlan等のcanonical surfaceへ直接戻る。

RecordのContext Inspectorには:

- summary
- Plan
- occurred date
- record kind
- 元のContextへの導線
- Timelineへの導線

を表示できる。

## Empty Lens

対象Recordが0件でも中央Nodeだけのdead-end Projectionにしない。

Projection-only NEXT OPTION:

- Timelineを確認
- 達成した計画を見る

これらはDB Entityではなく、Navigation fallbackである。

## Spatial Memory

Breadcrumb / Semantic Zoom / Space Station Dockは既存契約を維持する。

Reflection専用depth label:

- L0 Intent
- L1 Lens
- L2 Record
- L3 Detail

V47.4ではReflection Map自体はL2までを利用する。
L3 Detailは既存canonical surface側の責務とする。

## Safety / Truthfulness

Reflection Mapは過去を「それっぽく」補完しない。

- 外部作業をWorkLogなしで実施済みと推測しない
- Evidenceがない成果を生成しない
- 完了をdeadlineや経過時間から推測しない
- Reflectionを通常Evidenceから自動推測しない

Mapはcanonical historyのProjectionであり、Source of Truthではない。

## Compatibility

維持するもの:

- L0固定Intent
- V47.3 Semantic Interaction
- Navigation Graph / Attention State separation
- Living Reevaluation / Projection Key
- Map -> Map Instant Navigation
- Space Station Spatial Dock
- L3 Execution Map
- Collaboration専用Projection
- Timeline / Achievement既存画面

## Non-goals

- 新規Reflection DB Entity
- Timelineの置換
- Achievementの置換
- AIによる過去の要約生成
- Reflectionの自動判定
- Map position永続化
- billing / entitlement変更
